# 2. 最初に確認すべき前提（仮説として扱う）

## 2-1. 「8インチ専用」はコンテンツ供給が最大リスク

・レコードの一般流通規格は 7インチ（17cm）／10インチ（25cm）／12インチ（30cm）
・**8インチ（20cm）は一般流通規格ではない**。インディーズのラッカーカット（lathe cut）盤に少数存在する程度
・つまり「8インチ専用」にすると、**市販レコードがほぼ使えない**

これは欠点とは限らない。むしろ以下の分岐になる。

| 方針 | 内容 | 評価 |
|---|---|---|
| A. 8インチを貫く | 自社で8インチ盤をカット委託／内製し、オリジナル盤のみを再生 | 差別化は最大。著作権処理も自主制作なら簡潔。ただしコンテンツ制作が事業の主戦場になる |
| B. 7インチ（EP）に変更 | 中古市場が厚く、1960-70年代のドーナツ盤が安価かつ大量に入手可能。オリジナルのジュークボックスと同じ規格 | 現実解。集客装置としては最短距離 |
| C. 両対応 | 機構的にアーム位置決めをソフトで可変にすれば、7/8/10インチ混在も可能（後述の電動キュー方式なら追加コストほぼゼロ） | **推奨** |

→ **機構を「サイズ可変」に作れば、この判断を後回しにできる**。設計上そうしておくべき。

## 2-2. 「レコードを本当に回すこと」が価値の中心か

デジタル音源をスピーカーから流し、機構は演出だけ、というジュークボックスは既に存在する（安価）。
本企画の価値は「**本物の盤が選ばれ、運ばれ、針が落ちる**」という機構そのもの。
したがって機構は省略できない。ここがコストの大半を占めることを前提にする。

# 3. 中核課題：トーンアームの自動キュー（オートキュー）

## 3-1. 問題の正体

市販ターンテーブルの自動化には3段階ある。

| 種別 | 頭出し（リードイン） | 終了後リターン | 例 |
|---|---|---|---|
| マニュアル | × | × | オーディオ用単体アーム全般 |
| セミオート | × | ○ | 中級機に多い |
| **フルオート** | **○** | ○ | AT-LP60X系、DP-29F系など |

「既製アームは戻れるが出て行けない」という認識は、セミオート機を指している。
フルオート機なら頭出しもできるが、**リードイン位置は30cm/17cmのカムで固定**されており、8インチ盤には合わない。また曲単位の頭出し（3曲目だけ再生）はできない。

ジュークボックスは「**任意の盤の、任意の曲位置に、針を落とす**」必要がある。
→ **既製ターンテーブルの自動機構では要求を満たせない。ここは自社で作るべき領域。**

そしてこれは、RIGELにとっては**2軸の位置決め＋昇降という、ごく標準的なFA課題**である。ここが本企画で最も「RIGELだからできる」部分。

## 3-2. 推奨方式：ステッピングモータ駆動＋クラッチ解放式 回転アームベース

```
              ┌── アーム角度センサ（AS5600 磁気エンコーダ／非接触）
              │
  [ステッピングモータ]──[減速]──[駆動フォーク]  ⇄  [トーンアーム軸]
                                    ↑
                          ソレノイドで係合／解放
  [リフタ（カム＋マイクロステッパ or サーボ＋シリコンダンパ）] ── アーム上下
```

動作シーケンス：
1. 原点復帰（フォトマイクロセンサでアームレスト位置を検出）
2. リフタでアームを上昇（針を浮かせたまま）
3. 駆動フォークを係合し、ステッピングモータで目的半径までアームを旋回
   - 半径は「盤サイズ＋曲番号」からソフトで算出。**8インチでも7インチでも同じコードで対応可能**
4. リフタを**2秒程度かけてゆっくり**下降し、針を着地
5. **駆動フォークを解放** ← ここが要。再生中はアームを完全にフリーにしないと音質・盤・針を壊す
6. 再生中はアーム角度センサで半径を常時監視
7. 内周側で角度が急変＝リードアウト検出 → フォーク再係合 → リフト → アームレストへ復帰

### この方式の利点
・**曲頭出しができる**（ジュークボックスの必須機能）
・盤サイズがソフトで可変（8/7/10インチ混在可）
・終了検出をリードアウト溝の機械検出ではなくセンサ値で行うため、無音部での誤動作が少ない
・部品が安い（ステッピング2軸＋ソレノイド1＋磁気エンコーダ1＋フォトマイクロ数個）

### 設計上の注意点
・**再生中の非接触（フリー）状態の確保が絶対条件**。フォーク解放後にわずかでも接触があると、音飛び・偏摩耗が出る。フォーク側に0.5mm程度の逃げを持たせる
・針圧はアームの静的バランスで決める。ここに電動要素を入れない
・リフタの下降速度が速いと針とレコードを痛める。シリコンダンパ必須
・アーム角度センサはアーム軸に磁石を貼るだけ（非接触）。接点式ポテンショは摩耗するので不可
・アーム自体は既製品（ヘッドシェル交換式＝SME規格）を流用してよい。**自動化するのはアームの外側**

## 3-3. 代替案（比較）

| 案 | 内容 | 評価 |
|---|---|---|
| フルオート機のカム改造 | 既製フルオート機のサイズ選択カムを8インチ用に作り直す | 安いが曲頭出し不可。ジュークボックスとして成立しない |
| リニアトラッキング化 | アーム基部を直動軸に載せ、追従制御 | 高音質だが制御難度が跳ね上がる。v1では避ける |
| **回転アーム＋クラッチ解放（推奨）** | 上記3-2 | **コスト・難度・機能のバランスが最良** |

# 4. 15〜20枚の選盤機構（アーキテクチャ選択）

ここが機構設計の本体であり、**コストと工数の7割はここ**。

## 案A：垂直再生方式（Seeburg型）— v1推奨

レコードをマガジンに**立てたまま保持し、その場で立てたまま再生**する。

・マガジン：15〜20スロットの垂直ラック（固定）
・キャリッジ：直動軸（タイミングベルト＋リニアガイド、ステッピング駆動）上に
  **ターンテーブル駆動部＋トーンアームユニットを丸ごと搭載**して走行
・目的スロットで停止 → スピンドルが盤を横から掴み、わずかに引き出して回転 → アームが側面からキュー

**利点**
・**レコードの搬送・受渡しが一切不要**。ピック＆プレース機構が消える＝部品点数が劇的に減る
・直動1軸＋アーム2軸のみ。RIGELの標準的なFA構成そのもの
・実機のSeeburg Select-O-Maticが半世紀実証した方式

**注意点**
・垂直再生では針圧を重力で得られない → **アームにばね式の針圧付与**が必要（Seeburgも同じ方式）
・ダストが盤に積もりにくいという副次的利点がある（運用上かなり効く）

## 案B：水平ターンテーブル＋搬送方式（Wurlitzer型）

垂直マガジンから1枚取り出し、水平に姿勢変換してターンテーブルに載せる。

**利点**：「レコードが運ばれる」動きが見えるので**体験の見せ場になる**。既製ターンテーブルを移植したいという当初要望にも合う
**欠点**：90°姿勢変換＋スピンドル挿入という最難関工程が入る。盤の落下・割れ・傷のリスク、位置決め精度要求が一段厳しい。工数とコストは案Aの1.5〜2倍とみる

## 案C：レコード1枚固定（v0＝検証機）

マガジンなし。人が1枚セットする。自動化するのは**コイン→選曲→オートキュー→自動リターン**のみ。

**これを最初に作るべき。** 理由は後述（第8章）。

# 5. 制御アーキテクチャ

```
 [コインセレクタ 100円専用] ──パルス──┐
 [選曲ボタン／テンキー]              │
                                     ▼
                          ┌──────────────────┐
                          │ Raspberry Pi 5    │  UI・選曲ロジック・売上ログ
                          │ (Python)          │  曲目DB・照明演出・遠隔監視
                          └────────┬─────────┘
                                   │ UART / USB（コマンド＆ステータス）
                          ┌────────▼─────────┐
                          │ RP2040 (Pico)     │  リアルタイムのモータ制御
                          │ or 小型PLC        │  原点復帰・インターロック
                          └────────┬─────────┘
             ┌──────────────┬──────┴───────┬──────────────┐
      ステッピングドライバ  ソレノイド    センサ入力      LED演出
      (TMC2209等 ×3)      (クラッチ)   (フォトマイクロ／  (WS2812B)
                                        AS5600／近接)
```

## 設計判断
・**Pi にリアルタイム制御をさせない**。Linuxはモータのパルス生成に向かない。脱調・異音の原因になる。Piは「上位（UI・DB・通信）」、Picoまたは小型PLCが「下位（軸制御・安全）」という分担にする
・RIGELの本業がPLCであることを考えると、**下位をPLC（FX5U級）にしてPiと連携する構成も有力**。RTS教材に転用する前提なら、むしろPLC版の方が価値が高い（第9章）
・**音声信号はPiを通さない**。カートリッジ→フォノイコライザ（MM）→アンプ→スピーカー のアナログ経路を維持する。これが「本物」の根拠になる。Piは再生トリガとログのみ扱う

## 安全設計（省略不可）
・非常停止押ボタン（機械的接点でモータ電源を直接遮断）
・扉／カバー開時のインターロック（PET扉にセーフティスイッチ）
・全軸の原点復帰シーケンスと、原点未確立時の動作禁止
・AC100V部は絶縁・接地・PSE適合部品。ロジック側と物理的に区画分離
・コインセレクタ入力はフォトカプラでアイソレーション＋チャタリング除去

# 6. コイン・課金部（100円専用）

・国産の電子式コインセレクタ（100円専用設定）を使用。パルス出力をGPIOで受ける
・**必須要件**
  - 返却レバーとコイン返却口（詰まり時に客が自力で取り出せること）
  - コインボックスは施錠式、かつ売上カウンタをソフト側にも記録（実機との突合せ）
  - 糸吊り・逆流などの不正対策（安価なセレクタは弱い）
・**クレジットの扱い方で法的論点が変わる（要確認・断定しない）**
  - 投入→即時再生（繰越なし・返金なし）＝前払式支払手段には当たらない可能性が高い
  - 「クレジットを貯めて後日使える」設計にすると論点が発生しうる
  - → **v1では繰越・返金なしの即時消費型にする**のが安全

# 7. 筐体（アルミフレーム＋PET）

| 項目 | 検討事項 |
|---|---|
| フレーム | ブラックアルマイトのアルミフレーム。**重量物（マガジン＋キャリッジ）を支えるため、剛性計算とアンカー／転倒防止が必要**。人が寄りかかる設置環境を想定すること |
| PETカバー | 2〜3mm厚のダークスモーク。**PETは帯電してホコリを吸う**＋傷が付きやすい。前面の頻繁に触れる部分は帯電防止処理かハードコート品を選定 |
| 曲面 | 1970年代らしいアールを出すならPETの熱曲げ。Wurlitzer 1015のようなアーチは加工難度が高い。**v1は直線基調のミニマルな解釈にする方が完成度が上がる** |
| 照明 | アドレサブルLED（WS2812B）でバブルチューブ風／グラデーション演出。ここが「1970年代の再解釈」の主戦場。コストに対する見た目の効果が最も高い |
| 表示 | ニキシー管風・VFD風・16セグでレトロ感を出す。液晶は世界観を壊す |
| 防塵 | **レコード機構にとってホコリは最大の敵**。前面開口は最小限にし、盤の露出部にはブラシシールを |
| 騒音 | ステッピングの唸り音が演奏中に乗らないよう、再生中は駆動系を完全停止させる（前述のクラッチ解放と整合） |

# 8. 開発の進め方（小さく作る）

RIGELの事業開発スタイル（小さく作る→使ってもらう→改善→仕組み化）に従い、3段階に分ける。

## v0：オートキュー検証機（最優先）
・レコード1枚固定・手動装填
・コイン投入 → 曲番選択 → オートキュー → 再生 → 自動リターン
・**検証すべき仮説**
  1. クラッチ解放式で音飛び・偏摩耗なく再生できるか
  2. 曲頭出しの位置決め精度は実用範囲か（溝ピッチに対して何mm狙えるか）
  3. リフタ下降で針・盤を痛めないか
  4. 100円課金〜再生までの一連の体験が、客にとって気持ちよいか
・ここで失敗したら、v1の機構設計は全部無駄になる。**必ず先にやる**

## v1：15〜20枚マガジン機（案A：垂直再生方式）
・v0の成果を載せ替える。キャリッジ直動軸＋マガジンを追加
・古民家（源氏車）に設置し、実際に客に使ってもらう

## v2：製品化・横展開
・8インチ（または7インチ）オリジナル盤のカット供給
・他店舗販売／イベントレンタル
・RTS教材版への転用

# 9. 事業としての評価（理念 §8 の10観点）

事業として無理に肯定しない。現時点の率直な評価は以下。

| # | 観点 | 評価 | コメント |
|---|---|---|---|
| 1 | 顧客の課題を解決するか | **△** | 「ジュークボックスが無くて困っている人」はいない。解決するのは**店舗の集客・滞在価値**という間接的な課題。顧客を「設置する店舗」に定義しないと成立しない |
| 2 | 顧客が金を払う理由 | **△** | 単体販売は難しい。「集客装置」「撮影映えする什器」「体験コンテンツ」として売るなら理由は立つ |
| 3 | RIGELだからできるか | **◎** | 機構設計＋位置決め制御＋センサ＋筐体を一社で完結できる会社は少ない。ここは明確な優位 |
| 4 | 継続的収益 | **△** | 1台売り切りでは弱い。**オリジナル盤の供給／保守契約／レンタル**に繋げてはじめて継続性が出る |
| 5 | 他事業との相乗効果 | **○** | 古民家事業（源氏車）の集客装置として直接効く。RTSへの転用余地が大きい（下記） |
| 6 | 技術・ノウハウの蓄積 | **◎** | 直動位置決め・割出し・ピック・課金HMI・Pi×PLC連携という**再利用可能な資産**が丸ごと残る |
| 7 | 将来的な拡張性 | **○** | 盤サイズ可変に作れば、用途拡張は容易 |
| 8 | 小さく検証できるか | **◎** | v0（1枚固定・オートキューのみ）で中核仮説を安く潰せる |
| 9 | 運用・保守コスト | **×（最大の懸念）** | **針の消耗**（常用で数百時間ごと交換）、盤の摩耗・汚れ、ホコリ、客による物理的な乱暴な扱い。歴史上ジュークボックスが消えた理由の一つがこれ。→ 針はヘッドシェル交換式にして**工具レスで数十秒で交換できる設計**を最初から織り込むこと |
| 10 | 模倣困難性 | **○** | 機構ノウハウは図面が無ければ模倣しにくい。ただし「デジタル音源の見た目ジュークボックス」という安価な代替は既に存在し、そちらと比較される |

## 総評（率直に）

**「1台目を作る」ことの価値は高いが、「ジュークボックス製造事業」として成立させるのは現時点では弱い。**

理由：顧客課題が間接的で、継続収益の道筋が未定義で、運用保守コストが構造的に重い。

一方で、**以下の2つの用途に転用する前提なら、投資は十分に回収可能**と考える。

1. **古民家（源氏車）の集客装置**
   「本物の機械が動く」体験は写真・動画で拡散されやすく、古民家事業の集客施策と直結する。1台完結でも意味がある

2. **RTSの総合実習教材への転用 ← 最も注目すべき**
   ジュークボックスは、FA教育に必要な要素をほぼ全部含んでいる：
   - 直動軸の位置決め・原点復帰
   - 割出し（インデックス）
   - センサ（フォトマイクロ／近接／エンコーダ）
   - アクチュエータ（ステッピング／ソレノイド）
   - シーケンス制御（PLC）
   - 上位連携（PLC × Raspberry Pi）
   - 安全設計・インターロック
   - HMI・課金処理

   しかも**動作結果が「音楽が鳴る」という形で即座に、感覚的に分かる**。これは教材として極めて強い性質である（普通の実習装置は「ワークが移動した」で終わる）。

   → **v1の設計段階から「RTS教材版に展開できる構成」を意識して作るべき**。具体的には、下位制御をPicoではなくPLCで組み、軸・センサをユニット単位で切り出せるようにしておく。これができれば、1台の投資が2事業に効く。

## 現時点の推奨アクション

1. **8インチを貫くか7インチに変えるか**を決める（コンテンツ調達の見通しがすべてを左右する）。ただし機構はサイズ可変に設計し、判断を後ろにずらせるようにする
2. **v0（オートキュー検証機）に着手**。ここが技術的な最大のリスクであり、かつ最も安く検証できる
3. v0が通った時点で、v1の機構方式（案A垂直再生／案B水平搬送）を、コストと「見せ場」の重みで決める
4. 並行して、**RTS教材版への展開可否**を検討する。これが成立するなら本企画の事業評価は一段上がる
