# 古民家（源氏車）Instagram・Threads 連携メモ

■ 前提（陛下ご指示 2026-09-16）
- 古民家事業「源氏車」のSNSは **Instagram・Threads ともにハンドルは `genjiguruma1976`** とする。
- 本ノートは、両者を連携させたうえで運用するための手順と役割分担を整理したもの。

⚠️ **実際の連携操作（ログイン・設定変更）はアプリ側の手作業であり、Claude Code側からは実行できない。** 本ノートは手順書であって「連携済みの記録」ではない。連携完了後、下部のチェック欄を更新すること。

■ 連携の仕組み（前提知識）
- ThreadsはInstagramアカウントを使ってログインする設計のため、**Instagram `@genjiguruma1976` でThreadsにログインすれば、同じハンドルのThreadsプロフィールが作られ、自動的に連携された状態になる**。ハンドルを別々に取り直す必要はない。
- Threadsのプロフィールには連携元のInstagramへの導線が表示される。逆にInstagram側からもThreadsのバッジ／リンクを出せる。
- Threadsプロフィールのみを削除することは可能だが、**Instagram本体を削除するとThreads側も使えなくなる**関係にある。アカウント整理の際は注意。

■ 連携手順（スマートフォンで実施）
1. Threadsアプリをインストールし、**「Instagramでログイン」から `genjiguruma1976` を選ぶ**（すでに月英など他アカウントでログイン済みの場合は、アカウント切替でgenjiguruma1976を追加する）。
2. プロフィール（名前・自己紹介・アイコン）はInstagramから引き継げるので、**源氏車紋のアイコンとプロフィール文をInstagramと揃える**。
3. プロフィールのリンク欄に、Instagramと同じ**スペースマーケット掲載ページ**を設定する。
4. クロス投稿設定
   - Instagram側：投稿画面に出る「Threadsにも投稿」トグル（アプリのバージョンにより文言は異なる）。
   - Threads側：投稿をInstagramのストーリーズへ共有する導線。
   - **常時ONにはしない。**下記の役割分担のとおり、内容によって使い分ける。
5. 連携後、Instagramのプロフィール上でThreadsへの導線（バッジ）が表示されているかを確認する。

■ 役割分担（同一内容の全転載はしない）
| | Instagram | Threads |
|---|---|---|
| 軸 | 「魅せる」 | 「いま伝える」 |
| 主なコンテンツ | 提灯演出・外観・改修Before/After・利用シーンの写真／リール | 短文の実況、改修の進捗ひとこと、空き日程の告知、撮影当日の様子、質問への返答 |
| 頻度 | 週3〜5回（[[古民家事業_SNS戦略メモ]]の方針どおり） | 思いついた時に軽く。1日1〜2投稿でも成立する |
| 目的 | 新規リード獲得（リールの拡散） | 既存フォロワーとの接点維持・人柄の可視化 |

- Threadsは会話型のため、**コメント（返信）に返すこと自体がコンテンツになる**。Instagramで反応が薄いネタでも、Threadsなら「問いかけ」として出せる。
- 両方に同じ文章をそのまま流すと、どちらを見ても同じで片方をフォローする意味がなくなるため、**クロス投稿は「告知」など重複しても害のない内容に限る**。

■ 連携によって期待できること
- Threads→Instagramの相互導線が増え、[[古民家事業_SNS戦略メモ]]提案Bの「他チャネルからの導線」が1本増える。
- Instagram側の課題（フォロー中779／フォロワー104という比率の偏り）に対し、Threadsは立ち上げ直後で数字の先入観がないため、**健全なフォロー／フォロワー比で始め直せる**。最初からフォロー返し狙いの大量フォローはしないこと。

■ 留意点（過度な期待はしない）
- Threadsは現状、**外部リンクのクリック導線としてはInstagramより弱い**。集客の主戦場はあくまでInstagramのリールとスペースマーケット掲載ページであり、Threadsはその補助と位置づける。
- 運用者が1人（陛下）である以上、**Threadsを増やすと投稿工数が単純に増える**。Instagramの週3〜5回が回らないうちにThreadsへ手を広げると共倒れになりやすい。まずは「Instagram優先、Threadsは短文で気軽に」を徹底する。
