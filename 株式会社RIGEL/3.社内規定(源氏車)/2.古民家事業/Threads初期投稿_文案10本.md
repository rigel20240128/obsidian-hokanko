# 源氏車 Threads 初期投稿 文案10本

■ 使い方
- Threads `@genjiguruma1976` の立ち上げ用。上から順に、**1日1本・10日間**を目安に投稿する。
- **そのまま使わず、実際の状況に合わせて数字・固有名詞を差し替えること。**事実と違う投稿はしない。
- Threadsは会話型のSNS。**完成された文章より、独り言に近い短さの方が伸びやすい。**長くしないこと。
- 写真は1枚あれば添える。なくても成立する文案にしてある（Threadsは文字だけで問題ない）。
- ハッシュタグはThreadsでは**1投稿1個まで**が目安。Instagramのように並べると読みにくくなる。

■ 役割の再確認（[[古民家_Instagram_Threads連携メモ]]より）
- Instagram＝「魅せる」。完成した写真・リール。
- Threads＝「いま伝える」。作業中の手元、迷っていること、空き日程、当日の出来事。
- **同じ文章を両方に流さない。**Threadsは未完成・進行中のものを出せる場所として使う。

---

### 1本目｜開設のあいさつ（1日目）
```
茨城の稲敷で、築50年の古民家を少しずつ直しています。
源氏車といいます。
撮影やロケ地としてお貸ししながら、直しては使い、使っては直しの繰り返し。
ここでは、進行中のことをそのまま書いていきます。
```
※ Instagramのプロフィール文と重複しない書き出しにしてある。Threadsは「作業日誌」の位置づけだと最初に宣言しておくと、以降の投稿が楽になる。

### 2本目｜いま手をつけている場所
```
今日は納屋の片付け。
50年分の物が出てきて、半分は何に使う道具か分からない。
古いものに新しい役目を、と言っておきながら、まず役目を調べるところから。
```
※ 弱さ・手探りを出す。これがThreadsで伸びやすい型。

### 3本目｜提灯（Instagramの主力コンテンツの裏側）
```
日が落ちてから提灯を灯すと、昼とは別の建物になる。
写真だと一瞬だけど、実際は一つずつ火を入れていくので地味に時間がかかります。
この作業、嫌いじゃない。
```
※ Instagramに提灯の完成写真があるなら、その「裏側」として出す。同じ写真を再投稿しない。

### 4本目｜問いかけ（エンゲージメント狙い）
```
古民家で撮影するとしたら、どの場所を撮りたいですか。
母屋の広間、離れ、納屋、それとも外の屋根まわり。
意外な答えが返ってくると、こちらも気づきがあります。
```
※ 返信が来たら必ず返す。**返信のやりとり自体がThreadsのコンテンツ**になる。

### 5本目｜空き日程の告知（送客導線）
```
今月の空き、まだ何日かあります。
撮影・ロケでのご利用はプロフィールのリンクから。
平日の方が静かです。鳥の声しかしない。
```
※ **リンク欄にスペースマーケットのURLが入っていることが前提。**未設定なら先に設定する。

### 6本目｜Before / After の途中経過
```
床を張り替え中。
剥がしたら下から古い床板が出てきて、これはこれで味があるので残すか迷っています。
効率だけ考えたら全部替えた方が早いのだけど。
```
※ 迷いを書く。答えを出さない投稿があってよい。

### 7本目｜季節・地域
```
稲敷は稲刈りの時期。
古民家の前の道を、コンバインが普通に通っていきます。
この景色ごと撮りたいという方がいたら、今が一番いい時期です。
```
※ 季節ネタは地域性が出るうえ、投稿の口実として毎年使える。

### 8本目｜利用シーンの報告
```
先日、離れで撮影がありました。
撮影が終わったあと、こんな空間があるとは思わなかった、と言っていただけて。
建物が褒められると、自分が褒められるより嬉しい。
```
※ **実際に利用があった時にだけ投稿する。**なければこの回は飛ばす。利用者が特定される情報（企業名・人物）は出さない。

### 9本目｜手仕事のディテール
```
屋根の瓦、一枚ずつ形が違う。
機械で作っていない時代のものなので、当たり前といえば当たり前なのだけど、
並べて見ると誰かが手で作ったんだなと分かる。
#古民家
```
※ ハッシュタグを使うならこの型。1個だけ添える。

### 10本目｜Instagramへの導線
```
写真でまとめたものはInstagramの方に上げています。
こちらは作業しながらの独り言なので、完成形はあちらでどうぞ。
@genjiguruma1976
```
※ 10本目で初めて相互導線を張る。1本目でやると宣伝色が強く出るので後ろに置いてある。

---

■ 投稿後にやること
- コメント（返信）が付いたら、**その日のうちに返す。**Threadsは返信の速さがそのまま評価につながる。
- 10本終わったら、どの投稿に反応があったかを記録し、次の10本の方向性を決める。反応の記録は[[古民家事業_SNS戦略メモ]]に追記する。

■ やらないこと
- Instagramの投稿をそのままコピーして流す（両方見ている人にとって無価値になる）
- フォロー返し狙いの大量フォロー（Instagram側で比率が崩れている問題を、Threadsで繰り返さない）
- 毎日必ず投稿しようとして、書くことがないのに無理に書く（沈黙の方がましな日はある）
