# API設定

保管庫（`obsidian-hokanko`）における API 接続・APIキーの取り扱いを定める。
実体の設定ファイルはリポジトリ直下に置き、本書はその内容と運用ルールを記す。

最終更新：2026-08-30

---

## 1. 設定ファイルの構成

| ファイル | 追跡 | 役割 |
|---|---|---|
| `.claude/settings.json` | ✅ Git管理 | **保管庫共通**のClaude Code設定。接続を許可する外部サイト、および秘密情報の読取禁止を定める |
| `.claude/settings.local.json` | ❌ Git除外 | **端末ごと**の個人設定。PC固有のパスや一時的な許可を記す。共有しない |
| `.env` | ❌ Git除外 | APIキーの実体。**絶対にコミット・共有・外部送信しない** |
| `.env.example` | ✅ Git管理 | 必要なキーの**変数名だけ**を記したひな型。値は常に空 |

### なぜ2つに分けるか

従来は `.claude/settings.local.json` のみが存在し、これが Git で追跡されていた。
このファイルには特定PCのユーザー名を含む一時フォルダのパスなど、**他の端末では意味をなさない記述**が混在していた。
そこで、保管庫全体で共有すべき設定を `settings.json` へ移し、端末固有の設定は `settings.local.json` に残したうえで Git の追跡から外した。

---

## 2. 外部サイトへの接続許可

`.claude/settings.json` の `permissions.allow` に、調査で常用する同業・関連事業者のサイトを登録済み。
登録済みのサイトは都度の確認なく参照できる。

- テクノリーチ／ロボットクラウド／FABIC／セレンディップ／アフレル（3ドメイン）
- BYNAS／ファクトリーDXセンター／ロボリース／ヴイストン

**新しいサイトを恒常的に使う場合**は `settings.json` の `allow` に
`WebFetch(domain:ドメイン名)` の形式で追記する。一度きりの参照であれば追記は不要。

---

## 3. APIキーの取り扱い（厳守）

1. キーの実体は `.env` にのみ記す。保管庫内の通常のノートに書き写さない。
2. `.env` は `.gitignore` により除外済み。**GitHubへ上がらないことを確認済み。**
3. `.claude/settings.json` の `permissions.deny` で `.env` 系ファイルの読取を禁止しているため、
   Claude Code はこれらを読まない。
4. キーをログ・コミットメッセージ・出力・外部送信に含めない。
5. 保管庫を外部と同期・共有・公開する際は、`.env` を含めないことを毎回確認する。

### 現在必要なキー

| 変数名 | 用途 | 要否 |
|---|---|---|
| `GEMINI_API_KEY` | AI社員ペルソナ画像の生成等 | 取得済み（PC上の `.env` に保管） |
| `ANTHROPIC_API_KEY` | ClaudeをAPI経由で直接呼ぶ場合のみ | **不要。** 定額プランのClaude Codeを使う通常運用では使わない |

---

## 4. MCP（外部サービス連携）について

Google ドライブ・Notion・Slack・Gmail・カレンダー等との連携は、
リポジトリ内の設定ファイルではなく **Claude 側のコネクタ設定**で管理される。
そのため本保管庫に `.mcp.json` は置いていない。

連携の追加・削除は Claude の設定画面から行うこと。
`settings.local.json` に残る `mcp__` で始まる記述は、過去に個別許可した際の記録であり、
サーバーの定義そのものではない。
