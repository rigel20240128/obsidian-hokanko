# 提灯昇降モジュール — 開発物の所在

作成日：2026-08-20

## 概要

引掛シーリングに挿すだけで、和紙提灯をスマートフォンから昇降させ、
ゆらぎ点灯を制御できるモジュール。

| 項目 | 内容 |
|:--|:--|
| 目標原価 | 3万円以下（部品費 約1.5万円で試算済み） |
| 想定売価 | 8万円 |
| MCU | ESP32-WROOM-32 |
| 開発環境 | PlatformIO + Arduino framework |

## ソースコードの所在

**`C:\Users\RIGEL\Documents\dev\chochin-lift-module\`**

保管庫の運用規定「削除しない・移動とリネームのみ」は本フォルダにも適用する。

## 事業判断に関わる要点（諸葛亮より上奏）

1. **PSE（電気用品安全法）**。AC100Vを直接受ける器具として販売する場合、
   届出・適合性検査・PSEマーク表示が必要になる公算が高い。
   **一次側をPSE取得済みの市販ACアダプタに外出しし、本体をDC12V入力のみとすれば
   対象から外れる公算が大きい。** 売価8万円の商品として、この設計変更を推奨する。
2. **原価の見立て**。部品費は約1.5万円で目標内に収まる。ただし組立工数・治具・
   PSE対応費・不良率・梱包送料は未計上。売価8万円の妥当性はこれらを積んで再検証が要る。
3. **落下に対する製品責任**。天井から可動物を吊る。想定重量の4倍での静荷重試験と、
   昇降1万回の耐久試験の記録を残すこと。
4. **未実装**。エンコーダによる位置検出と、電流センシングによる過負荷検知は
   現行版に無い。「途中でワイヤーが引っ掛かった」ことは60秒のタイムアウトでしか
   検出できない。商品化前の追加を推奨する。
