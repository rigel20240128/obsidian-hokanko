## 2. 電源トポロジ — **要ご裁可（本書の最重要事項）**

RIGEL標準は「PSE認証済み外付けACアダプタ、機器内にAC一次側を持ち込まない」である。
**しかし本製品では、それが商品コンセプトと両立しない。**
引掛シーリングは天井の照明用ローゼットであり、そこから給電する限り
AC100Vは必ず機器内に入る。ゆえに構成を選ばねばならない。

### 構成A：AC内蔵（引掛シーリング直結）

```
引掛シーリング ──[プラグ]── 本体（内部にAC-DC 12V/2A）
```

| | |
|:--|:--|
| 商品性 | **◎** 「挿すだけ」が成立する。天井まわりに余計な物が出ない |
| 設置 | **◎** 購入者が自分で取り付けられる（プラグ抜き差しは資格不要） |
| 法対応 | **×** AC100Vを直接受けるため**PSE届出＋適合性検査が必要**。費用・期間を要する |
| 一次側設計 | 沿面6.4mm以上、UL94 V-0筐体、ヒューズ、絶縁距離の作り込みが要る |
| 重量 | AC-DC基板 約150g が本体に載る |

### 構成B：DC入力（ACアダプタ外付け）

```
引掛シーリング ──[コンセント変換アダプタ]── 市販PSE認証ACアダプタ ── DC12V ── 本体
```

| | |
|:--|:--|
| 商品性 | **△** 天井に変換アダプタとACアダプタが露出し、コードが垂れる |
| 設置 | ○ 資格不要のまま |
| 法対応 | **◎** 本体はDC機器。PSEの対象から外れる公算が大きい |
| 一次側設計 | 不要。開発工数と部品点数が減る |
| 重量 | 本体が約150g軽くなる |

### 諸葛亮の推奨

**構成Aを推奨する。** 理由は3点。

1. 本製品の価値は「**引掛シーリングに挿すだけ**」の一点に集約されている。
   天井にアダプタとコードが垂れた時点で、和の意匠を売る商品として成立しない。
   売価8万円は、その体験に対する値である。
2. PSE（特定電気用品以外）の届出・自主検査は、**1機種あたり数十万円規模**で見込める。
   売価8万円・想定100台なら総売上800万円。吸収できない額ではない。
3. 構成Bで妥協した外観は、あとから構成Aへ戻せない（商品としての印象が先に決まる）。

**ただしこれは事業判断であり、当職が決めることではない。**
費用の実額と期間は、`agy`（Gemini）へ検証を委ねたうえで改めて上奏する
（帝国ルール 基本方針⑤：制度・法務はClaudeの知識が古い恐れがある）。

**以降の記述は構成Aを前提とする。** 構成Bを採る場合、U2からAC-DC部を除き、
U1を「引掛シーリング→コンセント変換アダプタ」に置き換える。他は変わらない。

## 4. インターフェース定義

| 経路 | 信号 | 電線 | コネクタ |
|:--|:--|:--|:--|
| U1 → U2a | AC100V L/N | AWG18・**圧着＋絶縁被覆** | 直結（抜けない処理） |
| U2a → U3 | DC12V | AWG20 | XT30 |
| U3b → U4 | モーター駆動 | AWG20 ＋ **端子間0.1µF** | 2P端子台 |
| U6 → U3a | リミット信号 ×2 | **シールド2芯・片端のみ接地** | JST-XH 3P |
| U3a → U7 | ゲート信号 | AWG24 ＋ 100Ω直列 | — |
| U7 → U8 | DC5V（LED給電） | AWG22 | 2P端子台 |
| U8 → U11 | DC5V | 導電性ワイヤー2条 | 圧着端子 |
| （荷重） | — | **ステンレスφ0.6mm以上 or ケブラー** | 別系統。給電線に荷重を負担させない |

## 5. 電源容量収支

| 負荷 | 電圧 | 定常 | ピーク |
|:--|:--|--:|--:|
| ギアードモーター（提灯吊上げ時） | 12V | 0.4 A | — |
| ギアードモーター（拘束時） | 12V | — | 1.5 A |
| ESP32（Wi-Fi送信ピーク） | 5V | 0.12 A | 0.35 A |
| ゆらぎLEDモジュール | 5V | 0.15 A | 0.15 A |
| **12V換算 合計** | | **約0.65 A** | **約1.75 A** |

**選定：AC-DC 12V / 2A（24W）。** 拘束電流とWi-Fiピークが重なっても余裕がある。
DC-DCは 5V / 2A。ここを1A品にすると、モーター起動時にESP32がブラウンアウトする。
