# 個人負担費用・取得資産表

金額は `資産譲渡台帳.xlsx` の値をそのまま転記した。**本書の金額が変わる場合は台帳を先に直す。**
設立予定は2026年11月下旬（日付未確定）、資本金300万円、発起人は代表者1名。

## 3. 運営経費として支払いを法人へ切り替える項目

次の6項目は、法人への精算ではなく**運営経費**として扱い、法人設立後は支払いを法人に切り替える（2026-09-19の指示）。
- **レンタルサーバー・KOIL・J-SPORTS**：法人カード払いに変更する。
- **ガソリン代**：ENEOSカード（エネキーなど）で精算し、個人利用とは分けて使う。請求は**法人カードの請求書にまとめる**。
- **ETC（3台）**：ETCカードを、個人利用と法人利用で差し替えて使う。法人利用分は法人カードに付帯するETCカードで払い、請求は**法人カードの請求書にまとめる**。
- **古民家の家賃**：カードではなく、これまでどおり手動で振り込む。利用口座だけを個人口座から法人口座に変更する。

**支払いの原則**：法人カードの請求書に、レンタルサーバー・KOIL・J-SPORTS・ガソリン代・ETC代をまとめ、合計して1回で支払う。引き落とし口座は法人口座とする。

ただし、エネキーはENEOSカードに紐づくため、ガソリン代が法人カードの請求書に載るかどうかは、法人カードの発行元とENEOSに確認が必要。載らない場合は、法人名義のENEOSカードを法人口座からの引き落としで使い、請求は別に届く形になる。

法人口座・法人カードは、法人設立後に京葉銀行で開設・作成する。口座ができるまでは、設立日以降の分も個人の口座・カードで払うことになる点に注意。

| 項目 | 現時点で分かっていること | 切り替え時の確認事項 |
|---|---|---|
| お名前.com レンタルサーバー（契約番号2459867） | 2026.10.31まで契約を継続する方針。11月からお名前メールへ切替予定 | 月額・年額。契約名義と支払方法を法人に変更できるか |
| 古民家（倉庫・メンテナンス作業場）の家賃 | 個人名義で賃借。家賃は2か月ごとに手動で振込。運営固定費台帳では家賃50,000円（月額） | **法人口座から手動で振込**（カード払いにはしない）。契約名義を個人のままにするか法人へ変更するか、大家の承諾。振込明細・領収書の宛名を法人にできるか |
| KOIL柏の葉の初期費用 | 月額は使い放題プラン19,800円（税込）、法人登記オプション5,500円、駐車場13,000円 | 入会金・保証金などの金額、カード払いの可否、登記オプションと駐車場の税区分 |
| J-SPORTS | 月額1,980円。情報収集用 | 法人カードへ変更。事業関連性の説明を摘要に残す |
| ETC（3台） | 3台分。個人利用と法人利用でカードを差し替えて使う | 法人カードに付帯するETCカードを3枚発行できるか、年会費。請求が法人カードにまとまること。個人用カードと取り違えない運用（業務で使うときだけ法人用に差し替え、利用日を記録） |
| ガソリン代（ENEOSカード・エネキーなど） | ENEOSカードで精算する。個人利用とは分けて使う | 法人カードの請求書にまとめられるか（エネキーの支払い元を法人カードにできるか、または法人カードで直接給油する）。不可なら、法人名義のENEOSカードを法人口座引き落としで併用 |

ETCとガソリン代は、デミオとプラドが法人へ譲渡されない車両のため、私用分と混ざらないようにする。業務で使った分だけを経費にし、プラドは業務使用30%の按分方針に合わせて給油・通行の記録を分ける。
台帳に含まれていないその他の項目（会計ソフト、携帯電話、保険など）も、洗い出して同じ扱いにするか決める。
ITソフトウェア費用（Claude Code、Google AI Plus、3D CAD iCAD SX）は、2026-08-20の指示により法人の計上経費に含めない。

## 4. 論点（税理士と確認する事項）

1. **譲渡のタイミング**：法人が成立する前には売買できない。設立時に現物出資・財産引受にするか、設立後に売買するかで、手続きと税の扱いが変わる。
   - 設立後の売買は、会社法の「事後設立」に当たる。設立後2年以内に、成立前から持つ財産を、純資産の5分の1（資本金300万円なら約60万円）を超える対価で取得する場合、株主総会の特別決議が必要（株主が代表者1名なら議事録で足りる）。譲渡代金2,042,500円はこれを超える。
   - 設立後に譲渡する場合、譲渡日が第1期に入るか第2期以降になるかで、法人側の減価償却や少額資産（30万円未満）の経費化が入る事業年度が変わる。決算月・設立日と一緒に決める。
   - 車両は、自動車税の課税対象が4月1日時点の所有者になるため、名義変更の時期で当年度の負担が変わる。
2. **資金への影響**：譲渡代金の合計2,042,500円に対し、資本金は300万円。全額を現金で支払うと、資本金の手元残は957,500円になる。次の選択肢を比較する。
   - 一括で支払う
   - 未払金として分割で精算する（融資実行後に支払うなど）
   - 現物出資として資本金に充てる（総額500万円以下なら検査役の調査は不要。定款への記載が必要）
3. **譲渡価格の根拠**：適正な時価で売買する。取得時の領収書・請求書を保管し、中古価格の根拠（購入時の価格、査定など）を残す。台帳ではPC（Victus15）のみ取得額の75%で計上している。
4. **車両**：譲渡するのはフィットシャトルハイブリッド1台のみ。運輸支局での名義変更、自動車保険の名義、車庫証明（KOILの駐車場）が必要。デミオとプラドは法人へ譲渡しない。プラドは業務使用30%の按分で利用する方針。
5. **減価償却と少額資産**：ロボット（JR3203は1台100,000円）は、中小企業者の少額減価償却資産の特例（30万円未満）の対象になる可能性がある。中古資産の耐用年数の扱いとあわせて確認する。
6. **消費税**：個人（免税事業者）からの購入は、法人が課税事業者になった場合でも仕入税額控除の対象にならない。資本金300万円なら設立第1期は原則免税の見込みで、影響は小さい。
7. **法人カード**：京葉銀行の法人口座開設には審査で数週間かかることがある。カードの種類・審査条件・発行までの日数を、口座開設の相談時にあわせて確認する。
