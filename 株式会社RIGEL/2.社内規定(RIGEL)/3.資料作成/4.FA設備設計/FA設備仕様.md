# FA設備仕様スキル

FA設備設計事業（②）における設備構想資料・仕様書・見積資料作成、設計チェックの基準をまとめたスキル。
**本スキルの管理・運用・更新は趙雲（FA設計AI）が担当する**（[[AIエージェント組織表]] 参照）。設計基準の追加・改訂は趙雲が随時行い、更新時は本ファイル末尾の改訂履歴に追記すること。

## 使い方（プロンプト例）

> FA設備の仕様書・構想資料を作って。〇〇工程用の卓上ロボット設備、JANOME系機材、対象ワークは△△。
> 本スキルの設計必須項目・仕様書構成に沿って作成して。

- 安全性
- 強度
- 剛性
- 耐久性
- 加工性
- 組立性
- 調整性
- 保守性
- 標準化
- 部品共通化
- コスト
- 納期
- 拡張性

差別化ポイントとして、机上の設計に留めず以下も常に検討する：
- 加工性・組立性・調整性・保守性・耐久性・安全性を踏まえた現場目線の設計
- 実際に製作できるか、量産できるか、メンテナンスできるか

## 標準設備構成

RIGELのFA生産設備は、基本的に以下の構成要素を組み合わせて設計する。標準構成をベースに、対象ワーク・工程に応じて構成要素の追加・置換を検討する（例：画像検査ユニット、コンベア、センサ類の追加等）。

### ① 架台（アルミフレーム）

- 基本方針：MISUMIのアルミフレームをベースとし、溶接構造は極力避けて**ボルト組立式**とする（現地レイアウト変更・追加工程への対応力を優先）
- フレームサイズは想定荷重・スパン・振動要因（ロボット動作時の反力等）から選定し、過剰スペックによるコスト増を避ける
- 天板・取付ブラケット類も可能な限り標準品（MISUMI規格）で構成し、特注部品を最小化する
- 保守性の観点から、配線・配管はフレーム内側またはケーブルダクトでまとめ、点検口を確保する

### ② 駆動軸（単軸アクチュエータ）

- 主用途：ワークの搬送・位置決め（ロボット可動域外への送り出し、ストッパ位置決め等）
- 選定基準：ストローク、可搬重量、要求タクトタイムから必要推力・最高速度を算出し、余裕率を持たせて機種選定する
- 駆動方式（ボールねじ／ベルト／ロッドレス等）は、要求精度・ストローク長・コストのバランスで選定する
- IAI等、ロボット本体と親和性の高いメーカーの単軸を優先し、コントローラ・ケーブル類の共通化を図る

### ③ ロボット（卓上ロボット）

- JANOME卓上ロボット（JR3000シリーズ等）を主軸とし、組立・塗布・検査・ネジ締め等の工程に適用
- 選定基準：可搬重量、動作範囲（X/Y/Z）、繰り返し精度、タクトタイム要求から機種を選定
- カメラ・塗布ユニット等のオプション要否は、工程内容（位置補正の要否、塗布/接着剤工程の有無）に応じて検討する
- 垂直多関節ロボットは対象外とし、卓上・直交・SCARAの3カテゴリで完結する設計を基本とする（[[RTS競合調査報告書]] 参照）

### ④ 空圧機器（シリンダ）

- 主用途：位置決め、クランプ（ワーク固定）、押し出し・排出
- 選定基準：必要推力（負荷・摩擦・安全率）からシリンダ径を選定し、ストロークは動作範囲に必要十分な長さとする（過大ストロークは座屈・たわみリスクを増やす）
- 動作方式は基本を**複動式**とし、単純な押し出し等の用途に限り単動式を検討する
- 速度調整はスピードコントローラで行い、急速動作による衝撃・振動を抑える

### ⑤ 制御機器（電磁弁：SMC）

- SMC製電磁弁を標準とし、シリンダ・空圧回路の制御を担う
- 弁種（3ポート／5ポート、シングル／ダブルソレノイド）は、シリンダの動作方式（複動／単動）・保持要否に応じて選定する
- マニホールド化により配管・配線をまとめ、保守性・省スペース性を確保する
- 非常停止時は空圧回路を大気開放（排気）する構成を基本とし、意図しない再起動動作を防止する

### 制御信号フローの基本形

```
PLC（KEYENCE／三菱電機）
  ├─ 電磁弁（SMC）→ シリンダ／単軸アクチュエータ
  ├─ ロボットコントローラ（JANOME）→ 卓上ロボット
  └─ センサ・画像処理（KEYENCE／Panasonic PV200）→ 位置・良否判定
```

ロボット動作と単軸・シリンダ動作は、干渉防止のため必ずインターロック（動作範囲の排他制御）を組み込む。

### 安全対策（本構成における具体項目）

- シリンダ・単軸の可動範囲には安全カバー・光電センサ等の侵入検知を設置する
- 非常停止時は電磁弁を介して空圧回路を排気し、シリンダ・単軸を無負荷状態にする
- ロボット動作エリアと作業者アクセスエリアを物理的に分離する
- エアの元圧遮断・残圧排気手順を保守マニュアルに明記する
