## 4. この文面の狙い（社内向けの注記・送信時は不要）

| 仕掛け | 狙い |
|---|---|
| **「要整備品・不動品も引き取る」を前面に出した** | 業者にとって**処分に困る個体を引き取る相手**は貴重。優先的に声がかかる。かつRTSの教育思想「"壊す→直す"を教材にする」と完全に一致しており、嘘がない |
| **「外観の程度は問わない」** | 値引き交渉の余地が生まれる |
| **ペンダント単体でも可と明記** | ペンダントは元々オプションで新品約5万円。**本体なしの余り品**が業者に眠っている可能性がある |
| **JR4000を明確に除外** | 誤った提案を受けて手間が増えるのを防ぐ（教材が JR C-Points Ⅱ のため使い回せない） |
| **22年の経歴と設計500件を添えた** | 冷やかしでないことを示す。業者は本気度で対応を変える |
| **法人未設立を隠さない** | 隠して後で発覚する方が損。設立予定日を明記して信用を得る |
