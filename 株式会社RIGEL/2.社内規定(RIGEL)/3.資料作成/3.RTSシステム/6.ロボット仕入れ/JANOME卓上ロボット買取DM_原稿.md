[[勅命_中古ロボット安定供給]] の **第二段／第三段「産廃・解体業者ルート」** における、

## 1. 紙面の狙い（v1.1で確定）

> **売り込みではなく、覚えてもらうための紙である。**

この紙面が果たすべき仕事は次の2つに限る。

1. **JANOME製卓上ロボットを認識してもらう** — 相手はFA機器の知識を持たない。「どんな見た目で、どこに型番が書いてあるか」が伝わらなければ、そもそも連絡は来ない
2. **継続的に買い受けたいという意思を、誠実に伝える** — 一回の買い叩きではなく、年間10〜20台を継続してお願いしたい取引先であることを最初に述べる

そのため紙面は**煽らない**。「至急」「買取強化中」「鉄くずにする前に」といった強い訴求は使わず、
**探しております／お願いしたい**という語調で通す。相手は日々DMを受け取っており、
強い文句は「また買取業者か」と読み飛ばされる。落ち着いた紙面のほうが、結果として残る。

> **v1.0からの変更（2026-08-29）**：見出しを「その机の上の機械、鉄くずにする前にご一報ください。」から
> 「JANOME（ジャノメ）製の卓上ロボットを探しております。」へ改めた。あわせて煽りの語を全廃し、
> 「3つの理由（メリット訴求）」を「お願いしたいこと」に、写真と見分け方を紙面の先頭へ移した。

## 3. 紙面の構成と、そう作った理由

上から読んだときに「**何を探しているか → どんな機械か → 対象機種 → お願いしたいこと → 連絡先**」の順になる。

| 部位 | 内容 | 根拠 |
|---|---|---|
| 見出し帯 | 「JANOME（ジャノメ）製の卓上ロボットを探しております。」＋ 用途（技術者教育用レンタル設備）＋ **年間10〜20台を継続して** | 何者が、何のために、どれくらい必要としているかを最初に述べる。用途を隠さないことが誠実さの担保になる。台数は [[勅命_中古ロボット安定供給]] の年間最大20台に拠る |
| 探しておりますのは、この機械です | **写真枠を紙面の先頭・左に配置**＋見分け方3点（①門型の小型ロボット ②銘板の「JR」 ③重量20〜48kg・ペンダント不要） | 本紙の第一の仕事は認識してもらうこと。相手はFA機器の知識を持たない。**見分けられなければ連絡は来ない** |
| 対象となる機種 | JR3000系10機種を「サイズ級×軸数」の表で提示 | 型番の読み方（[[JANOME機種理解メモ]] 1章）をそのまま表にした。**「頭がJR3なら対象」**と言い切れば現場で照合できる |
| 他世代・周辺機器／装置ごとでも可 | JR2000・JR4000、ペンダント・ケーブル等のみ、装置に組み込まれたまま | 卓上型は装置に組み込まれたままスクラップにされる（[[評定議事録_中古ロボット調達ルート]]）。ここを拾えないと機体が消える |
| お願いしたいこと① | お写真を2枚お送りください。当日中に金額を回答 | 相手の手間を最小にする。**メリットの列挙ではなく「お願い」として書く** |
| お願いしたいこと② | 動かない機体でも構いません（理由：代表がFA設備設計歴20年で、弊社で整備し直せるため） | 「直せる故障品を買う」という戦略の指定（[[勅命_中古ロボット安定供給]]）。**理由まで書くから信じてもらえる** |
| お願いしたいこと③ | お引き取りは弊社で手配。鉄スクラップより高い金額 | 20〜48kgの重量物で運搬は相手の障害（[[JANOME機種理解メモ]] 2章）。価格の優位はここで一度だけ、静かに述べる |
| 注記（有価物の売買） | 売買契約書・受領書を発行する旨を明記 | 産廃業者が最も気にする廃棄物処理法上の扱いへの回答（[[評定議事録_中古ロボット調達ルート]] 麋竺の指摘） |
| 注記（商標） | JANOMEは蛇の目ミシン工業株式会社の登録商標である旨と、無関係である旨 | 他社名を冠したDMのため、関係会社と誤認させない |
| ご連絡票（FAX返信用） | 同一用紙の下半分。切り取り線つき。「売却の義務はございません」と明記 | 1枚で完結させ、FAX送信費と返信の手間を最小にする。**査定のみ・情報提供のみの連絡も歓迎**と書くことで返信の敷居を下げる |

### 意図的に**載せなかった**もの

- **強い訴求語**：「至急」「高価買取」「買取強化中」「鉄くずにする前に」。上記1のとおり
- **番号付きの「01/02/03」**：3つの「お願い」は手順ではなく並列。順序を持たないものに番号を振らない
- **買取価格**：上限10万円は社内の戦略値であり（[[勅命_中古ロボット安定供給]]）、紙面に出すと相手の基準額になる
- **実機イラスト**：[[RIGEL資料作成ルール_統合版]] 2.4⑤「実在メーカーのロゴ・型番・意匠を図中に描かない」に従い、作図せず**写真の差し込み枠**とした

## 4. 書式（RIGEL資料作成ルール準拠）

| 規定 | 適用 |
|---|---|
| 0.3 用紙 | A4縦（`@page{size:A4 portrait}`）。PRカタログは縦 |

| 1.4 書体 | Noto Sans JP（フォールバック：Yu Gothic / Hiragino Sans / Meiryo） |
| 2.1 禁止事項 | 影・3D・グラデーション・ストックフォト・装飾図形は不使用 |
| 著作権表示 | 1枚物のため最下部に `Copyright © 2026 株式会社RIGEL All Rights Reserved.` |

> **4.4（問い合わせ欄は会社名・HP・メールの3項目のみ）は本紙に適用していない。**
> 同項の対象は「プレゼン・提案資料」であり、本紙は**FAX返信を受けることが目的のDM**であるため、
> 電話番号・FAX番号・担当者名が無ければ紙面が機能しない。ご確認いただきたい。

### FAX送信への配慮

FAXは白黒2値・低解像度で潰れる。次を守っている。
- 本文は **8pt以上**、記入欄の罫線間隔は **6mm以上**（手書きできる高さ）
- 濃色は塗りつぶし＋白抜き文字とし、細い網掛け・淡いグレー文字を使わない
- チェックボックスは3.2mm角の実線

## 5. 出力手順（PDF化）

[[RIGEL資料作成ルール_統合版]] 3.2 に従う。

```
msedge --headless=new --print-to-pdf="JANOME卓上ロボット買取DM.pdf" --no-pdf-header-footer "JANOME卓上ロボット買取DM(解体・産廃業者向け).html"
```

- 生成されたPDFは Downloads フォルダと本フォルダの両方に残す
- ブラウザから印刷する場合は、**余白「なし」・背景グラフィックあり** を指定する（濃色帯が白く抜けるのを防ぐ）
- 単一HTMLで完結している（ロゴはbase64埋め込み）ため、そのままメール添付でも配布できる
- **A4縦1枚に収まることを確認済み**（Chromiumで検証、余白約9mm）。写真を差し込む際は写真枠の高さ（20mm）を変えないこと。広げると2枚目に溢れる
