## 1. 配布前に必ず確認すること

> [!warning] 配布は古物商許可の取得後とする
> [[勅命_中古ロボット安定供給]]「上申の義務」に **「古物商許可の取得完了までは、買取の実行を一切行わない」** と定めがある。
> 本DMは「買い取ります」と明示的に勧誘する紙面であるため、**許可取得前の配布は行わない。**
> - 古物商許可：法人登記後に申請（2026年11月中旬以降）・取得は2027年初頭見込み（[[会社概要(外部提出用)]]）
> - 社名「株式会社RIGEL」も設立登記（2026年11月予定）後でなければ名乗れない
>
> **許可取得前に接触したい場合は、本DMではなく「情報提供のお願い（買取の勧誘を含まない版）」を別途起こすこと。**
> 接触・関係構築・情報収集そのものは許可を要さない。

## 2. 紙面の構成と、そう作った理由

| 部位 | 内容 | 根拠 |
|---|---|---|
| 見出し | 「その机の上の機械、**鉄くずにする前に**ご一報ください。」 | 相手は卓上ロボットを「机の上の謎の機械」と認識している（[[黄忠_JANOME中古ロボット調達プロジェクト_基本プロンプト]]）。まず**捨てる直前で止める**ことが紙面の唯一の仕事 |
| 買取対象機種（表） | JR3000系10機種を「サイズ級×軸数」の表で提示 | 型番の読み方（[[JANOME機種理解メモ]] 1章）をそのまま表にした。**「頭がJR3なら対象」**と言い切れば、現場は型番を照合できる |
| 現場での見分け方 | ①門型の小型ロボット ②銘板の「JR」 ③重量20〜48kg・ペンダント不要 | 相手はFA機器の知識を持たない。**見分けられなければ電話は来ない** |
| 理由01 | 動作未確認・ジャンク・欠品のままで可 | 「直せる故障品を買う」という戦略の指定（[[勅命_中古ロボット安定供給]]）。**動かない機体を買うと言えるのはRIGELだけ**という唯一の差別化点なので、最も大きく置いた |
| 理由02 | スマホ写真1枚で即日回答 | 現場の手間をゼロにする |
| 理由03 | 即金・引き取り手配はRIGEL負担 | 20〜48kgの重量物で、運搬は相手にとって障害になる（[[JANOME機種理解メモ]] 2章） |
| 「装置に組込のままで可」 | 対象機種欄と返信用紙の両方に明記 | 卓上型は装置に組み込まれたままスクラップにされる（[[評定議事録_中古ロボット調達ルート]]）。ここを拾えないと機体が消える |
| 注記（有価物の売買） | 売買契約書・受領書を発行する旨を明記 | 産廃業者が最も気にする廃棄物処理法上の扱いへの回答（[[評定議事録_中古ロボット調達ルート]] 麋竺の指摘） |
| 注記（商標） | JANOMEは蛇の目ミシン工業株式会社の登録商標である旨と、無関係である旨 | 他社名を冠したDMのため、関係会社と誤認させない |
| FAX返信用紙 | 同一用紙の下半分。切り取り線つき | 1枚で完結させ、FAX送信費・返信の手間を最小にする |

### 意図的に**載せなかった**もの

- **買取価格**：上限10万円は社内の戦略値であり（[[勅命_中古ロボット安定供給]]）、紙面に出すと相手の基準額になる。「スクラップ単価を上回る金額」とだけ書いた
- **実機イラスト**：[[RIGEL資料作成ルール_統合版]] 2.4⑤「実在メーカーのロゴ・型番・意匠を図中に描かない」に従い、作図せず**写真の差し込み枠**とした

## 3. 書式（RIGEL資料作成ルール準拠）

| 規定 | 適用 |
|---|---|
| 0.3 用紙 | A4縦（`@page{size:A4 portrait}`）。PRカタログは縦 |
| 1.1 ロゴ | 縦用紙のため**左上**。高さ15.5mm（下限15mm・幅28mmを充足）、原本 `RIGEL_logo.png` をbase64で埋め込み |
| 1.3 配色 | `#026881` / `#014B5D` / `#74ACBA` / `#C7CBD3` / `#17181A` / `#6B6E73` / `#E3E1DB` / `#F7F6F3`。`#E8622C` は見出しの下線1箇所のみ |
| 1.4 書体 | Noto Sans JP（フォールバック：Yu Gothic / Hiragino Sans / Meiryo） |
| 2.1 禁止事項 | 影・3D・グラデーション・ストックフォト・装飾図形は不使用 |
| 著作権表示 | 1枚物のため最下部に `Copyright © 2026 株式会社RIGEL All Rights Reserved.` |

> **4.4（問い合わせ欄は会社名・HP・メールの3項目のみ）は本紙に適用していない。**
> 同項の対象は「プレゼン・提案資料」であり、本紙は**FAX返信を受けることが目的のDM**であるため、
> 電話番号・FAX番号・担当者名が無ければ紙面が機能しない。ご確認いただきたい。

### FAX送信への配慮

FAXは白黒2値・低解像度で潰れる。次を守っている。
- 本文は **8pt以上**、記入欄の罫線間隔は **6.4mm以上**（手書きできる高さ）
- 濃色は塗りつぶし＋白抜き文字とし、細い網掛け・淡いグレー文字を使わない
- チェックボックスは3.2mm角の実線

## 4. 出力手順（PDF化）

[[RIGEL資料作成ルール_統合版]] 3.2 に従う。

```
msedge --headless=new --print-to-pdf="JANOME卓上ロボット買取DM.pdf" --no-pdf-header-footer "JANOME卓上ロボット買取DM(解体・産廃業者向け).html"
```

- 生成されたPDFは Downloads フォルダと本フォルダの両方に残す
- ブラウザから印刷する場合は、**余白「なし」・背景グラフィックあり** を指定する（濃色帯が白く抜けるのを防ぐ）
- 単一HTMLで完結している（ロゴはbase64埋め込み）ため、そのままメール添付でも配布できる
