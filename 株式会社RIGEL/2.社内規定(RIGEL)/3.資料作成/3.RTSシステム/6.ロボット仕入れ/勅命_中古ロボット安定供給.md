# 📜 勅命：JANOME中古ロボットの安定供給ルート構築

## 勅命の要旨

**後将軍・黄忠に命ず。RTS事業の生命線である JANOME製卓上ロボットの、継続的かつ安価な調達ルートを構築せよ。**

## 任務の位置づけ

RTS事業は**ロボット本体を資産として保有し、レンタル収益を積み上げる**モデルである。したがって**調達力がそのまま事業の成長上限を決める**。営業がいかに顧客を獲得しようとも、貸し出す機体がなければ売上は立たない。

本任務は単なる購買業務ではない。**「必要になった時に、適正価格で入手できる状態を常時維持すること」**——すなわち蛇口を作ることが本質である。

## なぜ黄忠か

③FA設備営業代行事業の定義そのものが「**FA業界で築いた人脈を活かす**」ことであり、本任務もまた同じ資産を源泉とする。

- 20年間のFA設備設計（株式会社サンエイテック・課長／3D機械設計・FA設備・ロボットシステム分野）で築いた**取引先・協力会社・OB筋の人脈**
- 「どの工場のどこにJANOMEが置かれているか」を想像できる**現場の土地勘**
- 若手（関羽の几帳面さ、張飛の勢い、馬超の新技術志向）が構造的に持ち得ない**時間の蓄積**

**この任務は、年の功でしか遂行できない。**

## 確定条件（陛下ご指示 2026-08-04）

| 項目 | 内容 |
|---|---|
| **目的** | **レンタル用の自社資産として保有する（転売しない）** |
| **年間予算** | **200万円** |
| **年間台数** | **最大20台**（部品取り機を含む） |
| **1台単価** | **10万円は固定上限ではない。状態により変動可**（＝年間平均10万円の運用） |
| **部品取り機** | **購入可**（ニコイチ運用） |
| **再生費用** | 別枠 |
| **古物商許可** | 2026年8月中に申請・取得予定 |
| **現状の課題** | ネットオークションで探しても見つからない |
| **入手できぬ場合** | **新品購入（200〜300万円/台）** となり、投資回収が20〜30ヶ月に伸びる |
| **前職の取引先** | **可能なら積極的にコンタクトし、不要ロボットの買取を進める** |

## 戦略の核心

> **上限10万円は制約ではなく、戦略の指定である。**
> 「動く中古品を買う」のではなく「**直せる故障品を買う**」。

陛下は20年の設計者（FA設備・ロボットシステム）であり、動かない機体を診て直せる。
FA中古業者は動作確認して売るのが商売ゆえ、**直せない機体は仕入れないし、仕入れても捨てる**。

**「動かないJANOMEでも買います」と言えるのは、この業界でRIGELだけである。**
業者にとってジャンクは処分に困る在庫であり、それを引き取る客は競合ではない。

## 達成目標

| 区分 | 内容 |
|---|---|
| **主目標** | **業者の在庫に直接触れる状態を作ること**（在庫リスト配信網への参入、古物市場への参加） |
| **副目標** | 動作不良品の再生ルート確立（趙雲と連携。ニコイチ運用を含む） |
| **禁止事項** | **上限10万円を超える買取**。台数を稼ぐための高値掴み。**安く買えないなら買わない** |

## 上申の義務

- 買取の実行前に、必ず諸葛亮の精査と**陛下のご承認**を得ること
- 古物商許可の取得完了までは、**買取の実行を一切行わない**（接触・関係構築・情報収集は可）
- 月次で進捗を諸葛亮へ報告し、劉備を通じて上奏すること
