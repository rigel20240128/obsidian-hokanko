# 第2章：ロボット単体動作

## 2.1 RTSのロボット構成

RTSで使うのは **3軸ロボット**で、**X（横）・Y（奥行）・Z（上下）** の直線3方向に動く。いわゆる**直動ロボット（直交ロボット）**である。

**このロボットの最大のメリットは、非常に安全であることである。**

**【追記】なぜ安全と言えるのか**

| 理由 | 説明 |
|---|---|
| 動作範囲が予測できる | 直線軸の組合せなので、動作範囲が**直方体**になる。どこまで動くかが見た目で分かる |
| 動きが単純 | 各軸が独立して直線移動するだけで、腕が回り込んでくるような動きをしない |
| 小型・低出力 | 可搬質量が小さく、モーター出力が小さい |

>
※イラスト挿入（RTS装置の正面図とX・Y・Z軸の方向。軸ごとに矢印で動作方向を示す）

## 2.2 ロボットの事を知る

※イラスト挿入（直動・スカラ・多関節ロボットの比較図。3体を横並びで描き、動作範囲を破線で示す）


|         | **卓上ロボット**                             | **直交ロボット**                                   | **多関節ロボット**                      |     |
| ------- | -------------------------------------- | -------------------------------------------- | -------------------------------- | --- |
| 構造      | X軸とY+Z軸の2パターン組合せ                       | 直線軸（X・Y・Z）の組合せ                               | 回転関節を複数直列に繋いだ腕型                  |     |

| 得意なこと   | 持ち運びが容易で作業性が高い                         | 位置決め精度が高い。剛性が高く**押し込む力に強い**。ピック＆プレース、塗布、ねじ締め | 姿勢を自由に変えられる。**斜めからのアプローチ**、溶接、塗装 |     |

> **なぜRTSは直動ロボットを主軸にするのか**：①安全 ②座標が直感的で初学者が挫折しにくい ③剛性が高く、多少乱暴に扱っても壊れにくい ④中古市場での調達性が良い。**教育設備として合理的だから**であり、多関節が優れていないという意味ではない。

## 2.3 サンプルプログラム1番を動かす

サンプルプログラム **1番** で、以下の3つを学ぶ。

※イラスト挿入（操作パネル配置図：スタートスイッチ・非常停止・原点復帰の各ボタンの位置と形状）

### ① スタートスイッチ( A接点)

- 1回目のスタートボタンでメカ初期化を実行、2回目のスタートボタンで動作開始
  　→ 2回目以降は原点復帰後に動作開始
  　→ 非常停止を行った場合は、メカ初期化から再始動が必要


### ② 非常停止( B接点)

- 緊急事態の時に使用（電源を遮断してロボットを停止させます）
- **押すと「ロック」される**（押しボタンが引っ込んだまま戻らない）。解除は**回して引き上げる**
  - 【追記】**非常停止を解除しただけでは動き出さない。**解除後に改めて原点復帰・起動操作が必要になる。これは意図しない突然の再起動を防ぐための設計である

### ③ メカ初期化

**【追記】なぜ電源投入のたびにメカ初期化が必要なのか**

ロボットは「今どこにいるか」をエンコーダという部品で数えている。エンコーダには2種類ある。

| 種類                | 特徴               | 原点復帰                |
| ----------------- | ---------------- | ------------------- |
| **インクリメンタル型**     | 電源が切れると位置の記憶が消える | **電源投入のたびに必要** ※RTS |
| **アブソリュート（絶対値）型** | バッテリー等で位置を保持し続ける | 原則不要（バッテリー切れ時は必要）   |

つまりメカ初期化とは、**「機械の基準点まで一度動かして、そこを0番地と決め直す作業」**である。これをしないと、プログラムが指定した座標と実際の位置がずれる。


## 2.4 この章の用語
- **A接点（NO＝ノーマルオープン）**：ふだん開いていて、押すと閉じる接点
- **B接点（NC＝ノーマルクローズ）**：ふだん閉じていて、押すと開く接点
- **可搬重量**：そのロボットが搬送可能な重さの上限 ※JR3203は最大10kg

# 第3章：ロボット操作基礎（センサーの基礎知識）

今あるセンサーがどういう種類で、どういうことに使われているかを、ドキュメントを見て理解を深める。**A接点、B接点、ライトオン、ダークオン、PNP、NPN、センサーの種類・役目**について学ぶ。

## 3.1 Q&A（考えてから読む）

### Q1. どうしてスタートスイッチはA接点、非常停止はB接点なのか

**A.** 設備では「**fail safe（フェイルセーフ）**」という考え方がある。※「故障は安全な側に」というのが原則である

- **スタートスイッチ（A接点）**：断線しても「動かないだけ」で済む
- **非常停止（B接点）**：**断線したら回路が切れる＝停止する**。もしA接点にしていたら、断線した非常停止ボタンを押しても信号が届かず、**止まらないという大変な事態になる**

【追記】この考え方を一般化すると、**「壊れたときに、安全な側に倒れる設計にする」**ということである。センサーの選定・回路設計・プログラムのすべてに一貫して適用される、FAで最も重要な原則である。

※イラスト挿入（A接点/B接点の回路図。通常時・押下時・断線時の3状態を並べて比較する）



### Q2. どうしてライトオン、ダークオンがあるのか

**A.** 【追記】光電センサーには、光を受けている状態でオンになる「**ライトオン（入光時ON）**」と、光が遮られた状態でオンになる「**ダークオン（遮光時ON）**」の2種類がある。

検知したい対象が「**物があるとき**」なのか「**物がないとき**」なのかによって、どちらを使うべきかが変わる。

| 使いたい検知 | 透過型センサー | 反射型センサー |
|---|---|---|
| **物があるときON** | ダークオン（物が光を遮る） | ライトオン（物が光を反射する） |
| **物がないときON** | ライトオン | ダークオン |

**選定理由はもう一つある。断線・故障時にどちらの状態になるか（フェイルセーフ）である。**
たとえば「ワークが正しく置かれていることを確認してから次工程に進む」回路では、**ワーク有りでON**になる設定にしておけば、センサーが壊れて信号が出なくなったとき、設備は「ワークが無い」と判断して**止まる側に倒れる**。逆の設定にすると、故障時に「ワーク有り」と誤認して動き続けてしまう。

※イラスト挿入（ライトオン／ダークオンの動作イメージ図。透過型センサーの投光器・受光器とワークの位置関係、および出力のON/OFFを示す）

### Q3. どうして PNP や NPN があるのか

**A.** 【追記】出力トランジスタの極性が異なる。

|        | **NPN（シンクタイプ）**            | **PNP（ソースタイプ）**            |
| ------ | -------------------------- | -------------------------- |
| 動作     | 電流を**吸い込む**                | 電流を**吐き出す**                |
| 負荷の接続先 | 負荷の反対側は **＋24V** へ         | 負荷の反対側は **0V（−）** へ        |
| 主流地域   | **日本国内**                   | **欧米**                     |
| 安全上の性質 | 信号線が地絡すると**誤ってONになる**ことがある | 信号線が地絡（フレームに触れる）しても誤動作しにくい |


> 【追記】**JANOMEのJR3000シリーズは、日本ではNPN仕様の採用が一般的。

※イラスト挿入（PNP／NPN 結線図。センサー内部の出力トランジスタ、負荷、電源の接続を2つ並べて対比する）

### Q4. どうしてセンサーには種類があるのか

**A.** 【追記】検知したい対象物の**材質・形状・周囲環境**（粉塵、水濡れ、透明物体など）によって、最適な検知方式が異なるためである。

| 検知したいもの        | 向いているセンサー                | 理由                       |
| -------------- | ------------------------ | ------------------------ |
| 色・形状の違い        | **光電センサー（カラー／レーザー）**     | 反射光の量や色を見分けられる           |
| 狭い場所・微小な物      | **ファイバーセンサー**            | 検出ヘッドが極小。アンプは離れた場所に置ける   |
| 確実な物理接触        | **マイクロスイッチ**             | 接触するまでONにならないので、確実性が最も高い |
| 金属             | **近接センサー**               | 非接触。金属だけに反応するので誤検知が少ない   |

> **本章は「何を検知したいかで選ぶ」観点で扱う。**「接触させてよいか・寿命はどうか」という観点は第6章で扱う。

※イラスト挿入（用途別センサー選定フローチャート）


### Q5. 透過式と反射式の違い

|       | **透過式センサー**        | **反射式センサー**      |
| ----- | ------------------ | ---------------- |
| 方式    | 投光部と受光部を設置する場所が異なる | 投光部と受光部が同じ       |
| 用途    | 確実に検知したい場合         | 限られたスペースで検知したい場合 |
| メリット  | 検知能力が高い            | 設置が容易            |
| デメリット | 取付場所が2か所と配線数が多い    | 取付場所が1か所と配線数が少ない |



※イラスト挿入（2芯／3芯 結線比較図）### Q5. 2芯のセンサーと3芯のセンサーがあるのはなぜか


|     | **3芯センサー**                             | **2芯センサー**                                              |
| --- | -------------------------------------- | ------------------------------------------------------- |
| 構成  | 電源（＋／−）＋ 信号線 の3本                       | 電源線と信号線を**共用**（2本）                                      |
| 接続  | 外部電源で動作しながら、出力信号を送る（アンプ内蔵型）            | 負荷（PLC入力など）と**直列**に接続し、電流のON/OFFで検知する                   |
| 利点  | 応答が速い。出力形式（PNP/NPN）を選べる。センサー単体で動作確認できる | 配線がシンプル。既存の2線式回路に置き換えやすい                                |
| 注意点 | 配線が1本増える                               | **OFF時にも微小な漏れ電流が流れる**。ON時にも**残留電圧**が生じるため、接続できる負荷に制約がある |

> 【追記】**2芯センサーの漏れ電流は実務でのトラブル源である。**漏れ電流が入力機器の「OFF電流」の規格を超えると、センサーがOFFなのに入力がONのままになる。この場合、**ブリーダ抵抗**を入れて漏れ電流を逃がす。

# 第4章：配線の基礎

実際にセンサーを取り付ける。**この章は、以降すべての章の土台になる。**配線が正しくなければ、プログラムがどれだけ正しくても設備は動かない。

## 4.1 作業の流れ

1. ワイヤーストリッパーで配線の被覆を剥く
2. **マークチューブを挿入する**（圧着より先）
3. 圧着端子を圧着工具で配線と接続する
4. 端子台に接続する
5. 結束・整線する

※イラスト挿入（ワイヤーストリッパー・マークチューブ・圧着端子の使用手順図。①〜⑤の丸数字で工程を示す）

## 4.2 ワイヤーストリッパーの注意点

### ① 太さを必ず合わせる

配線の太さ（**sq または AWG**）と、ストリッパーに刻印されている数字を合わせる。

| 合わせ方 | 起きること |
|---|---|
| **正しい穴** | 被覆だけがきれいに剥ける |
| **1つ大きい穴** | 被覆が切れずに剥けない、または被覆が伸びて残る |
| **1つ小さい穴** | **心線（銅線）に傷が付く／素線が何本か切れる** |

> ⚠️ **心線に付いた傷（ニック）は、その場では見えても切れていないので気付きにくい。**しかし断面積が減っているため、**通電するとその一点だけが発熱し、いずれ断線する。**これが実際の設備で起きると原因究明が非常に困難になる。

### ② 剥き長さを圧着端子に合わせる

- 剥き長さは、使う**圧着端子の心線を掴む部分（圧着バレル）の長さ**に合わせる
- 圧着後、**圧着部の先から心線が 0.5〜1mm 程度見える**のが適正
- 剥きすぎ → 心線が露出したままになり、**隣の端子と接触して短絡する危険**
- 剥き足りない → 被覆を噛み込んで**接触不良**になる

### ③ 心線の扱い

- **撚り（より）をほどかない、ほぐさない。**ほどくと素線がばらけ、圧着時にバレルからはみ出す
- 素線を1本も折らない・散らさない。ばらけた場合は撚り直す（指で軽く撚る程度）
- 心線に**手の脂・汚れを付けない**（接触抵抗の原因）



## 4.3 マークチューブの注意点

マークチューブは、その線が「どこからどこへ行く線か」を示す番号札である。**設備が動かなくなったときに、これが無いと原因が追えない。**

### ① 圧着より先に通す

> ⚠️ **圧着端子を付けてしまうと、マークチューブは通らない。**必ず「被覆を剥く → **マークチューブを通す** → 圧着する」の順で作業する。**これを忘れるのが初学者の最頻出ミスである。**（忘れたら、端子を切って剥き直す）

### ② 向きを揃える

- **端子台側から見て、文字が正しく読める向き**に統一する
- 縦に配線する場合は「**下から上**」、横に配線する場合は「**左から右**」に読める向きに揃えるのが一般的
- 1本でも向きが逆だと、盤を見た人が**読み違える**。統一されていること自体が品質である

※イラスト挿入（マークチューブの挿入向き。正しい例と誤った例を並べて示す）

### ③ 番号は図面と一致させる

- 番号は**展開接続図（電気図面）と完全に一致**させる。図面が `#sysIn1` なら現物も `#sysIn1`
- 現物に合わせて図面を直すのではなく、**図面を正としてから現物を合わせる**
- 両端に付ける（片側だけだと反対側から追えない）

> 🔲 **要ご確認**：RTSキットで採用するマークチューブの方式（差し込み式／印字式／熱収縮式）を確定させたい。番号体系はJANOMEのI/O名（`#sysIn1`〜`#sysIn16` / `#sysOut1`〜`#sysOut16`）に合わせるのが合理的と考える。

## 4.4 図面（展開接続図）の読み方【追記・新設】

前節で「図面と一致させる」と述べたが、そもそも図面が読めなければ照合できない。最低限、次の3つが読めればよい。

### ① 電源は上下の横線

展開接続図では、**上の横線が＋24V、下の横線が0V（COM−）**と決まっている。すべての部品は、この2本の線の間に縦に描かれる。**電気は上から下へ流れる**と考えて読む。

### ② 線番号

線の脇に書かれた番号（`#sysIn1` など）が、**マークチューブに書く番号**であり、**プログラムで使う番号**でもある。**この3つが一致していれば、設備は必ず追える。**

> 🔲 **要作成**：RTSキットの実際の展開接続図。上記の説明は図面が完成した時点で、その図面の抜粋に差し替える。

## 4.5 圧着端子の注意点

### ① 端子のサイズを合わせる

圧着端子の型番は「**1.25-3**」「**2-4**」のように書かれている。

- **前の数字＝適合する電線の太さ（sq）**
- **後ろの数字＝ねじの呼び径（M3、M4）**

電線の太さと端子が合っていないと、**どんなに丁寧に圧着しても規定の保持力は出ない。**

### ② 専用の圧着工具を使う

> ⚠️ **ペンチ・プライヤー・ニッパーで圧着してはいけない。**見た目は潰れていても、内部で必要な圧縮がかかっておらず、**振動や熱で必ず抜ける・緩む。**

- **ラチェット式の圧着ペンチ**を使う。圧着が完了するまでラチェットが戻らない構造になっている
- 工具の**ダイス（圧着する溝）の位置**を、端子サイズの刻印に合わせる
- **ラチェットが「カチッ」と戻り切るまで握り込む。**途中で開くと圧着不足になる

### ③ 圧着後の確認（4点）

| 確認項目 | 良品 | 不良 |
|---|---|---|
| 心線の出方 | 圧着部の先から**0.5〜1mm**心線が見える | 見えない（短すぎ）／長く飛び出している |
| 被覆のかみ込み | 心線だけが圧着されている | **被覆が圧着部に噛んでいる**＝接触不良 |
| 絶縁バレル | 被覆部分をしっかり保持している | 被覆を掴んでいない＝**線が振動で疲労断線** |
| 引張り | **軽く引いて抜けない** | 抜ける／動く |

> 【追記】**圧着不良は「最初は動くが、しばらく経つと動かなくなる」という最も厄介な故障になる。**接触抵抗が大きいと通電時に発熱し、酸化が進んでさらに抵抗が増え、最終的に接触不良になる。**その場で動いたから良いとは判断しない。**

### ④ Y型（先開き）と O型（丸型）の使い分け

|          | **O型（丸型）**           | **Y型（先開き）**        |
| -------- | -------------------- | ------------------ |
| ねじを緩めたとき | **抜けない**             | 抜ける                |
| 着脱の速さ    | 遅い（ねじを外す必要がある）       | 速い                 |
| 向いている場所  | **振動する場所、重要回路、電源回路** | 頻繁に着脱する場所、保守性優先の場所 |

### ⑤ 端子台への接続

- - **1つのねじに端子を2枚以上重ねない**（通常は1枚まで）
- 締付後、**軽く引っ張って確認**する
- 【追記】**通電前に必ず、隣接端子との短絡がないか目視確認する**

※イラスト挿入（圧着端子の良否判定図。良品／被覆かみ込み／心線はみ出し／圧着不足 の4パターンを断面図で並べる）

## 4.6 整線・配線ルート

-  結束バンドは**締めすぎない**（被覆が変形すると特性が変わる）。
- 配線には**適度なたるみ（サービスループ）**を持たせる。ぴんと張ると、振動で端子部に応力がかかる

## 4.7 この章の用語

- **被覆**：電線の外側を覆っている絶縁体（ビニル等）
- **心線／素線**：被覆の中の銅線。細い線（素線）が何本も撚られて心線になっている
- **ニック**：被覆を剥くときに心線に付いた傷。**発熱・断線の原因**
- **sq（スケア）**：電線の断面積（mm²）。太さの単位。0.5sq、1.25sq など
- **AWG**：米国式の電線の太さ表示。**数字が大きいほど細い**
- **圧着**：端子を工具で強く潰して電線と一体化させること
- **圧着バレル**：圧着端子のうち、心線を掴む筒状の部分
- **絶縁バレル**：被覆部分を掴んで、線の振動を受け止める部分
- **マークチューブ**：線番号を書いた小さな筒。電線に通して識別する
- **展開接続図**：電気回路を上下の電源線の間に展開して描いた図面
- **ダクト**：配線をまとめて通す樹脂製の溝。フタが付く
- **サービスループ**：配線にあえて持たせる余裕（たるみ）
- **ロボットケーブル**：繰り返し曲げても断線しにくい構造の可動対応ケーブル
- **短絡（ショート）**：本来つながってはいけない箇所どうしが接触すること
- **接触抵抗**：接続部で生じる抵抗。大きいと発熱し、やがて接触不良になる

## 5.2 I/O割付とは---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

**I/O（アイオー）** とは Input / Output（入力／出力）のこと。

- **入力（Input）**：外から設備に入ってくる信号。センサー、スイッチ、押しボタン
- **出力（Output）**：設備から外へ出す信号。電磁弁、ランプ、ブザー

ロボットは「**端子台の何番に何が繋がっているか**」を自分では知らない。**人間がプログラムの中で「入力1番＝ワーク検知センサー」と決めてやる**必要がある。これを **I/O割付（わりつけ）** という。

### JANOME JR3000 の I/O 名称【追記】

JR3000シリーズでは、汎用の入出力は **I/O-SYS** というコネクタ（37ピン）に集約されており、プログラム上は次の名前で呼ぶ。

| 区分 | プログラム上の名前 | ピン番号 |
|---|---|---|
| **入力** | **`#sysIn1` 〜 `#sysIn16`**（16点） | 1〜16 |
| **出力** | **`#sysOut1` 〜 `#sysOut16`**（16点） | 17〜32 |
| コモン（＋） | COM＋（DC24V） | 33 |
| コモン（−） | COM−（GND） | 34・35・36 |

- **入出力はNPN仕様とPNP仕様がある。**装置がどちらかを最初に確認すること（第3章Q3）
- I/O-SYSへ供給できる電流には上限がある。センサーを増やしすぎると電圧が下がり、原因不明の誤動作を起こす（第8章）

> 🔲 **要確認**：上記はJANOME提供資料（`JANOME抜粋/IO-SYS.pdf`）から読み取った内容。**実機の型式（JR3200/JR3300/JR3400等）によりピン配置が異なる可能性があるため、納品する機種の資料で必ず照合すること。**

## 5.3 演習：接続先を変えてみる

今接続されている場所と、例題にある接続先は違う。**例題の接続先に変更し、プログラムの割付も自分で変えてみる。**

これができたら、**「I/Oの接続先とソフトウェアの番号が一致しないと動かない」**ということを体で理解できたことになる。

> 【追記】**この演習が本章の核心である。**実務のトラブルで最も多いのが、この不一致である。
> - 配線だけ変えて割付を変えない → 別の動作をする、または動かない
> - 割付だけ変えて配線を変えない → 同上
> - **どちらも変えて、初めて正しく動く**

サンプルプログラム **2番** でロボットを動かしてみる。

## 5.4 動かないときの確認順序

**闇雲に触らず、上流から順に確認する。**（症状から引くときは第10.2節の早見表を使う）

| 順 | 確認 | 見方 |
|---|---|---|
| 1 | センサーに電源は来ているか | センサー本体の**電源ランプ**が点いているか |
| 2 | センサーは検知しているか | 手をかざして**動作表示灯**が変化するか |
| 3 | 信号は装置まで届いているか | **I/Oモニター**で該当番号が変化するか |
| 4 | プログラムは正しい番号を見ているか | 割付表とプログラムを照合 |

> **1〜2でNGなら配線・センサーの問題、3でNGなら配線または出力方式（PNP/NPN）の問題、4でNGならプログラムの問題**と切り分けられる。この切り分けの手順そのものが、FAで最も重要な技能である。

## 5.5 この章の用語

- **I/O（アイオー）**：Input（入力）／Output（出力）の総称
- **入力（Input）**：外から設備に入ってくる信号。センサー、スイッチ
- **出力（Output）**：設備から外へ出す信号。電磁弁、ランプ、ブザー
- **I/O割付**：端子の番号とプログラム上の番号を対応づけること
- **I/Oモニター**：入出力の現在のON/OFFを画面で一覧表示する機能
- **I/O-SYS**：JR3000の汎用入出力コネクタ（37ピン）
- **`#sysIn1`〜`#sysIn16`**：JR3000の汎用入力の名前（16点）
- **`#sysOut1`〜`#sysOut16`**：JR3000の汎用出力の名前（16点）
- **コモン（COM）**：複数の回路で共通に使う電位。COM＋は24V、COM−は0V
- **活線**：電気が流れたままの状態。**活線作業は禁止**

# 第6章：センサーの違い

ファイバーセンサー、マイクロスイッチ、近接センサーなど、**どのセンサーがどういう用途に向いているか**を学ぶ。

> **第3章Q4では「何を検知したいか」で選んだ。本章では「接触させてよいか・どれだけ持つか」で選ぶ。**

## 6.1 3種類の検出原理

| センサー | 検出原理 |
|---|---|
| **ファイバーセンサー** | 光ファイバーで導いた光が**遮蔽される**ことによりON/OFFを判定する |
| **マイクロスイッチ** | **物理的にスイッチが押される**ことでON/OFFを判定する |
| **近接センサー** | **金属が近くにあるかないか**によってON/OFFを判定する（誘導型は金属に発生する渦電流を検出） |

※イラスト挿入（センサー種類別 検出原理図。3種を横並びで、検出のしくみが分かるように描く）

## 6.2 比較表

| | ファイバーセンサー | マイクロスイッチ | 近接センサー |
|---|---|---|---|
| 接触の有無 | **非接触** | **接触** | **非接触** |
| 検出対象 | ほぼ何でも（光を遮れば） | 何でも（押せれば） | **金属のみ**（誘導型） |
| 検出距離 | 数mm〜数百mm | 0（接触） | 数mm〜十数mm（**短い**） |
| ヘッドの大きさ | **極小**（狭所に入る） | 中 | 小〜中 |
| 応答速度 | **速い** | 遅い（機械動作） | 速い |
| 寿命 | 長い（光学部品） | **短い**（接点・機構の摩耗） | 長い |
| 弱点 | 粉塵・汚れで光量低下。透明物に弱い | 摩耗・チャタリング。ワークが軽いと押せない | 金属以外を検出できない。距離が短い |
| 確実性 | 高 | **最も高い**（物理接触） | 高 |
| 価格 | 中〜高（アンプが必要） | 安い | 中 |

## 6.3 接触か、非接触か

- **マイクロスイッチ**は物理的接触が必要なため摩耗・寿命の問題があるが、**確実性が最も高い**。「本当にそこに物があるか」を疑いなく確認したい場面（安全確認、治具のクランプ完了確認など）で使う
- **ファイバーセンサー・近接センサー**は非接触のため摩耗しないが、**検知距離や対象物の材質に制約がある**
- 用途（**検知対象・耐久性・設置スペース・要求される確実性**）に応じて最適なものを選ぶ

> 【追記】**「一番良いセンサー」は存在しない。**選定とは、制約条件の中で最もましなものを選ぶ行為である。これが分かると、部品選定ができるようになる。

## 6.4 チャタリングについて

**マイクロスイッチのような機械接点は、切り替わる瞬間に微小なON/OFFを数回繰り返す。**これを**チャタリング**という。

- そのままプログラムで数えると、1回の動作を複数回とカウントしてしまう
- 対策：**プログラム側で数十ms程度の遅延（フィルタ）を入れる**、またはチャタリング防止機能のある入力を使う
- 非接触センサー（光電・近接）ではチャタリングは原則起きない。**これも非接触の利点である**

## 6.5 この章の用語

- **ファイバーセンサー**：光ファイバーで光を導いて検知するセンサー。ヘッドが極小
- **マイクロスイッチ**：レバーやローラーが物理的に押されて動作する接点式スイッチ
- **近接センサー**：金属が近づいたことを非接触で検知するセンサー
- **渦電流**：金属に磁界が当たると内部に発生する電流。近接センサーはこれを検出する
- **検出距離**：センサーが対象を検知できる距離。近接センサーは数mm〜十数mmと短い
- **チャタリング**：接点が切り替わる瞬間に、微小なON/OFFを数回繰り返す現象
- **ms（ミリ秒）**：1000分の1秒。フィルタや応答速度の単位
- **アンプ**：センサーの微弱な信号を増幅して、ON/OFFの信号に変える装置

# 第7章：配線・プログラムの応用

センサーを2つ付けて、応用のプログラムを組む。**条件分岐（AND回路、OR回路）**を学ぶ。

## 7.1 AND回路とOR回路

| | **AND（論理積）** | **OR（論理和）** |
|---|---|---|
| 条件 | **両方がON**でないと動かない | **どちらか片方でもON**なら動く |
| 回路の形 | **直列** | **並列** |
| 覚え方 | **全部そろわないとダメ**（1つでも欠けたらダメ） | **1つでもあればOK** |
| 実例 | 両手押しボタン（安全）、ワーク有り**かつ**扉閉 | 3か所のうちどこかの停止ボタン、複数の異常検知 |

※イラスト挿入（AND回路／OR回路の比較図。直列と並列の回路図を対比する）

### 動作の一覧【改善】

「入力AがON、入力BがOFFのとき、装置は動くのか」を表にしたもの。**ON/OFFの羅列ではなく、実際に動くかどうかで読む。**

| センサー1 | センサー2 | **AND（直列）**　両方そろって初めて動く | **OR（並列）**　どちらかあれば動く |
|:---:|:---:|:---:|:---:|
| ✕ 反応なし | ✕ 反応なし | ✕ **動かない** | ✕ **動かない** |
| ✕ 反応なし | 〇 反応あり | ✕ **動かない** | 〇 **動く** |
| 〇 反応あり | ✕ 反応なし | ✕ **動かない** | 〇 **動く** |
| 〇 反応あり | 〇 反応あり | 〇 **動く** | 〇 **動く** |

> **読み方**：ANDの列は、**一番下の1行だけが「動く」**。ORの列は、**一番上の1行だけが「動かない」**。この非対称さが分かれば、AND と OR は取り違えない。

## 7.2 条件分岐（if-then-else）

「**これがONしていたらこうする、こちらがONしていたらこうする**」という分岐を学ぶ。

### ① まず考え方

```
もし センサー1 が ON なら       → A の動作をする
そうでなく センサー2 が ON なら → B の動作をする
どちらでもなければ             → 待機する
```

> 【追記】**「どちらでもないとき」を必ず書く。**書き忘れると、想定外の状態になったときに設備が何をするか分からなくなる。**分岐は必ず全部の場合を尽くす。**

### ② JANOME JR3000 での実際の書き方【追記・新設】

JR3000シリーズでは、**条件を作る命令**と**分岐する命令**が分かれている。

**条件を作る命令**

| 命令 | 意味 |
|---|---|
| `ldON` | その入力が **ON** であることを、条件の**先頭**に置く |
| `ldiOFF` | その入力が **OFF** であることを、条件の**先頭**に置く |
| `andON` | **かつ**、その入力が ON（**AND**） |
| `aniOFF` | **かつ**、その入力が OFF |
| `orON` | **または**、その入力が ON（**OR**） |
| `oriOFF` | **または**、その入力が OFF |

**分岐・出力する命令**

| 命令 | 意味 |
|---|---|
| `if` 〜 `then` 〜 `else` 〜 `endIf` | 条件が成立していれば `then` 側、しなければ `else` 側を実行する |
| `set` | 指定した出力を **ON にする** |
| `reset` | 指定した出力を **OFF にする** |
| `goPoint` | 指定したポイント（座標）へ移動する |
| `jump` / `Label` | 指定したラベルへ飛ぶ／飛び先の目印 |

**例1：AND（センサー2つが両方ONのときだけ電磁弁を出す）**

```
ldON  #sysIn1        ' ワーク検知センサー が ON、かつ
andON #sysIn2        ' 治具クランプ確認 が ON
if then
  set #sysOut1       ' 電磁弁を ON にする
endIf
```

**例2：OR（どちらかのセンサーが反応したら警報）**

```
ldON #sysIn3         ' 異常検知1 が ON、または
orON #sysIn4         ' 異常検知2 が ON
if then
  set #sysOut2       ' 警報ランプを ON にする
endIf
```

**例3：if-then-else（ワークの種類で行き先を変える）**

```
ldON #sysIn1         ' 種類判別センサー が ON か？
if then
  goPoint 10         ' ON  → A位置へ移動
  set #sysOut1       '       A用の電磁弁
else
  goPoint 20         ' OFF → B位置へ移動
  set #sysOut2       '       B用の電磁弁
endIf
```

> 🔲 **要確認**：命令名は JANOME 提供資料（`JANOME抜粋/命令一覧.pdf`）から読み取った実際の命令である。ただし**引数の書き方（`goPoint` のポイント指定形式、コメント記号など）は、実機の JR C-Points II の画面で確認して確定すること。**上記は構造を示すためのものであり、そのまま入力できる保証はない。

## 7.3 自己保持回路

押しボタンは**押している間しかONにならない**。しかし設備は「一度スタートを押したら、押し続けなくても動き続けて」ほしい。これを実現するのが**自己保持回路**である。

- **セット条件**（スタートボタン）でONにする
- **自分の出力を使って、ON状態を保持し続ける**
- **リセット条件**（停止ボタン・完了信号・非常停止）でOFFにする

JR3000では、`set` で出力をONにし、`reset` でOFFにすることで同じ働きを作れる（`set` した出力は、`reset` するまで保持される）。

> ⚠️ **リセット条件を必ず先に効かせる（優先させる）。**停止より起動が優先される回路を作ると、**停止ボタンが効かない設備**になる。

## 7.4 カウンタ【追記・新設】

**「何個できたか」を数える機能。**タイマが時間を数えるのに対し、カウンタは回数を数える。

| 使いどころ | 例 |
|---|---|
| 生産数の管理 | 100個作ったら停止して知らせる |
| パレットの位置決め | 5個並べたら次の列へ移る |
| 異常の判定 | リトライを3回繰り返してもダメならエラーにする |

JR3000には、パレット（並べた場所）を順に進めるための `incPallet`（1つ進める）、`resPallet`（最初に戻す）、`loopPallet`（全数まで繰り返す）という命令があり、**数を数えながら位置をずらしていく処理**はこれで組める。単純な繰り返しには `for` 〜 `next`、`do` 〜 `loop` を使う。

> ⚠️ **カウンタは電源を切っても値が残るものと、消えるものがある。**「電源再投入したら生産数がリセットされていた」という事故を防ぐため、**どちらの動作になるかを必ず確認する。**

## 7.5 タイムアウトエラー

**何秒以内に信号が入らなかったらエラーとする**、設備が出すエラーである。

### Q. どうしてタイムアウトエラーが必要なのか

**A.** タイムアウトエラーがないと、設備は信号を待ち続けて**何時間も止まったまま**になってしまう。それを防ぐためにタイムアウトエラーがある。

**【追記】もう少し踏み込むと**

| 無い場合 | 有る場合 |
|---|---|
| 設備は「待っている」だけなので、**異常だと誰も気付かない** | 設定時間で**エラー停止し、異常を知らせる** |
| 生産が止まっているのに原因不明の時間が積み上がる | **どこで止まったかがエラー番号で分かる** |
| 実は少し前にセンサーが壊れていた、という発見が遅れる | 故障の早期発見につながる |

**設定時間の決め方**：正常時にかかる時間の **1.5〜2倍程度**を目安にする。

- **短すぎる** → 正常なのにエラーが出る（誤検知でラインが止まる）
- **長すぎる** → 異常の発見が遅れる（タイムアウトの意味が薄れる）

### JANOME JR3000 での書き方【追記】

JR3000には、**条件が成立するまで待ち、時間切れになったら別の処理へ抜ける**ための命令が用意されている。

| 命令 | 意味 |
|---|---|
| `waitCond` | 条件が成立するまで待つ、の開始 |
| `Time` | 待つ時間の上限（タイムアウト時間）を指定する |
| `timeUp` | **時間切れになったときに実行する処理**をここから書く |
| `endWait` | 待ちの終わり |

```
waitCond
  ldON #sysIn5       ' 下降完了センサーが ON になるまで待つ
Time 3000            ' ただし 3秒 まで
timeUp
  set #sysOut3       ' 時間切れ → 警報ランプを ON
  jump ERR           ' エラー処理へ飛ぶ
endWait
```

> 🔲 **要確認**：`Time` の単位（ミリ秒／秒）と引数の書き方は、実機で必ず確認すること。

※イラスト挿入（タイムアウトエラーのタイムチャート。正常時とタイムアウト発生時を上下に並べ、設定時間を破線で示す）

## 7.6 エラーが出たあとの復帰手順【追記・新設】

**エラーは「出して終わり」ではない。復帰させて初めて設備として成立する。**

| # | 手順 | 内容 |
|---|---|---|
| **①** | **止まる** | まず装置に触らない。**どの工程で止まったか、どのランプが点いているかを見る**（第10.2節の早見表で症状から引く） |
| **②** | **記録する** | エラー番号・表示内容を控える。**写真を撮っておくと問い合わせがそのまま済む**（第1.2節） |
| **③** | **原因を取り除く** | ワークの詰まり、センサーの汚れ、配線の緩みなど。**原因を直さずに解除だけしても、また同じ場所で止まる** |
| **④** | **安全確認** | 可動範囲に手・工具・ワークが残っていないか |
| **⑤** | **エラーを解除する** | リセット操作を行う（非常停止を押していた場合は、回して引き上げてから） |
| **⑥** | **原点復帰する** | 位置がずれている可能性があるため、**必ず原点復帰からやり直す**（第2.3節③） |
| **⑦** | **低速で確認する** | いきなり通常速度で動かさない。1サイクル低速で流して確認する |

> ⚠️ **③を飛ばして⑤だけ行うのが、最もよくある間違いである。**エラー解除は「原因が消えたことの宣言」であって、原因を直す操作ではない。

> 🔲 **要作成**：RTS実機のエラー番号一覧と、番号ごとの原因・対処。[[RTS_QAトラブルシューティング]] に展開する。

## 7.7 この章の用語

- **AND（論理積）**：「かつ」。**すべての条件がそろって初めて成立**する。回路は**直列**
- **OR（論理和）**：「または」。**どれか1つでも成立すれば**成立する。回路は**並列**
- **条件分岐**：条件によって、その後の動作を変えること
- **自己保持**：一度ONになった状態を、自分の出力を使って保ち続ける回路
- **インターロック**：ある条件が成立していないと動かせないようにする、安全のための仕組み
- **タイマ**：時間を数える機能
- **カウンタ**：回数を数える機能
- **タイムアウトエラー**：決めた時間内に信号が来なかったときに出すエラー
- **`ldON` / `andON` / `orON`**：JR3000で条件を作る命令。それぞれ「先頭がON」「かつON」「またはON」
- **`if` / `then` / `else` / `endIf`**：JR3000の条件分岐命令
- **`set` / `reset`**：JR3000で出力をON／OFFする命令
- **`waitCond` / `Time` / `timeUp` / `endWait`**：JR3000で「条件成立まで待つ・時間切れなら別処理」を書く命令
- **`goPoint`**：指定したポイント（座標）へ移動する命令

# 第8章：電源の違い

**AC100V、200V、単相、三相、DC** について学ぶ。

## 8.1 種類と用途

### 交流（AC）

| 種類 | 特徴 | 主な用途 |
|---|---|---|
| **単相 AC100V** | 一般のコンセント。線は2本＋アース | 小型機器、制御電源、卓上装置 |
| **単相 AC200V** | 同じ単相で電圧が高い。同じ電力なら電流が半分で済む | エアコン、中型機器 |
| **三相 AC200V（動力）** | 線が3本。**モーターを効率良く回せる** | 生産設備の主モーター、コンプレッサ、大型機器 |

### 直流（DC）【追記・拡充】

**直流にも用途によって複数の電圧がある。**「DC＝24V」と思い込まないこと。

| 電圧 | 主な用途 | 備考 |
|---|---|---|
| **DC5V** | 制御基板の内部、センサーアンプの内部、USB機器 | 電圧が低く、**ノイズに弱い**ため装置内部に閉じて使う |
| **DC12V** | 車載機器、小型ファン、一部のカメラ・照明、無線機器 | 自動車系で標準。FAでは補助的 |
| **DC24V** | **FA制御の標準。**センサー、電磁弁、PLC入出力、表示灯 | **RTSはこれを使う。**部品の入手性が最も良い |
| **DC48V** | 一部のサーボモーター、電動グリッパ、搬送機器、通信機器（PoE） | 同じ電力なら**電流が24Vの半分**で済むため、太い配線が要らない |

> 【追記】**なぜ電圧の種類が分かれるのか**：同じ電力を送るとき、**電圧が高いほど電流が小さくて済む**（電線が細くて済み、損失も減る）。一方、電圧が高いほど感電の危険が増す。**「安全に扱える範囲で、できるだけ高い電圧」**という綱引きの結果が、用途ごとの電圧の違いである。

## 8.2 RTSの構成

今回のRTSシステムでは、**AC100V単相、DC24V**を使う。**この構成が、初期のFAで一番使われる仕様**になる。

```
AC100V 単相（工場コンセント）
   ↓
ノイズフィルタ／ブレーカ
   ↓
スイッチング電源（AC100V → DC24V）
   ↓
DC24V ─┬─ ロボット制御部
        ├─ センサー
        └─ 電磁弁
```

※イラスト挿入（電源系統図。AC100V入力からDC24Vが各機器へ分配される流れを示す）

## 8.3 なぜ制御回路はDC24Vなのか

| 理由 | 説明 |
|---|---|
| **感電の危険が低い** | 人体への危険が交流100Vより格段に小さい。触れる可能性のある配線を扱う教育設備として適切 |
| 半導体機器を直接駆動できる | センサー・PLCの内部回路は直流で動く |
| **ノイズに強い** | DC5VやDC12Vより電圧が高いぶん、ノイズによる誤動作が起きにくい |
| 世界標準 | FA機器の制御電圧としてDC24Vが事実上の標準。**部品の入手性が最も良い** |

## 8.4 安全上の注意

> ⚠️ **DC24Vには極性がある。＋と−を逆に接続すると、センサーや電磁弁が壊れることがある。**（逆接続保護が入っている機器もあるが、あることを前提にしない）

- **AC側の配線は、必ず電源を切ってから触る**
- **アース（接地）を必ず取る。**接地は感電防止とノイズ対策の両方の役割がある
- 電源容量を確認する。センサー・電磁弁を増やしていくと、**電源の容量を超えて電圧が下がり、原因不明の誤動作を起こす**
- AC配線とDC配線の分離については第4.6節を参照

## 8.5 この章の用語

- **AC（交流）**：電流の向きが周期的に入れ替わる電気。コンセントの電気
- **DC（直流）**：電流の向きが一定の電気。**極性（＋／−）がある**
- **単相**：交流のうち、線が2本（＋アース）のもの。一般のコンセント
- **三相**：交流のうち、線が3本のもの。**動力**とも呼ぶ。モーター用
- **極性**：＋と−の向き。**逆に繋ぐと機器が壊れることがある**
- **スイッチング電源**：ACをDCに変換する装置。RTSではAC100V→DC24Vに使う
- **ノイズフィルタ**：電源線に乗る電気的な雑音を取り除く部品
- **ブレーカ**：過大な電流が流れたときに、自動で回路を切る装置
- **電源容量**：その電源が供給できる電流の上限。超えると電圧が下がる

# 第9章：空圧回路

正圧と負圧、レギュレーター、フィルターレギュレーター、ミストセパレーター、それぞれの役目について学ぶ。

**空圧回路では、センサーと違い、何か物を動かすときに利用する。**圧力の単位は**メガパスカル（MPa）**である。この圧力を使って何をするかを学ぶ。

## 9.1 正圧と負圧

| | **正圧** | **負圧（真空）** |
|---|---|---|
| 意味 | 大気圧より**高い** | 大気圧より**低い** |
| 用途 | シリンダーを押す・引く、エアブロー | **ワークの吸着**（吸着パッドで持ち上げる） |
| 発生源 | コンプレッサ | 真空ポンプ、**真空エジェクタ**（正圧から真空を作る） |

> 【追記】RTSでは正圧が主。負圧は、薄い板や袋物など**掴めない物を持ち上げる**ときに使う。エジェクタを使えば、真空ポンプを別に用意せず、正圧のエアだけで真空が作れる。

## 9.2 空気の清浄化（3点セット）

工場の圧縮空気には、**水分・油分・ゴミ**が含まれている。そのまま機器に入れると故障の原因になる。

| 機器 | 役目 |
|---|---|
| **フィルター** | ゴミ・水滴を取り除く。**ドレン（溜まった水）は定期的に抜く** |
| **レギュレーター** | 圧力を必要な値に**下げて一定に保つ**。上げることはできない |
| **フィルターレギュレーター（F.R.）** | 上記2つが一体になったもの |
| **ミストセパレーター** | フィルターで取り切れない**微細な油分（オイルミスト）**を除去する |
| ルブリケーター | 逆に、機器に潤滑油を供給する（現在は無給油機器が主流で使わないことが多い） |

> ⚠️ **ドレン抜きを怠ると、水が下流に流れ、電磁弁・シリンダーの内部を錆びさせる。**日常点検の項目に入れる。

## 9.3 圧力の単位

- **1 MPa = 1,000,000 Pa**
- 目安：**0.5 MPa ≒ 5 kgf/cm²**（現場では今も「5キロ」という言い方をすることがある）
- RTSの空圧条件：**φ6ホース・0.4MPa以上**
- シリンダーの押す力は **推力 F = 圧力 P × 受圧面積 A** で決まる。**圧力を上げるか、シリンダーを太くするかの2択**である

## 9.4 電磁弁のシングルとダブル

| | **シングル（片ソレノイド）** | **ダブル（両ソレノイド）** |
|---|---|---|
| 動作 | 通電しているときに片方に切り替わり、**通電を切ると（バネで）元に戻る** | **電気的に切り替えたら、通電を切っても元に戻らない**（その位置を保持する） |
| 出力点数 | 1点 | 2点 |
| 停電・非常停止時 | **必ず決まった位置に戻る** | **その場に留まる** |

**設備の基本であるフェールセーフを考え、戻った方が良いのか、戻らない方が良いのか、それによってシングルかダブルかを使い分ける。**

**【追記】判断の目安**

| 状況 | 選ぶべきもの | 理由 |
|---|---|---|
| 停電時に**引っ込んでほしい**（ワークから離れてほしい） | **シングル** | 通電が切れれば自動で戻る |
| 停電時に**ワークを掴んだままでいてほしい**（落とすと危険） | **ダブル** | 通電が切れても保持する |
| 停電時に**その場で止まってほしい**（動くと干渉する） | **ダブル**（または3位置弁） | 動かない |

> ⚠️ 【追記】**ダブルは「両方のソレノイドに同時に通電してはいけない」。**プログラム側で、**両方が同時にONにならないようインターロックを組む**（片方を `set` するとき、必ずもう片方を `reset` する）。

※イラスト挿入（シングル／ダブル電磁弁の動作比較図。通電時・非通電時のスプール位置と流路を示す）

## 9.5 オートスイッチ（シリンダーの位置検出）【追記・新設】

電磁弁は「動け」と指令するだけで、**本当に動いたかどうかは返してこない。**そこで、シリンダーが目的の位置まで動いたことを確認するために、シリンダー本体に取り付けるのが**オートスイッチ**である。

| 項目 | 内容 |
|---|---|
| 仕組み | シリンダー内部のピストンに**磁石**が入っており、外側のスイッチがその磁石を検知する |
| 取付 | シリンダーの外周の溝に差し込み、**位置をずらして調整**してから固定する |
| 数 | 通常、**前進端と後退端の2個**を付ける |
| 配線 | 2芯が多い（第3章Q5）。入力（`#sysIn`）に接続する |

**なぜ必要なのか**

- **「〇秒待てば下がっているはず」という固定待ちをやめられる**（第11.3節）。実際に下がったことを確認して次へ進めるので、**速く、かつ確実**になる
- ワークが挟まって途中で止まったとき、**タイムアウトで異常を検出できる**（第7.5節）

> ⚠️ **調整位置がずれると、動いているのに検知しない。**取付後は必ず、シリンダーを手動で動かして**確実にON/OFFする位置**を確認してから本締めする。

## 9.6 実習：レギュレーターから電磁弁・シリンダーまで

RTSシステムでは、レギュレーターと電磁弁を使ってシリンダーを動かす。サンプルプログラム **4番**（【訂正】原稿は「5番」）。これに合わせて、I/Oの配線の場所を変えてみる。

※イラスト挿入（空圧回路図。エア源→フィルターレギュレーター→電磁弁→スピードコントローラー→シリンダー の順に、破線矢印で空気の流れを示す）

### 作業手順

| # | 手順 | 【追記】注意点 |
|---|---|---|
| **①** | 電磁弁の配線をI/O端子台に接続（**2芯線**） | **Q. どうして2本？** → **A. 出力（電磁弁を動かす）だけで、入力していないから。**電磁弁は「動け」という指令を受け取るだけで、状態を返さない。状態を知りたい場合はシリンダーに**オートスイッチ**（第9.5節）を付ける |
| **②** | レギュレーターを**反時計回りに回し、ゼロの状態にする** | **必ずゼロから始める。**いきなり圧力がかかると、シリンダーが勢いよく動いて危険 |
| **③** | 工場の圧縮空気をレギュレーターに接続する | 空圧条件は**φ6ホース・0.4MPa以上**。接続前にホース端のゴミを飛ばす |
| **④** | レギュレーターを少しずつ回し、**空気が出てきていることを確認する** | 少しずつ。急に回さない |
| **⑤** | レギュレーターを**0に戻す** | 次の接続作業を無圧で行うため |
| **⑥** | レギュレーターと電磁弁を繋ぐ（**φ6ホース**） | ワンタッチ継手は**奥まで確実に差し込む**。差し込みが浅いと運転中に**ホースが抜けて暴れる** |
| **⑦** | レギュレーターを **0.1MPa** に設定する | **低い圧力から始める。**0.4MPaでいきなり動かさない |
| **⑧** | ロボットのI/Oモニターで電磁弁を動かす | **ONしている時に空気が出て、OFFにすると空気が止まる**ことを確認する |
| **⑨** | シリンダーにホースを接続する | 2本（押し側・引き側）。**接続する前に、シリンダーの可動範囲に手や物が無いか確認** |
| **⑩** | **スピードコントローラー（スピコン）**のつまみを動かす | 圧力を上げるとシリンダーは**力強く**動く。スピコンを調整すると**速度**が調整できる |

> ⚠️ **【追記】空圧の最重要注意点**
> - **電源を切ってもシリンダーは動く。**空気が入ったままなら、残圧で突然動くことがある。**作業前は必ず空圧の元弁を閉じ、残圧を抜く**
> - ホースが外れると**ホースが鞭のように暴れる**。接続は確実に
> - **圧縮空気を人に向けない。**皮膚から体内に入ると重大な事故になる

## 9.7 メーターアウト／メーターインの違い

シリンダーの速度は、**流量を絞る（スピコン）**ことで調整する。絞る場所によって2方式ある。

| | **メーターアウト** | **メーターイン** |
|---|---|---|
| 絞る場所 | **排気側**（シリンダーから出ていく空気） | **給気側**（シリンダーへ入っていく空気） |
| 原理 | 出ていく空気を絞ることで**背圧（ブレーキ）**をかける | 入る空気の量を制限して押す速度を抑える |
| 安定性 | **負荷変動があっても動きが安定しやすい** | **負荷変動の影響を受けやすく、動きが不安定になりやすい** |
| 典型的な症状 | — | 動き出しに**ガクッと飛び出す（スティックスリップ）**、速度がばらつく |
| 使用頻度 | **一般的に推奨される標準方式** | 特殊な用途を除きあまり使われない |

> 【追記】**なぜメーターアウトが安定するのか**：シリンダー内の両側に空気が入った状態でバランスを取りながら動くため、常にブレーキがかかった状態になる。メーターインは押す側だけを制御するため、負荷が軽くなった瞬間に一気に動いてしまう。
>
> 【追記】**メーターインを使う例外**：単動シリンダー（片側にしか空気が入らない）や、低速で押し当てる用途など。**「基本はメーターアウト、理由があるときだけメーターイン」**と覚える。

※イラスト挿入（メーターイン／メーターアウトの比較図。絞り弁の位置と空気の流れ方向を回路図で対比する）

## 9.8 この章の用語

- **正圧**：大気圧より高い圧力。押す・引くのに使う
- **負圧（真空）**：大気圧より低い圧力。吸着に使う
- **真空エジェクタ**：正圧の空気を流すことで真空を作り出す部品
- **MPa（メガパスカル）**：圧力の単位。0.5MPa ≒ 5kgf/cm²
- **レギュレーター**：圧力を必要な値まで**下げて**一定に保つ機器。上げることはできない
- **フィルター**：圧縮空気中のゴミ・水滴を取り除く機器
- **F.R.**：フィルターとレギュレーターが一体になったもの
- **ミストセパレーター**：微細な油分（オイルミスト）を除去する機器
- **ドレン**：圧縮空気から分離して溜まった水。**定期的に抜く**
- **電磁弁（ソレノイドバルブ）**：電気信号で空気の流路を切り替える弁
- **シングルソレノイド**：通電を切るとバネで元に戻る電磁弁
- **ダブルソレノイド**：通電を切っても位置を保持する電磁弁
- **シリンダー**：空気の力で棒（ロッド）を出し入れする部品
- **オートスイッチ**：シリンダー内部の磁石を検知して、位置を確認するスイッチ
- **スピードコントローラー（スピコン）**：空気の流量を絞ってシリンダーの速度を調整する部品
- **メーターアウト**：**排気側**を絞る方式。**標準はこちら**
- **メーターイン**：**給気側**を絞る方式。動きが不安定になりやすい
- **背圧**：排気側に残る圧力。これがブレーキの役割をする
- **ワンタッチ継手**：差し込むだけで接続できるホース継手
- **残圧**：電源を切った後も配管内に残る圧縮空気

# 第11章：効率化

設備では**生産効率**が求められる。単純に動けば良いのではなく、**どこに何の時間がかかっていて、どこを効率化できるか**ということも考える。

**極端に時間を短くすると動作が不安定になる。しかし、無駄な時間があると生産能力が落ちる。**

## 11.1 サイクルタイムの考え方

**サイクルタイム**とは、1個のワークを処理するのにかかる時間である。まず、**1サイクルの中身を分解して書き出す。**

| 工程 | 内容 | 時間の例 |
|---|---|---|
| ① | ワーク検知待ち | 0.5秒 |
| ② | ロボット移動（X軸） | 1.2秒 |
| ③ | シリンダー下降 | 0.8秒 |
| ④ | **下降完了待ち（オートスイッチ確認）** | 0.3秒 |
| ⑤ | シリンダー上昇 | 0.8秒 |
| ⑥ | ロボット移動（原位置へ） | 1.2秒 |
| | **合計** | **4.8秒** |

※イラスト挿入（サイクルタイム内訳図。各工程を横帯グラフで並べ、動作時間と待ち時間を色分けする）

> **測る前に改善しない。**まず内訳を書き出すこと。感覚で「ここが遅い」と決めつけると、たいてい外れる。

## 11.2 ボトルネック工程の見つけ方

**ボトルネック**とは、全体の速度を決めてしまっている**最も遅い工程**のこと。

- **ボトルネック以外をいくら速くしても、全体は1秒も速くならない**（これが効率化で最も誤解されやすい点）
- 上の例では ② と ⑥ のロボット移動（合計2.4秒＝全体の50%）がボトルネック
- **最も時間の長い工程から順に手を付ける**

## 11.3 「速度を上げる」か「待ち時間を削る」か

改善には2つの方向がある。**まず待ち時間を疑う。**

| 方向 | 内容 | リスク |
|---|---|---|
| **待ち時間を削る** | 固定待ち（「2秒待つ」）をセンサー確認に変える、動作を**同時並行**にする | **低い**。まずここから手を付ける |
| **速度を上げる** | 移動速度・加減速を上げる | **高い**。振動・位置ずれ・機器寿命に影響する |

**待ち時間削減の具体例**

- **固定待ちをやめる**：「シリンダーが下がるのに0.8秒かかるはずだから1秒待つ」→ **オートスイッチ（第9.5節）で下降完了を検知して即座に次へ**進む。これだけで0.2秒短縮でき、しかも**確実性が上がる**。JR3000なら `delay`（時間待ち）ではなく `waitCond` 〜 `endWait`（条件待ち）を使う
- **同時に動かす**：ロボットが戻る動作と、次のワークの搬入を**並行させる**。順番にやる必要がない工程を見つける
- **無駄な原位置復帰をやめる**：毎回原点に戻らず、次のワーク位置へ直接向かう

## 11.4 Q. なぜ速度を上げすぎると不安定になるのか

**A.** 3つの理由がある。

| 現象 | 説明 |
|---|---|
| **慣性（イナーシャ）** | 動いている物は止まりにくい。速度が上がるほど、止めるのに大きな力が必要になる。無理に止めると**装置がたわむ・揺れる** |
| **オーバーシュート** | 目標位置を**行き過ぎてしまう**こと。速度が高いほど大きくなる |
| **整定時間（セトリングタイム）** | 行き過ぎた後、揺れが収まって目標位置に落ち着くまでの時間。**速く動かすほど整定時間が延びる** |

> **速く動かしたのに、揺れが収まるのを待つ時間が増えて、結局トータルでは遅くなる。**これが「速度を上げても効率化にならない」典型例である。
>
> **対策**：最高速度ではなく**加減速の設定**を調整する。加速をなだらかにすると、最高速は同じでも振動が減り、結果的にサイクルタイムが縮むことがある。JR3000では `mMoveSpeed`（速度）と `mMoveAccelRate`（加速の割合）／`mMoveAccelTime`（加速にかける時間）が別々に設定できる。

## 11.5 効率化の指標

| 指標 | 意味 |
|---|---|
| **サイクルタイム** | 1個を処理するのにかかる**実際の**時間 |
| **タクトタイム** | 1個を作らなければならない**目標**時間（需要から逆算する） |
| **可動率（べきどうりつ）** | 動かしたいときに、ちゃんと動いてくれた割合。**故障・チョコ停で下がる** |

> **サイクルタイムがタクトタイムより長ければ、生産が間に合っていない。**効率化はここから逆算して目標を決める。
>
> 【追記】**速度を上げて可動率を下げるのは本末転倒である。**サイクルタイムを5%縮めても、それが原因でチョコ停が増えれば、実生産量は落ちる。**安定して動き続けることが、速さより優先される。**

## 11.6 演習

1. 第10章で組んだ統合動作のサイクルタイムを、**ストップウォッチで実測**し、工程ごとに分解して書き出す
2. 最も時間のかかっている工程を特定する（ボトルネック）
3. **固定待ちが使われている箇所を探し、センサー確認に置き換える**
4. 再度実測し、**何秒縮んだかを記録する**
5. 次に速度を10%上げてみて、**動作が不安定にならないか観察する**。不安定になったら戻す

> 🔲 **要ご確認**：この演習に専用のサンプルプログラムを追加するか（6番の新設要否）。現状は3番・5番の改造で対応する前提で記載している。

## 11.7 この章の用語

- **サイクルタイム**：1個を処理するのに**実際にかかる**時間
- **タクトタイム**：1個を作らなければならない**目標**時間。需要から逆算する
- **可動率**：動かしたいときに実際に動いてくれた割合。故障・チョコ停で下がる
- **ボトルネック**：全体の速度を決めてしまっている、最も遅い工程
- **固定待ち**：「〇秒待つ」と時間で決め打ちする待ち方。**確認に置き換えるのが望ましい**
- **条件待ち**：センサー等の条件が成立するまで待つ待ち方
- **慣性（イナーシャ）**：動いている物が動き続けようとする性質
- **オーバーシュート**：目標位置を行き過ぎてしまうこと
- **整定時間**：行き過ぎた後、揺れが収まって落ち着くまでの時間
- **加減速**：動き出しと止まり際の速度の変化のさせ方
