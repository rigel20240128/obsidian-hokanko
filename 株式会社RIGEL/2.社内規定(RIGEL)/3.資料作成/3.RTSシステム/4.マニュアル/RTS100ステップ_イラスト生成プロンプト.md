# RTS100ステップ　イラスト生成プロンプト（基盤テンプレート）

## 0. 位置づけ（2026-08-12 陛下ご指示）

> 「資料作成ルールは基本条件で、RTS用のSTEP100のマニュアルは個別で設定。会社としてのルールを守りつつ、プロジェクト毎のルールに従う事」

- **会社共通規定（基本条件）**：[[RIGEL資料作成ルール_統合版]] 第2.4章「イラスト・図版の作画統一規定」。本書はこれに矛盾しない。
- **本書の位置づけ**：上記を土台に、RTSマニュアル（全10/11章・100ステップ）専用に個別設定する**プロジェクトルール**。他プロジェクトの資料には適用しない。
- **[[RIGEL画像生成_基本プロンプト]]との違い**：あちらは「実写のイラスト化＝トレース（複製）」専用で本文改変禁止の別規定。今回は元写真が存在しない**ゼロからの技術図解**のため流用しない（別の作業のため別文書とする）。
- **生成の実行**：陛下がGoogle Geminiで直接生成（基本方針㉔）。本書はそのための**入力プロンプトの用意**までを担当し、生成そのものは行わない。
- **進め方**：基本方針㉕に従い、まず本書§3の試作1点のみ陛下にご確認いただき、ご承認後に残り99点を同じ型で量産する。

## 1. 固定ブロック（全100点で一字一句共通・変更禁止）

以下は100点すべてのプロンプト冒頭に**そのまま貼り付ける**部分。第2.4章の規定をGemini向けの生成指示文に落とし込んだもの。

```
【スタイル】フラットな線画（ベクターイラスト）。写真調・3Dレンダリング・水彩・手描き風・厚塗りは禁止。
【背景】白（#FFFFFF）単色のみ。枠線・影・グラデーション・テクスチャは付けない。
【視点】正面図・上面図・アイソメ図（等角投影）のいずれか1つのみを使用し、1枚の中で視点を混在させない。
【縦横比】4:3（横長）。フローチャート図のみ3:4（縦長）。
【配色】以下6色のみを使用する。指定以外の色を作らない。
　主線・輪郭：#17181A
　主役の機器・強調部：#026881（変更不可）
　第2系列・補助機器：#74ACBA
　背景オブジェクト・非主役の部品：#C7CBD3
　注意喚起（1図につき最大1箇所まで）：#E8622C
　注記・キャプション文字：#6B6E73
【線】主線は太め・補助線と寸法線は細めの2種類のみ。電気の流れは実線＋矢印、空気・エアの流れは破線＋矢印で示す（主線と同色。色は増やさず線種で区別する）。
【文字】日本語、ゴシック体。図中の文字は単語のみ（説明文・長文は書かない）。手順番号は①②③の丸数字を使う。
【人物】作業を示す場合は手のみを描く。顔・全身は描かない。
【禁止事項】実在メーカーのロゴ・型番・意匠を描かない（特徴は一般化する）。写真のトレースや他社マニュアルの模写はしない（完全新規のオリジナル技術図解とする）。図中に長文を書き込まない。
```

### RTS装置の統一形状（全100点で共通・変更禁止＝キャラクターシート）

100点を通じて同一の機器に見えるよう、外観を以下に固定する。

```
【RTS装置の統一形状】
・RTS本体：卓上サイズの直交（直動）3軸ロボット。X軸(横)・Y軸(奥行)・Z軸(上下)の直線3方向に動く。台座は角丸の直方体、可動部は角ばったシンプルなブロック形状。
・制御ボックス：本体の横に置く角型の箱。正面に電源スイッチ・非常停止ボタン（赤丸）・表示灯を配置。
・センサー類：円筒形または小型の箱型パーツとして単純化して描く（型番・ロゴは描かない）。
・配線／配管：電気配線は実線、エア配管は破線で統一する。
```

### 視点の選び方（内容に応じて選択する基準）

- 配置・作業スペース・可動範囲を示す図　→　**上面図**
- 配線・操作パネル・部品の外観を示す図　→　**正面図**
- 構造・組立の立体的な位置関係を示す図　→　**アイソメ図**

## 4. 今後の進め方

1. 上記§3を陛下がGeminiで生成 → スタイル・粒度をご確認。
2. ご承認後、同じ§1固定ブロック＋§2可変ブロックの型で、[[RTSマニュアル_第1-11章]]内の残り約24件の「※イラスト挿入」箇所（第1〜11章）を順次量産。
3. STEP/グレード別（STANDARD/ADVANCE/VISION/PROFESSIONAL、計100ステップ）の割付・命名規則は、[[基本概念]] 1.3節のレベル構成と突き合わせたうえで、試作承認後に別途整理する。
4. 生成画像の保存先は基本方針㉔に準拠：`5.画像、イラスト\イラスト生成画像\`。
