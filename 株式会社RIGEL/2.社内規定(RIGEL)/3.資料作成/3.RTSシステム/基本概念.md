# RTS事業 需要とターゲット調査


## 1. 事業概要・製品 (RTS)

### 1.1 コンセプト
- **自社技術者の育成が自動化の前提** という思想のもと、FA機器を「買う」ではなく「借りる」教育システムとして提供
- 工場の生産設備とは別の「教育専用設備」を顧客先に設置し、現場に影響せず実践的に学べる環境を提供
- 故障診断を組み込み "壊す→直す" サイクル自体が教育となる逆転の発想を採用

### 1.2 学習カバレッジ (網羅領域)
- I/O基礎:：ライトオン / ダークオン、A接点 / B接点、PNP / NPN、ポカよけ
- センサー：光電センサ、レーザー、近接センサ、マイクロスイッチ
- 電気配線：ワイヤーストリッパーでの被覆向き、圧着工具でのカシメ、マークチューブ
- 空圧機器：電磁弁（シングル、ダブル）、シリンダー（ロータリー、スライドテーブル、ロッド）
- 通信：シリアル通信、Ethernet/IP、Profinet
- モータ制御: サーボ、パルスモーター
- 画像処理: ビジョンシステム (欠品検査など)
- **複数メーカー機器の統合** が最大の差別化:
  - JANOME (制御ロボット) PLC機能搭載
  - KEYENCE (PLC、タッチパネル、画像処理、センサー)
  - SMC (シリンダー・電磁弁)
  - パナソニック (画像処理)
  - MISUMI（機構部品）

### 1.3 レベル構成 (4〜5段階)
| # | レベル | 内容 |
|---|------|------|
| 1 | Level 1 | I/O基礎 |
| 2 | Level 2 | 空圧・オートスイッチ |
| 3 | Level 3 | シリアル通信、Ethernet/IP、サーボ/パルスモーター制御 |
| 4 | Level 4 | 画像処理 (ビジョンシステム) |
| 5 | Level 5 | (上位モデル: 検査・エラー対応を含む総合) |

### 1.4 納品形態
- **完成品** か **組み立てキット (バラバラ)** の2方式のうち、組み立てキット方式に統一
  - 理由: 教育効果が最大化される & 運営側の組立工数が削減される
- キット内容: アルミ板・ベースフレーム、部材一式、結束バンド、ダクト、推奨工具リスト
- 工具 (ニッパー、ストリッパー、端子用圧着ペンチ等) は**顧客側で用意**してもらう方針

## 3. ターゲット・チャネル戦略

### 3.1 ターゲット層 (優先度順)
| 優先度 | セグメント | 位置付け |
|------|----------|---------|
| 最優先 | **基板・電子部品メーカー (中小) 関東圏** | 初年度の主軸 |
| 並行 | 学校 (専門学校・大学) | パイプライン確保 |
| 並行 | 大企業の生産技術部門 | 上位モデルの受け皿 |
| 中期 | ODA (政府開発援助・発展途上国) | 販路拡大時 |
| 中長期 | 海外市場 | 5年目以降 |

- **避ける業界**: 自動車 (品質要求が厳しい、ただしリースなら可能性あり)、医療、食品

### 3.2 チャネル戦略
- **商社経由** をメイン販路として活用
  - 関東圏の商社をリストアップ済み (例: 緑屋テクノ、和泉産業、五光社、ライト、柳田機器)
  - 商社は「誰でもウェルカム」、規模は問わず
- **人脈・紹介** → チラシ (A4裏表のカタログ仕様) → 商社訪問
- **SNS・YouTube** での情報発信
  - 一般公開動画: 商品説明・PR
  - 会員限定動画: トラブルシューティング詳細

### 3.3 展示会戦略
- 近場の展示会に絞る (遠方不可)
- 1日2〜3回、各1〜2時間のデモ
- 3ヶ月〜半年に2〜3回ペースで継続
- 自治体共同ブース活用でコストダウン
- 来場者名刺スキャンは必ず実施 → AI分析 → Obsidian保存 → リード管理

### 3.4 商社マージン体系
- **マージン: 15%**
  - 内訳: 商社 10% + 信販会社 5%
- 顧客視点で ¥100,000 リースした場合:
  - 商社: ¥10,000 取得
  - 信販: ¥5,000 取得
  - 自社受取: ¥85,000〜¥90,000
  - 顧客総支払い: ¥110,000〜¥120,000 (金利・手数料込み)

## 6. リース・信販スキーム (契約・法務)

### 6.1 採用する信販会社
**メイン: ちばぎんリース** (千葉銀行グループ)
- 千葉銀行をメインバンクに統一
- 資金調達とリースを一本化
- サポート費用もリース料と合算請求

**その他選択肢 (大手)**:
- ORIX
- 三井住友ファイナンス&リース
- 東京センチュリー
- 三菱HCキャピタル
- みずほリース

### 6.2 古物商許可
- 中古ロボットの取扱にあたり **古物商許可申請が必要** (実施予定)

### 6.3 法人運営における留意点
- 法人税は利益に連動して増加 → **税理士相談** を活用
- **資金繰り (キャッシュフロー) 管理が最優先**
- 株式会社の自己資本減少リスクに注意

### 6.4 自己保険的プール制度
- **整備費名目** で社内にリスクプール資金を積立て
  - 「保険」という名称を使うと保険業法の対象になるため注意
  - 「メンテナンス契約」「整備費用」として明示するのが安全
- プール金が利益源になり、修理発生時に充当
- 台数増でリスクをプールできる

### 6.5 故障対応ルール
| ケース | 対応 |
|------|------|
| 輸送中破損 | 運送会社責任 |
| 初期不良・自然故障 | 無償対応 |
| 顧客過失による故障 | 有償修理 |
| 構築済み部品 (端子処理済等) | 顧客に **買い取り** → ロボット本体のみ回収 |
| 高価部品 (アルミフレーム等) | **再利用** のため回収 |

## 7. 納品・サポート運用フロー

### 7.1 納品
- 基本 **郵送納品** (箱のまま送付)
- 顧客先で開梱・セットアップ
- 原則 **訪問なし** (コスト削減)
- 有償訪問サポートはオプション提供

### 7.2 サポートポリシー
- **メール受付** (電話受付は基本的になし)
- 問い合わせ時は **写真添付必須 + 状況記入フォーマット** を指定
- **1営業日以内に返信**
- **センドバック方式** (代替品先送・故障品回収)
- 故障対応そのものが教育になる設計 → カリキュラムにトラブルシューティングを組み込む

### 7.3 マニュアル・動画
- AI で生成した画像でステップ解説 (実写撮影なし)
- **Imagen / Nano Banana系** で画像生成
- 組み立て手順をステップ1, 2, 3... と段階表示
- 完成後は返却してもらうが、消耗部品は顧客側に残るため無駄がない

### 7.4 会員サイト・認証システム
| 区分 | 内容 |
|------|------|
| 一般公開 (YouTube等) | 商品紹介・PR・認知拡大 |
| 会員限定エリア | トラブルシューティング詳細、専門ノウハウ |

- **認証方式**: 顧客ID + 電話番号下4桁 でログイン
- データベースで有効期限管理 → 期限切れID自動無効化
- 会員用動画は限定公開で埋め込み → Obsidian側で認証ゲート制御

## 12. 差別化の整理 (競合 vs RTS)

- **メーカー直営デモ機**: 単一メーカー → RTS は複数メーカー統合 (ここが決定的な差別化)
- **短期レンタル教育サービス**: 限定的 -> RTS は 4〜5段階の体系的カリキュラム
- **受託研修**: 一回切り -> RTS は継続的な貸出+ドキュメント+動画+遠隔サポート
- **故障を学習素材化**: 他社にない教育的アプローチ
- **組み立てキット方式**: 自社組立で深い理解を得る
