# 01　事業概要・製品

## 1.1 コンセプト

> **「自動化したいが、設備を扱える自社技術者がいない」——この一点に絞る。**

- **自社技術者の育成が自動化の前提**という思想のもと、FA機器を「買う」ではなく「借りる」教育システムとして提供する
- 工場の生産設備とは別の「**教育専用設備**」を顧客先に設置し、現場に影響を与えずに実践的に学べる環境をつくる
- 故障診断を組み込み、**"壊す→直す" サイクル自体を教育とする**逆転の発想を採用

**この一文から外れる機能・サービスは足さない。** 判断に迷ったら「技術者育成に効くか」で切る。

## 1.2 学習カバレッジ（網羅領域）

| 領域 | 内容 |
|---|---|
| I/O基礎 | ライトオン／ダークオン、A接点／B接点、PNP／NPN、ポカよけ |
| センサー | 光電センサ、レーザー、近接センサ、マイクロスイッチ |
| 電気配線 | ワイヤーストリッパーでの被覆剥き、圧着工具でのカシメ、マークチューブ |
| 空圧機器 | 電磁弁（シングル／ダブル）、シリンダー（ロータリー／スライドテーブル／ロッド） |
| 通信 | シリアル通信、Ethernet/IP、Profinet |
| モータ制御 | サーボ、パルスモーター |
| 画像処理 | ビジョンシステム（欠品検査など） |

**最大の差別化は「複数メーカー機器の統合」**

| メーカー | 担当領域 |
|---|---|
| JANOME | 制御ロボット（PLC機能搭載） |
| KEYENCE | PLC、タッチパネル、画像処理、センサー |
| SMC | シリンダー・電磁弁 |
| パナソニック | 画像処理 |
| MISUMI | 機構部品 |

> 主軸機材は JANOME の**卓上ロボット・直交ロボット・SCARAロボット**であり、垂直多関節（6軸アーム型）ではない。これが競合分析上の重要な前提となる（第04章参照）。

## 1.3 レベル構成（**20段階**）

> **2026-08-01 変更：5段階 → 10段階 → 20段階へ細分化。** 1段階あたりの学習量を小さくするほど、①習得の実感が得やすい ②未習得の箇所を特定しやすい ③段階的な契約延長・グレードアップの動機付けになる。

### STEP 1｜配線と電気の基礎（Level 1〜5）

| Level | テーマ | 主な内容 |

| **5** | 出力形式 | PNP／NPN の理解と結線、誤結線時の挙動 |

| **11** | 電磁弁 | シングルソレノイド／ダブルソレノイドの回路と動作 |
| **12** | シリンダーとオートスイッチ | ロッド／スライドテーブル／ロータリーの各シリンダー、検出位置の調整 |

### STEP 3｜制御とプログラム（Level 13〜18）

| Level | テーマ | 主な内容 |
|---|---|---|

## 1.4 納品形態

**「コンプリートキット」方式に統一**（完成品納品は行わない）

- **完成品ではなく、バラバラの状態で必要部材が一式そろった「コンプリートキット」として送付する**
- 顧客は開梱後、自ら組み立てるところから学習が始まる
- 理由：①**組み立て工程そのものが最も重要な教育である** ②運営側の組立工数が削減される ③輸送時の破損リスクが下がる
- キット内容：**アルミフレーム・アルミ板（標準搭載品）**、部材一式、結束バンド、ダクト、推奨工具リスト、組立手順書
- **アルミフレームは全プラン共通の標準搭載品とする**（オプション扱いにしない）。架台を顧客側で用意させると、剛性・寸法のばらつきで学習環境が揃わず、サポート負荷が跳ね上がるため
- 工具（ニッパー、ストリッパー、端子用圧着ペンチ等）は**顧客側で用意**
- **「コンプリート」＝追加購入なしでその Level の学習が完結する構成**であることを対外訴求の要点とする

# 02　料金・契約条件（プラン体系）

> **提供形態はリース（月額）専業。単体販売は行わない。**（2026-08-01 裁可）

## 2.1 料金の二本立て構造（2026-08-01 決定）

料金は「**月額リース料**」と「**初期費用（基本料金）**」の二本立てとする。

| 区分 | 性質 | 対象 | 契約終了後 |
|---|---|---|---|
| **月額リース料** | ストック収入 | ロボット本体・**アルミフレーム（標準搭載品）**等の**再利用可能な設備** | **回収**（整備して再投入） |
| **初期費用（基本料金）** | 一時収入 | キット内の**消耗品部品**（センサー、電線、圧着端子、マークチューブ等） | **顧客の資産として残る** |

**この構造の意味**
- 消耗品は一度加工・圧着してしまえば原状回復できないため、**最初から顧客の資産として買い取ってもらう**のが合理的
- 顧客側にも「学習の成果物が手元に残る」という明確な利点がある
- 自社側は消耗品の原価を**契約初月に全額回収**でき、キャッシュフローが安定する
- **基本料金の額はグレードによって異なる**（上位グレードほどセンサー・カメラ等の消耗品構成が高価になるため）

## 2.3 休眠ロボット活用プラン（KIT ONLY）

**顧客が既にJANOMEロボットを保有している場合、基本キットのみを送付する低価格プラン。**

| 項目 | 内容 |
|---|---|
| 対象 | 遊休・休眠状態のJANOMEロボットを保有する企業 |
| 送付物 | **基本キットのみ**（ロボット本体を含まない周辺機器・消耗品一式） |
| 訴求 | 眠っている資産がそのまま教育設備になる、**最もお得なプラン** |

**このプランの戦略的意味**
- 顧客の初期障壁が最も低く、**新規開拓の入口として最適**
- JANOMEは直販でエンドユーザーが不明なため、休眠機の掘り起こしが最も効率の良いリード獲得口になる（第05章参照）
- 自社側もロボット本体の在庫を消費せず、保有機体を他の顧客へ回せる

# 03　収益モデルと採算

## 3.1 基本構造

収益は次の3層で構成される。

| 層 | 性質 | 内容 |
|---|---|---|
| ① 初期費用（基本料金） | **一時収入** | 消耗品部品の買い取り。契約初月に全額入る |
| ② 月額リース料 | **ストック収入** | 設備の貸与。稼働台数に比例して積み上がる |
| ③ サポート料 | **フロー収入** | 訪問・オンラインの従量課金 |

- 単発の売り切りは行わない
- 理由：①原価回収後は同一機体が利益を生み続ける ②顧客の初期投資障壁が低い ③信販会社を挟むことで与信・回収リスクを外部化できる
- **①の導入により、消耗品の原価を契約初月に全額回収できる。**これが採算の安定に大きく効く

## 3.2 商社・信販マージン（対外非公開）

**マージン合計 15%**（商社 10% ＋ 信販 5%）

| | STANDARD |
|---|---:|
| 表示リース料（月） | **¥120,000** |
| 商社取得（10%） | ▲¥12,000 |
| 信販取得（5%） | ▲¥6,000 |
| **自社受取（月）** | **¥102,000** |
| 顧客総支払額（金利・手数料込／月） | 約¥132,000〜144,000 |

> 🔲 **初期費用¥100,000にマージン15%を適用するかは未決。**適用すれば自社受取は¥85,000、適用しなければ¥100,000。商社との交渉事項。以下の試算は**両ケースを併記**する。

## 3.3 1台あたりの採算（STANDARD）

**前提**：1台原価 ¥300,000（うち消耗品部品分は初期費用で回収するため、リース料で回収すべき設備側の原価は約¥200,000）

| 項目 | 初期費用にマージン**なし** | 初期費用にマージン**あり** |
|---|---:|---:|
| 契約時の自社受取 | ¥100,000 | ¥85,000 |
| 月額の自社受取 | ¥102,000 | ¥102,000 |
| **3ヶ月契約の累計受取** | **¥406,000** | **¥391,000** |
| 3ヶ月時点の原価回収率 | **約135%** ✅ | **約130%** ✅ |
| 12ヶ月契約の累計受取 | ¥1,324,000 | ¥1,309,000 |
| 24ヶ月契約の累計受取 | ¥2,548,000 | ¥2,533,000 |

**✅ 最短の3ヶ月契約でも原価を大きく上回る回収が成立する。**
料金改定の推移：月額¥99,000のみ（回収率84%＝原価割れ）→ 月額¥100,000＋初期費用¥100,000（118%）→ **月額¥120,000＋初期費用¥100,000（135%）**。初期費用の導入と月額の引き上げにより、短期契約でも確実に利益が出る構造になった。

> **月額を¥120,000としたのは、アルミフレームを標準搭載品としたため。**架台を含めた完成環境を貸す以上、フレーム分を月額に織り込む。

- **回収後は同一機体が利益を生み続ける**のがこのモデルの核心。返却機は整備して再投入する
- ロボット本体は原則**中古調達**（¥50,000/台程度）、センサーも低価格品（¥2,000程度）で対応し、原価をさらに圧縮する
- 休眠ロボット活用プラン（KIT ONLY）はロボット本体の原価が発生しないため、**回収期間はさらに短い**

> ※本節は第02章の料金・原価と第3.2節のマージン15%から機械的に算出した試算。実際の信販手数料率および消耗品部品の実原価が確定した時点で再計算すること。
> 🔲 PROFESSIONAL の採算は、月額・初期費用の確定後に算出する。

## 3.4 ⚠️ 事業計画書との不整合（最優先の未決事項）

## 4.1 結論

**「JANOME系（卓上・直交・SCARA）× 産業グレード × 月額レンタル × FA技術者の技能継承特化」という4条件を同時に満たす競合は、現時点で確認されていない。**

## 6.2 保険（自家保険モデルを採用）

**動産総合保険ではなく、自社での自家保険（月額課金でリスクをカバー）を採用する。**

> 業界一般ではレンタル・リースの貸与元が動産総合保険を付保するのが標準（オリックス・レンテック等も標準付帯）。RTSは原価が小さいため自前で賄う判断。

**採算試算**

| 項目 | 金額 |
|---|---:|
| 月額「保護料」1万円 × 10件 × 12ヶ月 | 年間収入 120万円 |
| 想定損失（1件あたり5〜10万円 × 年3件＝全体の3割で破損） | 最大 30万円 |
| **差引** | **＋90万円** |

→ **経済合理性がある**と判断。契約件数が少ないうち（1〜3件程度）は破損が集中した場合に一時的な持ち出しが発生するが、原価自体が5〜10万円と小さいため許容範囲。

**運用上の名称に注意**：「保険」という名称を使うと保険業法の対象になる。「**メンテナンス契約**」「**整備費用**」として明示すること。プール金は利益源となり、修理発生時に充当する。台数増でリスクを分散できる。

**⚠️ 切り分けるべき別リスク**
機材の破損・故障に対する自家保険は合理的だが、**デモ中に第三者（顧客の従業員等）が怪我をした場合の対人賠償責任は性質がまったく異なる**。医療費・賠償額は数百万円規模になり得るため、**対人賠償責任保険（PL保険等）の要否は別途確認が必要** 🔲

## 6.3 故障対応ルール

| ケース | 対応 |
|---|---|
| 輸送中の破損 | 運送会社の責任 |
| 初期不良・自然故障 | **無償対応** |
| 顧客の過失による故障 | **有償修理** |
| 構築済み部品（端子処理済等） | 顧客に**買い取り** → ロボット本体のみ回収 |
| 高価部品（アルミフレーム等） | **再利用**のため回収 |

- 対応は**センドバック方式**（代替品を先送りし、故障品を回収）
