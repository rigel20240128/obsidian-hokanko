# 01　事業概要・製品

## 1.1 コンセプト

> **「自動化したいが、設備を扱える自社技術者がいない」——この一点に絞る。**

- **自社技術者の育成が自動化の前提**という思想のもと、FA機器を「買う」ではなく「借りる」教育システムとして提供する
- 工場の生産設備とは別の「**教育専用設備**」を顧客先に設置し、現場に影響を与えずに実践的に学べる環境をつくる
- 故障診断を組み込み、**"壊す→直す" サイクル自体を教育とする**逆転の発想を採用

**この一文から外れる機能・サービスは足さない。** 判断に迷ったら「技術者育成に効くか」で切る。

## 1.4 納品形態

**「コンプリートキット」方式に統一**（完成品納品は行わない）

- **完成品ではなく、バラバラの状態で必要部材が一式そろった「コンプリートキット」として送付する**
- 顧客は開梱後、自ら組み立てるところから学習が始まる
- 理由：①**組み立て工程そのものが最も重要な教育である** ②運営側の組立工数が削減される ③輸送時の破損リスクが下がる
- キット内容：**アルミフレーム・アルミ板（標準搭載品）**、部材一式、結束バンド、ダクト、推奨工具リスト、組立手順書
- **アルミフレームは全プラン共通の標準搭載品とする**（オプション扱いにしない）。架台を顧客側で用意させると、剛性・寸法のばらつきで学習環境が揃わず、サポート負荷が跳ね上がるため
- 工具（ニッパー、ストリッパー、端子用圧着ペンチ等）は**顧客側で用意**
- **「コンプリート」＝追加購入なしでその Level の学習が完結する構成**であることを対外訴求の要点とする

# 02　料金・契約条件（プラン体系）

> **提供形態はリース（月額）専業。単体販売は行わない。**（2026-08-01 裁可）

## 2.1 料金の二本立て構造（2026-08-01 決定）

料金は「**月額リース料**」と「**初期費用（基本料金）**」の二本立てとする。

| 区分 | 性質 | 対象 | 契約終了後 |
|---|---|---|---|
| **月額リース料** | ストック収入 | ロボット本体・**アルミフレーム（標準搭載品）**等の**再利用可能な設備** | **回収**（整備して再投入） |
| **初期費用（基本料金）** | 一時収入 | キット内の**消耗品部品**（センサー、電線、圧着端子、マークチューブ等） | **顧客の資産として残る** |

**この構造の意味**
- 消耗品は一度加工・圧着してしまえば原状回復できないため、**最初から顧客の資産として買い取ってもらう**のが合理的
- 顧客側にも「学習の成果物が手元に残る」という明確な利点がある
- 自社側は消耗品の原価を**契約初月に全額回収**でき、キャッシュフローが安定する
- **基本料金の額はグレードによって異なる**（上位グレードほどセンサー・カメラ等の消耗品構成が高価になるため）
- **基本料金は消耗品原価と同額にしない。**（2026-08-06 改定）消耗品の調達・検品・梱包・発送はすべて代表1名の工数であり、原価と同額では売上が立っても粗利がゼロになる。**この工数分の対価を必ず上乗せする。** STANDARD は消耗品原価上限¥100,000に対し基本料金¥150,000（差額¥50,000が工数対価）

# 03　収益モデルと採算

## 3.1 基本構造

収益は次の3層で構成される。

| 層 | 性質 | 内容 |
|---|---|---|
| ① 初期費用（基本料金） | **一時収入** | 消耗品部品の買い取り。契約初月に全額入る |
| ② 月額リース料 | **ストック収入** | 設備の貸与。稼働台数に比例して積み上がる |
| ③ サポート料 | **フロー収入** | 訪問・オンラインの従量課金 |

- **①の導入により、消耗品の原価を契約初月に全額回収できる。**これが採算の安定に大きく効く

## 6.2 破損リスクの扱い（2026-08-06 全面改定）

> **旧「自家保険（月額保護料1万円）」モデルは撤回する。**

> 撤回した旧試算：月額保護料1万円×10件×12ヶ月＝年間収入120万円、想定損失最大30万円、差引＋90万円。

**方針：「補償を売る」のをやめ、「部品と役務を売る」形に組み替える。**

| 区分 | 扱い |
|---|---|
| 消耗品・少額部品（ヒューズ等） | **予備をキットに同梱**。顧客が自分で交換する |
| 顧客の過失で破損した部品 | **顧客が自費で同型式品を購入する** |
| **ロボット本体の破損** | **別途請求** 🔲（損傷程度に応じた算定基準は未定） |
| 初期不良・自然故障 | **無償対応**（第6.3章） |

- **貸出リストに型式を明記し、契約時に顧客へ提出する。** 破損時に顧客自身が同一型式品を調達できるため、当社が修理費を立て替えて請求する構造にならない＝**保険性が生じない**。第2.6章の返却検品リスト（10点以下）と同一様式で兼用する
- **「壊さないための構造」をマニュアルに明記する。** 誤配線を物理的に起こしにくい結線順序、通電前チェック項目、極性の確認手順など。**事故を減らすこと自体が最大のコスト対策**である
- **定額の「保護料」は徴収しない。**

> 🔲 **弁護士確認待ち。** 本節の建て付けは保険業法リスクの回避を目的に組んだものだが、最終判断は**弁護士**の確認をもって確定する（税理士の管掌外）。確認が済むまで対外資料に補償的な表現を書かないこと。

**想定される破損の実態（2026-08-06 追記）**

外部レビューで「初心者が扱う以上、誤配線による短絡・基板焼損が多発し、年3件・最大30万円の想定は甘い」と指摘されたが、**実態としての最大リスクは誤配線による「ヒューズ飛び」**であり、基板焼損やロボット本体の損傷ではない。

- 対策として**予備ヒューズ5個をキットに同梱**する。顧客が自分で交換できるため、センドバックも修理費も発生しない
- 「ヒューズが飛ぶ → 原因を調べて自分で交換する」こと自体が電気の基礎教育になり、第1.1章の"壊す→直す"設計と整合する
- 🔲 予備5個を超えて飛んだ場合の扱い（追加送付は有償か無償か、上限を設けるか）は未定

**運用上の名称に注意**：「保険」という名称は使わない。ただし**名称の言い換えだけでは保険業法リスクは消えない**（上記のとおり実態で判定される）。「メンテナンス契約」「整備費用」という名称に変えて定額補償を続ける旧案は採らない。

**⚠️ 切り分けるべき別リスク**
機材の破損・故障に対する自家保険は合理的だが、**デモ中に第三者（顧客の従業員等）が怪我をした場合の対人賠償責任は性質がまったく異なる**。医療費・賠償額は数百万円規模になり得るため、**対人賠償責任保険（PL保険等）の要否は別途確認が必要** 🔲

## 6.3 故障対応ルール

| ケース | 対応 |
|---|---|
| 輸送中の破損 | **運送保険で填補する**（往路＝当社が付保・当社負担／復路＝顧客が付保・顧客負担。下記参照） |
| 初期不良・自然故障 | **無償対応** |
| **ヒューズ飛び（誤配線）** | 同梱の**予備ヒューズ5個**で顧客が自ら交換（第6.2章） |
| 顧客の過失による部品破損 | **顧客が自費で同型式品を購入**（貸出リストの型式による／2026-08-06改定） |
| **顧客の過失によるロボット本体の破損** | **下記「破損時の請求（3段階）」による** |
| 構築済み部品（端子処理済等） | 顧客に**買い取り** → ロボット本体のみ回収 |
| 高価部品（アルミフレーム等） | **再利用**のため回収 |

- 対応は**センドバック方式**（代替品を先送りし、故障品を回収）

#### 過失と自然故障の切り分け（2026-08-06決定）

判定を人の裁量に委ねず、**日数で機械的に切る。**中古機体を貸す以上「最初から壊れていた」という主張は必ず生じ、証拠がなければ争いになるため。

- **開梱時チェックを義務化する。**顧客は開梱時に所定のチェックを行い、**写真を提出**する。これをもって初期状態を確定させる
- **到着後7日以内の申告のみを初期不良として扱う。**それ以降の申告は**原則として過失と推定する**
- 🔲 開梱チェックリストの様式は未作成（貸出リスト・返却検品リストと一枚で兼用する形にすること）

#### 出荷前整備基準と機体履歴台帳（2026-08-06決定）

1台¥50,000程度の中古機を貸す以上、自然故障の頻度は新品と同列に論じられない。**無償対応の範囲が青天井になることを防ぐ。**

- **出荷前チェックリスト**を定め、貸出前に必ず実施する
- **機体ごとに稼働履歴と故障履歴を記録する**（機体履歴台帳）
- **同一機体で自然故障が2回続いた場合は退役させる。**個体単位で損切りし、赤字機体を持ち回らない
- 🔲 出荷前チェックリスト・機体履歴台帳の様式は未作成

#### 破損時の請求（3段階／2026-08-06決定）

**細分化した部位別の定額表は作らない。** 破損ケースを列挙するほど、顧客に「壊したときのこと」ばかりを想起させ、契約の障壁になるため。**程度による3段階のみとする。**

**請求額は3段階（¥50,000／¥100,000／¥400,000）とし、それに満たないものは請求しない。**

| 段階 | 状態 | 請求額 |
|---|---|---:|
| **通常損耗** | 使用に伴う軽微な擦れ、**清掃で落ちる汚れ** | **請求なし** |
| **軽度** | **外観の損傷。塗装の汚損・塗装の割れ・転倒による傷 等**（動作には影響しない） | **¥50,000** |
| **中度** | **部品交換で復旧する**（基板破損、落下による軸の破損 等） | **¥100,000** |
| **重度** | **復旧不能**（水没 等）、および**紛失・未返却** | **¥400,000** |

> **通常損耗と軽度の境**：**清掃で原状回復できるものは請求しない。**再塗装や部品交換を要する汚損・割れ・傷は軽度とする。

**運用の原則**

- **返却時に状態を確認して段階を判定する。**機械には程度があるため、事前に部位で決め打ちしない
- **判定は写真で記録し、顧客へ提示してから請求する。**透明性がなければ金額の妥当性を争われる
- **複数箇所が破損しても、請求の上限は重度額（¥400,000）を超えない**
- 本体の**分解・改造は禁止行為**とし、痕跡が認められた場合は程度に応じて中度または重度として扱う
- 🔲 定額は中古調達価格に連動するため、**年1回見直す**

#### 運送保険（2026-08-06決定）

**輸送中の破損は「運送会社の責任」では回収できない**（梱包不良を理由に免責されるのが通例）。**保険で填補する建て付けに改める。**

| 区間 | 付保する者 | 費用負担 |
|---|---|---|
| **往路（納品）** | **当社** | **当社負担** |
| **復路（返却）** | **顧客** | **顧客負担**（送料と同じ扱い） |

- 復路は顧客が発送するため、**返送手順書に「品名・申告価額を記載し、保険を付して発送すること」を明記して同梱する**。付保漏れのまま発送して破損した場合は顧客責任とする
- 🔲 一般の宅配便は**補償上限が30万円程度**。STANDARD一式（本体＋アルミフレーム）の再調達価額がこれを超えるなら**別建ての運送保険（貨物保険）が必要**。運送会社へ確認すること
- 本件は**保険会社の正規商品に当社が契約者として加入する**ものであり、第6.2章で撤回した自家保険とは性質が異なる（保険業法上の問題は生じない）

#### 代替品の発送と予備在庫（2026-08-06決定）

センドバック方式は予備機なくして成立しない。

| 項目 | 定め |
|---|---|
| **代替品の発送期限** | **3〜5営業日以内に発送**。この体制を常時整えておく |
| **予備在庫** | **稼働8台に対して2台**（＝稼働4台につき予備1台）。**最低2台は常時確保する** |

- 対外表記は「**3〜5営業日以内**」とする（土日を挟むと暦日では守れないため）
- **稼働台数の増加に合わせて予備機も増やす。**稼働8台までは2台、以降は稼働4台増ごとに予備1台を追加する（稼働12台＝3台、16台＝4台）
- 予備機は返却機を整備して充当する。**第10章の台数目標を更新する際は、予備機の必要数も併せて見直すこと**
- **現況（2026-08-08）：JR3203 を8台所有。配分は 6台稼働／2台予備。**稼働を8台へ引き上げる際は予備2台を追加調達し計10台とする。個体の内訳は [[所有機体台帳]]

**「速さ」の売り方（2026-08-06決定）**

電話サポートは新設しない。**急ぐ需要はオンラインへ集約し、訪問には時間保証を付けない。**

| 顧客の需要 | 提供するもの |
|---|---|
| 急いでいる | **オンラインサポート（¥10,000/時間・Teams）を当日〜翌営業日の枠で提供** |
| どうしても人に来てほしい | **訪問サポート（¥100,000/日・交通費別）。日程は調整のうえ確定**（時間保証なし） |
