# RTS 顧客リスト（営業資料）

> **本ファイルは営業活動で実際に使う顧客候補の名簿である。**
> 事業の方針・料金は [[基本概念]]、営業戦略は [[RTS営業戦略]] を正本とし、本ファイルは**候補企業・学校の実データのみ**を管理する。
> 対象エリアは **関東全域**。調査の進捗に応じて随時追記する。
>
> **更新したら必ず冒頭の `更新日時` を書き換えること。**

---

## 01　抽出方法（確立済み・再現可能）

**gBizINFO（経済産業省）の詳細検索を使う。無料で実在・実数の企業を取得できる。**

### 手順

```
① gBizINFO の詳細検索を開く
② 都道府県・市区町村を指定
③ 業種＝製造業 を指定
④ 検索結果から従業員数50人以下を目視で抽出
⑤ 本ファイルの該当エリアの表へ追記
```

### この方法に至った経緯

- 当初は**売上高・資本金での絞り込み**を試みたが、これらは**有価証券報告書提出企業（上場企業クラス）向けの項目であり、中小企業にはデータがほぼ存在しない**ことが判明した
- 代わりに、gBizINFO が**職場情報（労働条件等）として企業から任意登録された実際の従業員数**を保持していることを発見し、これを絞り込み軸に切り替えた
- Web検索で1社ずつ裏取りする方式より遥かに効率が良い（手動Web検索では9社が限度だった）

### 抽出条件

| 項目 | 条件 |
|---|---|
| 業種 | 製造業 |
| 法人種別 | 株式会社・有限会社・合同会社 |
| 従業員数 | **50人以下** |
| エリア | **関東全域**（下記02参照） |

## 08　運用ルール

- 初回コンタクトは**すべてメール**。返信があった先のみオンライン商談 → 有望案件のみ現地訪問
- 送付前に**必ず公開情報で事業内容を裏取りする**（「実機をお持ちの御社であれば」等の決めつけは、外すと無礼になる）
- 抽出した企業情報はすべて本ファイルで一元管理し、**二重連絡や取りこぼしを防ぐ**
- 展示会で獲得した名刺も、スキャン後に本ファイルへ統合する
- **本ファイルを更新したら、冒頭の `更新日時` を必ず書き換える**
