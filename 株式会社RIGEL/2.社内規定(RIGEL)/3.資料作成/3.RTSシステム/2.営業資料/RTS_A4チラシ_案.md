## 裏面

**学習カバレッジ（全20レベル・4STEP）**

| STEP | 内容 |
|---|---|
| STEP1 | 配線と電気の基礎 — 安全・工具・電源の基礎、被覆剥きと圧着、接点（A接点／B接点）、出力形式（PNP／NPN） |
| STEP2 | センサーと空圧 — 光電センサ・近接センサ・レーザーセンサ、ポカよけ、電磁弁、シリンダー |
| STEP3 | 制御とプログラム — PLCラダー基礎、タッチパネル、シリアル通信・Ethernet/IP・Profinet、モータ制御 |
| STEP4 | 画像処理と総合 — ビジョンシステム、欠品検査、総合トラブルシューティング（"壊す→直す"） |

（対外資料ではSTEP単位で説明し、Levelは学習進捗の管理単位として使う — [[基本概念]]1.3節）

**プラン・契約条件**

| 項目 | 内容 |
|---|---|
| 対応レベル | Level 1〜18（STEP1〜3） |
| 納品形態 | コンプリートキット（郵送。御社で開梱・組立） |
| 標準搭載 | アルミフレーム・アルミ板（全プラン共通） |
| 契約期間 | 最短3ヶ月〜最長24ヶ月 |
| 想定対象 | 中小の小型部品製造・組立業、専門学校 |
