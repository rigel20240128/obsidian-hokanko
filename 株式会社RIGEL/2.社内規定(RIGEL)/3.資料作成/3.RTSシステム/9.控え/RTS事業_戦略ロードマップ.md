## 1. RTSが解く問題（提供価値の一文）

> **「自動化したいが、設備を扱える自社技術者がいない」**——この一点に絞る。

- 顧客の真の障害は設備の価格ではなく、**導入後に運用できる人がいないこと**
- RTSは生産設備とは切り離した「教育専用設備」を貸すことで、**現場を止めずに技術者を育てる**
- 故障診断を組み込み、"壊す→直す" 自体を教材化する（他社にない構造）

**この一文から外れる機能・サービスは足さない。** 判断に迷ったら「技術者育成に効くか」で切る。

## 2. 事業フェーズの設計

### Phase 1｜実証と第一号（2026年11月 〜 2027年3月）

**目的：レンタルが回ることを1社で証明する。売上より「回る」ことが優先。**

| 項目 | 目標 |
|---|---|
| 稼働台数 | 2台（保有11台のうち） |
| 顧客数 | 1〜2社 |
| チャネル | 人脈・紹介が主。商社は打診開始のみ |
| 検証すること | ①キット納品で顧客が自力で組めるか ②メール＋写真のサポートで完結するか ③返却機の整備コストが想定内か |

- **この期の最大リスクは「サポートが電話対応化して1人体制が破綻すること」。** メール受付・写真添付必須のルールを最初の1社で必ず守り切る
- 第一号顧客は**近距離（千葉・柏近辺）から選ぶ**。トラブル時に自分で行ける距離であることを優先する 🔲

### Phase 2｜商社チャネルの確立（2027年4月 〜 2027年12月）

**目的：自分が営業しなくても引き合いが来る状態を作る。**

| 項目 | 目標 |
|---|---|
| 稼働台数 | 4〜6台 |
| 商社 | 2〜3社と取引開始（緑屋テクノ／和泉産業／五光社／ライト／柳田機器 が候補） |
| 施策 | A4両面チラシ配布、展示会2〜3回、YouTube公開動画の運用開始 |
| 補助金 | 小規模事業者持続化補助金〈創業型〉でPR資料・HP費用を回収 |

- 商社は「誰でもウェルカム」だが、**RTSを理解して説明できる担当者が1人いる商社**でなければ機能しない。社数より担当者の質で選ぶ
- **休眠JANOMEロボットの掘り起こし**をこの期の目玉施策とする。JANOMEは直販でエンドユーザーが不明のため、「遊休のJANOMEロボット、ありませんか？」の発信が最も効率の良いリード獲得口になる

### Phase 3｜上位モデルと全国展開（2028年 〜 2029年）

**目的：単価を上げ、大企業の生産技術部門を取りに行く。**

| 項目 | 目標 |
|---|---|
| 稼働台数 | 10台以上 |
| 施策 | ものづくり補助金（補助率2/3）で上位モデルのデモ機を導入 |
| 地域 | 関東 → 全国 |
| 顧客層 | 中小の基板メーカーに加え、大企業の生産技術部門・専門学校/大学 |

### Phase 4｜海外・ODA（2031年〜／5年目以降）

- ODA（政府開発援助）ルートでの発展途上国向け技術教育を狙う
- **Phase 3 で国内のリモートサポート体制が確立していることが前提。** 先行して着手しない

| 3年目（2029年） | 10台 | 約1,000万円〜 | 上位モデル投入で単価上昇 |
| 5年目（2031年） | — | 年商2億円（全事業） | 基本概念.md 5.3 の目標 |
| 10年目（2036年） | — | 年商10億円（全事業） | 同上 |

> 試算根拠：スタンダード自社受取 約¥84,150/月 × 12ヶ月 × 稼働台数。上位モデル・サポート収入は含まない。

**⚠️ 事業計画書との不整合（要対応）**
`2.事業計画書・融資/事業計画書_統合版マスター.md` は「RTS販売 198〜300万円/台・売上シェア40%」を前提に1期1,500万円を組んでいる。リース専業に一本化した以上、**販売40%分の売上根拠が消える**。金融機関へ提出済み／提出予定の数値であるため、次のいずれかを選ぶ必要がある。🔲

1. FA設備事業の比重を上げて売上構成を組み直す（RTSはストック収入として控えめに計上）
2. リース稼働台数を上積みして補う（保有11台を前提にすれば台数余地はある）
3. 「RTS販売」を残す（＝リース専業の決定を撤回する）

→ **税理士・公庫担当との相談事項。ここが未決のまま融資面談に臨まないこと。**

## 4. 1人経営を前提とした制約

RTSの設計はすべて「**代表1名で回ること**」を制約条件とする。これに反する施策は、売上が見込めても採用しない。

| 制約 | 具体化 |
|---|---|
| 訪問しない | 郵送納品・原則訪問なし。訪問は有償オプションのみ |
| 電話を受けない | メール受付＋写真添付必須＋状況記入フォーマット。1営業日以内返信 |
| 組み立てない | キット納品。組立工数は顧客側（＝教育効果と工数削減の両立） |
| 個別対応しない | トラブルシューティングは会員限定動画・ドキュメントに蓄積し、2回目以降は参照させる |
| 作らない | ロボット本体・部品は原則中古調達。自社製造しない |

- **サポートの属人化＝事業の上限。** 問い合わせが来たら回答すると同時に、必ず会員サイトのコンテンツに変換する
- マニュアル・動画はAI生成画像で作る（実写撮影しない）

## 5. 差別化の維持（守るべき堀）

| 差別化要素 | 競合が真似しにくい理由 |
|---|---|
| **複数メーカー機器の統合**（JANOME／KEYENCE／SMC／パナソニック／MISUMI） | メーカー直営デモ機は自社製品しか載せられない。**これが最大かつ決定的な差別化** |
| 故障の教材化（"壊す→直す"） | 通常の教育サービスは故障を避ける設計思想のため発想が逆 |
| 4〜5段階の体系的カリキュラム | 単発の受託研修では積み上がらない |
| キット組立方式 | 完成品を貸す競合は「触って終わり」になる |
| 20年のFA設備設計実務 | 教材の妥当性を担保する経歴そのものが参入障壁 |

**この5つを薄める方向の意思決定はしない。** 特に「複数メーカー統合」は、単一メーカーとの独占的提携と引き換えに失いやすい。JANOMEとの協業でも、他社機器を載せる自由は手放さない 🔲
