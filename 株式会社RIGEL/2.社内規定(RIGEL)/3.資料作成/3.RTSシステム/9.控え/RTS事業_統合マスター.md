# 01　RTSとは何か（製品・運用の正本）

> 出典：`基本概念.md`（最終更新 2026-08-01）

## RTS事業 需要とターゲット調査


### 1. 事業概要・製品 (RTS)

#### 1.1 コンセプト
- **自社技術者の育成が自動化の前提** という思想のもと、FA機器を「買う」ではなく「借りる」教育システムとして提供
- 工場の生産設備とは別の「教育専用設備」を顧客先に設置し、現場に影響せず実践的に学べる環境を提供
- 故障診断を組み込み "壊す→直す" サイクル自体が教育となる逆転の発想を採用

#### 1.2 学習カバレッジ (網羅領域)
- I/O基礎:：ライトオン / ダークオン、A接点 / B接点、PNP / NPN、ポカよけ
- センサー：光電センサ、レーザー、近接センサ、マイクロスイッチ
- 電気配線：ワイヤーストリッパーでの被覆向き、圧着工具でのカシメ、マークチューブ
- 空圧機器：電磁弁（シングル、ダブル）、シリンダー（ロータリー、スライドテーブル、ロッド）
- 通信：シリアル通信、Ethernet/IP、Profinet
- モータ制御: サーボ、パルスモーター
- 画像処理: ビジョンシステム (欠品検査など)
- **複数メーカー機器の統合** が最大の差別化:
  - JANOME (制御ロボット) PLC機能搭載
  - KEYENCE (PLC、タッチパネル、画像処理、センサー)
  - SMC (シリンダー・電磁弁)
  - パナソニック (画像処理)
  - MISUMI（機構部品）

#### 1.3 レベル構成 (4〜5段階)
| # | レベル | 内容 |
|---|------|------|
| 1 | Level 1 | I/O基礎 |
| 2 | Level 2 | 空圧・オートスイッチ |
| 3 | Level 3 | シリアル通信、Ethernet/IP、サーボ/パルスモーター制御 |
| 4 | Level 4 | 画像処理 (ビジョンシステム) |
| 5 | Level 5 | (上位モデル: 検査・エラー対応を含む総合) |

#### 1.4 納品形態
- **完成品** か **組み立てキット (バラバラ)** の2方式のうち、組み立てキット方式に統一
  - 理由: 教育効果が最大化される & 運営側の組立工数が削減される
- キット内容: アルミ板・ベースフレーム、部材一式、結束バンド、ダクト、推奨工具リスト
- 工具 (ニッパー、ストリッパー、端子用圧着ペンチ等) は**顧客側で用意**してもらう方針

- 来場者名刺スキャンは必ず実施 → AI分析 → Obsidian保存 → リード管理

#### 3.4 商社マージン体系

### 5. 成長戦略・収益モデル

#### 5.1 収益モデルの基本構造（リース専業）

**RTSはリース（月額）専業とする。単体販売は行わない。**（2026-08-01 決定）

- 収益は「月額リース料 × 稼働台数」の**ストック型**。単発の売り切りは行わない
- 理由：①原価回収後は同一機体が利益を生み続ける ②顧客の初期投資障壁が消える ③信販会社を挟むことで与信・回収リスクを外部化できる
- サポート（訪問・オンライン）は**リース料と別建ての従量収入**。リース会社経由で合算請求する

| 収益源 | 性質 | 単価 |
|---|---|---|
| 月額リース料（スタンダード） | ストック | ¥99,000 / 月〜 |
| 月額リース料（上位モデル） | ストック | ¥399,000 / 月〜 |
| 訪問サポート | フロー | ¥100,000 / 日（交通費別） |
| オンラインサポート | フロー | ¥10,000 / 時間 |

#### 5.2 1台あたりの採算（ユニットエコノミクス）

| 項目 | スタンダード | 上位モデル |
|---|---:|---:|
| 1台原価 | ¥300,000 | ¥1,200,000 |
| 月額リース料 | ¥99,000 | ¥399,000 |
| 商社・信販マージン（15%） | ▲¥14,850 | ▲¥59,850 |
| 自社受取（月） | 約¥84,150 | 約¥339,150 |
| **原価回収期間** | **約3.6ヶ月** | **約3.6ヶ月** |
| 最短契約（3ヶ月）時の回収率 | 約84% | 約85% |
| 最長契約（24ヶ月）時の累計受取 | 約¥2,020,000 | 約¥8,140,000 |

- **回収後は同一機体が利益を生み続ける**のがこのモデルの核心。返却機は整備して再投入する
- 最短契約3ヶ月では原価回収がわずかに届かない。**回収を確実にするなら最低契約期間を4ヶ月とするか、初期費用（セットアップ費）を別途設定する必要がある** → 未決事項（第11章参照）
- ロボット本体は原則中古調達（¥50,000/台程度）とし、上記原価をさらに圧縮する

> ※上表は第2章の料金・原価と第3.4章のマージン15%から機械的に算出した試算。実際の信販手数料率が確定した時点で再計算すること。

#### 5.3 段階的成長ロードマップ
- 段階的台数拡大: 導入 → 3ヶ月後 +1台 → 6ヶ月後 +5台 → 右肩上がり
- **5年後目標: 年商 ¥200,000,000 (2億円)**
- **10年後目標: 年商 ¥1,000,000,000 (10億円)** (RTS事業以外も含む)

#### 5.4 地域展開
- **1年目**: 関東圏 (千葉近辺) 基盤固め
- **2年目以降**: 全国レベルへ拡大
- **5年目以降**: 海外 (ODA含む) 展開

#### 5.5 ものづくり補助金活用
- **申請準備: 2027年3月から書類作成**
- **申請: 2027年7月**
- **補助率: 2/3** (採択後、上位モデルのデモ機購入に充当)

#### 5.6 ロボットの仕入れ戦略
- **原則中古ベース**: ロボット本体 ¥50,000/台 程度
- センサーも ¥2,000 程度の低価格品で対応可能とする (耐久性は下がるがコスト最優先)
- 部品も中古調達で原価圧縮

### 6. リース・信販スキーム (契約・法務)

#### 6.1 採用する信販会社
**メイン: ちばぎんリース** (千葉銀行グループ)
- 千葉銀行をメインバンクに統一
- 資金調達とリースを一本化
- サポート費用もリース料と合算請求

**その他選択肢 (大手)**:
- ORIX
- 三井住友ファイナンス&リース
- 東京センチュリー
- 三菱HCキャピタル
- みずほリース

#### 6.2 古物商許可
- 中古ロボットの取扱にあたり **古物商許可申請が必要** (実施予定)

#### 6.3 法人運営における留意点
- 法人税は利益に連動して増加 → **税理士相談** を活用
- **資金繰り (キャッシュフロー) 管理が最優先**
- 株式会社の自己資本減少リスクに注意

#### 6.4 自己保険的プール制度
- **整備費名目** で社内にリスクプール資金を積立て
  - 「保険」という名称を使うと保険業法の対象になるため注意
  - 「メンテナンス契約」「整備費用」として明示するのが安全
- プール金が利益源になり、修理発生時に充当
- 台数増でリスクをプールできる

#### 6.5 故障対応ルール
| ケース | 対応 |
|------|------|
| 輸送中破損 | 運送会社責任 |
| 初期不良・自然故障 | 無償対応 |
| 顧客過失による故障 | 有償修理 |
| 構築済み部品 (端子処理済等) | 顧客に **買い取り** → ロボット本体のみ回収 |
| 高価部品 (アルミフレーム等) | **再利用** のため回収 |

### 7. 納品・サポート運用フロー

#### 7.1 納品
- 基本 **郵送納品** (箱のまま送付)
- 顧客先で開梱・セットアップ
- 原則 **訪問なし** (コスト削減)
- 有償訪問サポートはオプション提供

#### 7.2 サポートポリシー
- **メール受付** (電話受付は基本的になし)
- 問い合わせ時は **写真添付必須 + 状況記入フォーマット** を指定
- **1営業日以内に返信**
- **センドバック方式** (代替品先送・故障品回収)
- 故障対応そのものが教育になる設計 → カリキュラムにトラブルシューティングを組み込む

#### 7.3 マニュアル・動画
- AI で生成した画像でステップ解説 (実写撮影なし)
- **Imagen / Nano Banana系** で画像生成
- 組み立て手順をステップ1, 2, 3... と段階表示
- 完成後は返却してもらうが、消耗部品は顧客側に残るため無駄がない

#### 7.4 会員サイト・認証システム
| 区分 | 内容 |
|------|------|
| 一般公開 (YouTube等) | 商品紹介・PR・認知拡大 |
| 会員限定エリア | トラブルシューティング詳細、専門ノウハウ |

- **認証方式**: 顧客ID + 電話番号下4桁 でログイン
- データベースで有効期限管理 → 期限切れID自動無効化
- 会員用動画は限定公開で埋め込み → Obsidian側で認証ゲート制御

- **メーカー直営デモ機**: 単一メーカー → RTS は複数メーカー統合 (ここが決定的な差別化)

> **本書の位置づけ**：[[基本概念]] が「RTSとは何か（仕様・運用の事実）」を記す正本であるのに対し、本書は「**どこへ向かうか・何を先にやるか**」を記す。判断が変わったら本書を先に直し、基本概念.md へ反映する。

---

### 0. 確定している大方針

| # | 方針 | 状態 |
|---|---|---|
| 1 | **リース専業**。単体販売は行わない | ✅ 2026-08-01 裁可 |
| 2 | 納品は**組み立てキット方式**に統一（完成品納品はしない） | ✅ |
| 3 | 販路は**商社経由**をメインとする（直販は補助） | ✅ |
| 4 | 主戦場は**関東圏・中小の基板/電子部品メーカー** | ✅ |
| 5 | 避ける業界：自動車・医療・食品 | ✅ |
| 6 | 信販メインは**ちばぎんリース**（千葉銀行と一本化） | ✅ |

---

### 1. RTSが解く問題（提供価値の一文）

> **「自動化したいが、設備を扱える自社技術者がいない」**——この一点に絞る。

- 顧客の真の障害は設備の価格ではなく、**導入後に運用できる人がいないこと**
- RTSは生産設備とは切り離した「教育専用設備」を貸すことで、**現場を止めずに技術者を育てる**
- 故障診断を組み込み、"壊す→直す" 自体を教材化する（他社にない構造）

**この一文から外れる機能・サービスは足さない。** 判断に迷ったら「技術者育成に効くか」で切る。

---

### 2. 事業フェーズの設計

#### Phase 1｜実証と第一号（2026年11月 〜 2027年3月）

**目的：レンタルが回ることを1社で証明する。売上より「回る」ことが優先。**

| 項目 | 目標 |
|---|---|
| 稼働台数 | 2台（保有11台のうち） |
| 顧客数 | 1〜2社 |
| チャネル | 人脈・紹介が主。商社は打診開始のみ |
| 検証すること | ①キット納品で顧客が自力で組めるか ②メール＋写真のサポートで完結するか ③返却機の整備コストが想定内か |

- **この期の最大リスクは「サポートが電話対応化して1人体制が破綻すること」。** メール受付・写真添付必須のルールを最初の1社で必ず守り切る
- 第一号顧客は**近距離（千葉・柏近辺）から選ぶ**。トラブル時に自分で行ける距離であることを優先する 🔲

#### Phase 2｜商社チャネルの確立（2027年4月 〜 2027年12月）

**目的：自分が営業しなくても引き合いが来る状態を作る。**

| 項目 | 目標 |
|---|---|
| 稼働台数 | 4〜6台 |
| 商社 | 2〜3社と取引開始（緑屋テクノ／和泉産業／五光社／ライト／柳田機器 が候補） |
| 施策 | A4両面チラシ配布、展示会2〜3回、YouTube公開動画の運用開始 |
| 補助金 | 小規模事業者持続化補助金〈創業型〉でPR資料・HP費用を回収 |

- 商社は「誰でもウェルカム」だが、**RTSを理解して説明できる担当者が1人いる商社**でなければ機能しない。社数より担当者の質で選ぶ
- **休眠JANOMEロボットの掘り起こし**をこの期の目玉施策とする。JANOMEは直販でエンドユーザーが不明のため、「遊休のJANOMEロボット、ありませんか？」の発信が最も効率の良いリード獲得口になる

#### Phase 3｜上位モデルと全国展開（2028年 〜 2029年）

**目的：単価を上げ、大企業の生産技術部門を取りに行く。**

| 項目 | 目標 |
|---|---|
| 稼働台数 | 10台以上 |
| 施策 | ものづくり補助金（補助率2/3）で上位モデルのデモ機を導入 |
| 地域 | 関東 → 全国 |
| 顧客層 | 中小の基板メーカーに加え、大企業の生産技術部門・専門学校/大学 |

#### Phase 4｜海外・ODA（2031年〜／5年目以降）

- ODA（政府開発援助）ルートでの発展途上国向け技術教育を狙う
- **Phase 3 で国内のリモートサポート体制が確立していることが前提。** 先行して着手しない

### 4. 1人経営を前提とした制約

RTSの設計はすべて「**代表1名で回ること**」を制約条件とする。これに反する施策は、売上が見込めても採用しない。

| 制約 | 具体化 |
|---|---|
| 訪問しない | 郵送納品・原則訪問なし。訪問は有償オプションのみ |
| 電話を受けない | メール受付＋写真添付必須＋状況記入フォーマット。1営業日以内返信 |
| 組み立てない | キット納品。組立工数は顧客側（＝教育効果と工数削減の両立） |
| 個別対応しない | トラブルシューティングは会員限定動画・ドキュメントに蓄積し、2回目以降は参照させる |
| 作らない | ロボット本体・部品は原則中古調達。自社製造しない |

- **サポートの属人化＝事業の上限。** 問い合わせが来たら回答すると同時に、必ず会員サイトのコンテンツに変換する
- マニュアル・動画はAI生成画像で作る（実写撮影しない）

### 5. 差別化の維持（守るべき堀）

| 差別化要素 | 競合が真似しにくい理由 |
|---|---|
| **複数メーカー機器の統合**（JANOME／KEYENCE／SMC／パナソニック／MISUMI） | メーカー直営デモ機は自社製品しか載せられない。**これが最大かつ決定的な差別化** |
| 故障の教材化（"壊す→直す"） | 通常の教育サービスは故障を避ける設計思想のため発想が逆 |
| 4〜5段階の体系的カリキュラム | 単発の受託研修では積み上がらない |
| キット組立方式 | 完成品を貸す競合は「触って終わり」になる |
| 20年のFA設備設計実務 | 教材の妥当性を担保する経歴そのものが参入障壁 |

**この5つを薄める方向の意思決定はしない。** 特に「複数メーカー統合」は、単一メーカーとの独占的提携と引き換えに失いやすい。JANOMEとの協業でも、他社機器を載せる自由は手放さない 🔲

# 04　競合調査

> 出典：`RTS競合調査報告書.md`（最終更新 2026-07-20）

【RTS事業 競合調査報告書】

■調査目的
RTS事業（産業用ロボット・FA設備の教育システムを月額レンタル形式（10-40万円/月）で提供する事業）について、
国内市場に同種・類似の競合サービスが存在するかを確認する。
RTSの主軸機材は、JANOME（ジャノメ）の卓上ロボット・直交ロボット・SCARAロボットであり、
垂直多関節ロボット（6軸アーム型）ではない点が本事業の前提。

■調査方法
Web公開情報をもとに、切り口を変えながら複数ラウンドの検索・検証を実施
（孔明＝調査、関羽＝集約、劉備＝精査という役割分担のイメージで反復確認し、精度を上げた）。
・1回目：産業用ロボット教育／研修サービス全般、レンタル・リース業界の概況
・2回目：ロボットレンタル各社（オリックス・レンテック、TECHNO REACH、ROBOT CLOUD等）の料金・教育機能の詳細確認
・3回目：JANOME関連、研修+レンタルのハイブリッド型、FA人材育成専門機関、スタートアップ動向の追加確認
・4回目（改訂）：事業主指摘を受け、TECHNO REACHを対象外に修正。「小型卓上ロボット」軸で再調査
・5回目（改訂）：事業主指摘を受け、バイナスの機材種別／アフレルDOBOTの位置づけを再確認し、
　「卓上・直交・SCARA（産業グレード）」「垂直多関節」「簡易教育用トイロボット」の3カテゴリに整理
調査日：2026年7月18日／改訂：2026年7月18日（2回）

■結論（サマリー）
RTSが構想する「JANOME系（卓上・直交・SCARA）の産業グレードFA教育システムを、月額定額でレンタル提供する」
という事業モデルにピンポイントで一致する競合は、公開情報の範囲では確認できなかった。
機材カテゴリを整理すると、既存の隣接プレイヤーは以下の3層に分かれ、いずれもRTSの機材軸（卓上/直交/SCARA×産業グレード）
とは完全には重ならないことが判明した。


■機材カテゴリの整理（重要）

| カテゴリ | 該当プレイヤー | 機材の実態 | RTSとの重なり |
|---|---|---|---|
| ①卓上・直交・SCARA（産業グレード） | JANOME、IAI 等（メーカー本体） | 実際の生産現場で使われる産業用ロボット | ◎機材は同一カテゴリだが、いずれも販売・自社講習が主で「教育システムのレンタル」事業は確認できず |
| ②垂直多関節ロボット（小型含む） | バイナス、デンソーウェーブ等のスクール | 6軸アーム型。小型でも構造・操作系がJANOME系と異なる | △機材カテゴリが異なる（課題設定は類似） |
| ③簡易教育用トイロボット | アフレル（DOBOT Magician）、ヴイストン（Academic SCARA Robot） | 570g〜1.5kg程度のプログラミング教材。産業グレードではなく玩具・教材グレード | △「卓上」「SCARA」という名称は似るが、実生産で使う機材とは精度・剛性・用途が別物 |

→ 産業グレードのJANOME系機材（卓上/直交/SCARA）を使い、なおかつ月額レンタルで教育システムとして提供する
　プレイヤーは、調査した範囲では見つからなかった。


■競合分析（カテゴリ別・詳細）

【A. ロボットメーカー直営スクール】一致度：低
- デンソーウェーブ、安川電機、ファナック、エプソン、パナソニック 等
- 単発講習が中心（2〜4日間、受講料2.9万〜11万円）。自社製ロボットのみが対象で、レンタル・月額課金なし
- IAI（JANOMEと同じ卓上・直交・SCARA領域の直接メーカー競合）についても、教育・研修やレンタルサービスの
　具体的情報は確認できず、自社製品の販売が主軸とみられる
→ RTSとは価格モデルが異なり、直接競合ではない

【B. ロボット単体レンタル業者（生産用・大型）】一致度：低（対象外に整理）
※訂正：TECHNO REACHは多関節の生産用ロボット（大型）のレンタルが中心で、RTSが想定する教育用の小型卓上ロボットとは
　対象サイズ・用途が異なるため、競合から除外（2026-07-18 事業主確認済み）。
- オリックス・レンテック「RoboRen」：CRX・UR・YuMi等、生産ライン向けの実機サイズが中心のため非該当
- ROBOT CLOUD：サブスク型ロボットレンタルポータル。貸出＋簡易レクチャー止まりで体系的教育カリキュラムなし
→ 生産用・大型ロボットのレンタル業者はRTSと機材カテゴリが異なり、直接競合ではない

【C. 研修＋レンタルのハイブリッド型】一致度：中
- セレンディップ・ロボクロス：協働ロボット研修（対象はユニバーサルロボット／テックマンのみ、垂直多関節・アーム型）。
　1日6万円（税抜）、研修後はレンタル機で延長訓練可
→ 研修とレンタルを組み合わせる提供方式はRTSと類似するが、機材がアーム型協働ロボットでJANOME系とは別カテゴリ

【D. FA人材育成専門機関】一致度：中（機材カテゴリは別）
- バイナス「DX人材育成教育センター」：「産業用ロボットを導入・運用したいが対応できる技術者がいない」という
　課題設定はRTSの問題意識とほぼ同一。ただし使用機材は「6軸小型垂直多関節ロボット」であることを確認
　（事業主指摘の通り、JANOME系＝卓上・直交・SCARAとは異なる機材カテゴリ）。技術研修＋教材提供、料金非公開
- FABIC：「ファンクショナル・アプローチ」という汎用問題解決手法の教育で、ロボット特化ではない
- ワクコンサルティング／Insource／WinSchool：製造業向け一般研修、ロボット実機のハンズオン教育ではない
→ 課題設定（技術者不足）は最も近いが、機材カテゴリが垂直多関節でありJANOME系とは異なるため、
　機材面での直接競合ではない。ただし将来的に卓上・SCARA領域へ展開してくるリスクは残る

【E. 簡易教育用トイロボット】一致度：低〜中（機材の"小ささ"は似るが産業グレードではない）
- アフレル（DOBOT Magicianシリーズ正規代理店）：A4用紙1枚分の設置面積で使える教育用卓上ロボットアーム（4軸/6軸）。
　購入価格は本体約13〜15万円。全国150校以上の教育機関で導入実績あり。対象は主に学校・教育機関
- ヴイストン「Academic SCARA Robot」：SCARA型の教育教材。サイズ210×230×200mm、重量約570g、USB HID接続、
　座標変換やモーター制御を学ぶプログラミング教材。学校向け、レンタル・企業研修モデルは確認できず
→ 事業主指摘の通り、これらは「教育用の簡易ロボット」であり量産FA用の産業グレード機材ではない。
　「卓上」「SCARA」という名称の一致はあるが、実際の生産現場の精度・剛性・制御方式とは別物で、
　FA技術者が現場で使う実機での技能習得を目的とするRTSとは訴求点が根本的に異なる


■RTSの差別化ポイント（総合評価）
①月額定額レンタル制（10〜40万円/月）で「教育システムそのもの」を提供する例は見当たらない
②JANOME系（卓上・直交・SCARA）という産業グレード機材を、複数メーカー横断でカバーする教育事業は競合に見当たらない
③「技能継承・技術者不足」という中小製造業の経営課題への直接訴求は、バイナス以外にほぼ見られない
　（ただしバイナスは機材カテゴリが異なる＝垂直多関節）
④「産業グレードの実機」で学べる点は、簡易教育用トイロボット（DOBOT Magician、Academic SCARA Robot）に対する
　明確な優位性となる（現場で実際に使う機材とそのまま同じため、習得したスキルがそのまま実務に直結する）
⑤営業資料・動画教材・SNS発信・CRM構築等、AIを活用した周辺業務効率化を前提に事業全体を設計している点は、
　調査した競合には見られない独自性

総括：「JANOME系（卓上/直交/SCARA）×産業グレード×月額レンタル×FA技術者の技能継承特化」という
4条件を同時に満たす競合は、現時点で確認されていない。


■リスク・留意点
・本調査はWeb公開情報が中心であり、非公開の新規参入企業や地域密着型の小規模事業者までは捕捉しきれていない可能性がある
・バイナスが将来的に卓上・直交・SCARA領域の機材を教育ラインナップに追加した場合、機材面でも直接競合化するリスクがある
・IAI（JANOMEの直接的な製品競合メーカー）が自社で教育レンタル事業に参入した場合、最も脅威度の高い競合になりうる
・アフレル／ヴイストンが「簡易教材」から「産業グレード機材の教育レンタル」へ事業を拡張してくる可能性はゼロではない


■提言
・「JANOME系・産業グレード機材×月額レンタル×FA技術者の技能継承特化」という差別化軸を
　事業計画書・営業資料に明確に打ち出すべき（特に④の「実機で学べる」という優位性は訴求力が高い）
・準競合として以下を定点観測することを推奨
　－バイナス：課題設定（技術者不足）が酷似。卓上・直交・SCARA領域への展開有無を継続確認
　－IAI：JANOMEと同カテゴリの機材メーカー。教育・レンタル事業への参入可能性を定期チェック
　－セレンディップ・ロボクロス：研修＋レンタルのハイブリッド型という提供方式が類似
・参入障壁が低い領域のため、早期のサービス開始とJANOME特化・複数メーカー横断の強みを生かした差別化のスピードが重要

### ④ 補助金まわりの考察（企業向け・学校向け 多角的に確認）

#### 企業向け

* **ものづくり補助金（製品・サービス高付加価値化枠）**：ロボット本体・周辺機器・制御ソフトも対象経費に含まれる。こちらも購入前提の制度。

#### 学校向け（新規調査分）
* **私立学校施設整備費補助金（私立大学・大学院等教育研究装置施設整備費）**：私立大学の教育研究装置整備を対象とする文部科学省の補助金。埼玉工業大学のような私立大学が対象になり得る。
* **専修学校関係施設・設備補助金／私立専修学校教育環境整備費助成事業**：専修学校（日本工学院等）向けの設備助成。都道府県ごとに制度があり、教育用機械器具の購入費用が対象。

#### 共通の重要論点
**企業向け・学校向けいずれの補助金も「購入」を前提とした設計になっており、RTSの「月額レンタル」モデルへそのまま適用できるかが最大の不確定要素**です。この点を解消しない限り、補助金を営業トークの決め手として使うことはできません。

### ⑤ 問題点と対策（陛下のご回答を受けて更新）

#### 問題① 陛下ご自身の移動負担 → 解決済み
陛下のご指示「メールでコンタクトしてアポイントが取れれば移動は問題なし」により解決したものと理解します。地域クラスタ訪問のような事前の計画は不要で、**メール一斉送付→返信があった先のみ訪問**という、よりシンプルな方式に変更します。

#### 問題② 学校営業の予算サイクルの壁 → 具体的アプローチ方法を追加調査
前回、私立大学は短期攻略対象、国公立は2028年度以降という時間軸を報告しましたが、陛下より「具体的なアプローチ方法」のご下命があったため、産学連携の窓口を追加調査しました。

* **大学向け**：多くの大学には「産学連携窓口」「産学官連携センター」が置かれており、企業からの技術相談・連携提案を受け付けています。ただし窓口経由は手続きに時間がかかるため、**学科主任・研究室教授へ直接コンタクトする方が早い場合が多い**と考えます（研究室単位の機材ニーズは教授の裁量で動くため）。
* **高専向け**：ロボットメーカー各社と国立高専機構等が参画する産学官連携の枠組み「CHERSI」が存在します。ロボットメーカー8社が参画する既存の枠組みであり、RIGELのような零細企業が直接参加できるかは要確認ですが、**高専側の「地域連携センター」への相談は有効な入口**と考えます。
* **共通の入口**：企業が学校へ提供できる関係構築の手段として、①出前授業、②教員向け研修会、③学生インターンシップの受け入れ、④教育設備の無償・割引提供、が一般的です。RTSのデモ機を「まずは1台、期間限定で無償貸与」する形で関係を作り、その後有償契約につなげる、という段階的アプローチが有効と考えます。
* **学校向け初回コンタクトも企業と同様、まずメールで学科主任・産学連携窓口宛に送付**し、反応があった先を優先する方式とします。

#### 問題③ 実機デモ中の事故・破損リスク → 自家保険モデルの妥当性を試算
陛下より「動産総合保険ではなく自社で保険システムを構築予定。原価が安く壊れても5〜10万円の損失。月1万円の保険料が集まれば成立する」とのご指示を受け、麋竺にて簡易試算しました。

* 月額1万円の「保護料」を仮に10件の契約から徴収した場合：年間収入 120万円（10件×1万円×12ヶ月）
* 想定損失：1件あたり5〜10万円。仮に年間3件（全体の3割）で破損が発生しても、想定損失は最大30万円
* **差引90万円のプラスとなり、自家保険モデルは経済合理性がある**と判断します。契約件数が少ないうち（1〜3件程度）は、稀に集中して破損が起きた場合に一時的な持ち出しが発生するリスクはありますが、原価自体が5〜10万円と小さいため許容範囲と考えます。
* **一点、切り分けて申し上げたい論点**：上記は「機材の破損・故障」に対する自家保険としては合理的ですが、**デモ中に第三者（顧客の従業員等）が怪我をした場合の対人賠償責任は、性質が異なるリスク**です。医療費・賠償額は数百万円規模になり得るため、機材破損の自家保険とは別に、**対人賠償責任保険（PL保険等）の要否だけは改めてご確認いただきたく**存じます。
