# RTS 商品・料金プラン体系表（叩き台 v0.1）

> **本書の位置づけ**：顧客・商社に提示する「プラン」の正本。営業資料・チラシ・見積の数値は必ず本書から引く。
> **提供形態はリース（月額）専業。単体販売は行わない。**（2026-08-01 裁可）
> **status: draft** — 🔲 は未裁可・要決定。

## 2. 学習レベルと搭載機器

| Level | テーマ | 主な学習内容 | 主な搭載機器 |
|---|---|---|---|
| **1** | I/O基礎 | ライトオン／ダークオン、A接点／B接点、PNP／NPN、ポカよけ、ワイヤーストリッパーでの被覆剥き、圧着カシメ、マークチューブ | 光電センサ、レーザーセンサ、近接センサ、マイクロスイッチ |
| **2** | 空圧・オートスイッチ | 電磁弁の単動／複動、シリンダー動作、オートスイッチ検出 | SMC 電磁弁（シングル／ダブル）、シリンダー（ロータリー／スライドテーブル／ロッド） |
| **3** | 通信・モータ制御 | シリアル通信、Ethernet/IP、Profinet、サーボ／パルスモーター制御 | JANOME ロボット（PLC機能搭載）、KEYENCE PLC・タッチパネル |
| **4** | 画像処理 | ビジョンシステムによる欠品検査、照明・撮像条件の設定 | KEYENCE／パナソニック 画像処理装置 |
| **5** | 総合（検査・エラー対応） | 上記全体の統合、異常系の切り分け、トラブルシューティング | 上記一式 |

**全レベル共通の設計思想**
- **複数メーカー機器の統合**が最大の差別化（JANOME／KEYENCE／SMC／パナソニック／MISUMI）。単一メーカーのデモ機では成立しない
- 故障診断を組み込み、**"壊す→直す" サイクル自体を教材化**する
- 機構部品は MISUMI、ベースはアルミフレーム・アルミ板

## 3. サポート料金（リース料と別建て）

| 区分 | 料金 | 備考 |
|---|---:|---|
| メールサポート | **無償** | 写真添付＋状況記入フォーマット必須。**1営業日以内に返信** |
| オンラインサポート | **¥10,000 / 時間** | Zoom / Slack / Teams |
| 訪問サポート | **¥100,000 / 日** | 交通費別 |

- 請求は**リース会社経由でリース料と合算**する（顧客の支払窓口を一本化）
- 電話受付は行わない。すべてメール起点とする

## 4. 契約条件

| 項目 | 内容 |
|---|---|
| 最短契約期間 | **3ヶ月** 🔲 |
| 最長契約期間 | **24ヶ月** |
| 途中解約 | **1〜2ヶ月での途中解約は不可** |
| 信販会社 | ちばぎんリース（メイン）／ORIX・三井住友ファイナンス&リース・東京センチュリー・三菱HCキャピタル・みずほリース（選択肢） |
| 納品 | 郵送（箱のまま）。顧客先で開梱・セットアップ。原則訪問なし |
| 工具 | ニッパー、ストリッパー、端子用圧着ペンチ等は**顧客側で用意** |

> 🔲 **最短3ヶ月では原価回収が約84%にとどまる**（[[基本概念]] 5.2）。4ヶ月へ延長するか、初期費用（セットアップ費）を別途設定するかの決定が必要。

### 返却・買い取りの扱い

| 対象 | 扱い |
|---|---|
| ロボット本体 | 回収（整備して再投入） |
| アルミフレーム等の高価部品 | 回収・再利用 |
| 端子処理済み等の構築済み部品 | **顧客に買い取り** |
| 消耗部品 | 顧客側に残る（無駄が出ない設計） |

## 5. 故障時の費用負担

| ケース | 対応 |
|---|---|
| 輸送中の破損 | 運送会社の責任 |
| 初期不良・自然故障 | **無償対応** |
| 顧客の過失による故障 | **有償修理** |

- 対応は**センドバック方式**（代替品を先送りし、故障品を回収）
- 修理原資は「整備費」名目で社内にプールする（「保険」の名称は保険業法の対象となるため使用しない）
