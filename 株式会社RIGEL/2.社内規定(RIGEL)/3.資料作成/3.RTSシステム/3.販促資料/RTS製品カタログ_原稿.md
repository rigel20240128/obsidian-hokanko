# P2｜課題提起

### 二段見出し
```
（小）自動化が進まない、本当の理由
（大）設備より、人。
```

### 本文

```
「ロボットを導入したい。けれど、扱える人がいない。」

多くの中小製造業が、この一点で止まっています。

設備は買えます。導入もできます。
しかし現場に、配線を読み、センサーを調整し、
エラーが出たときに原因を切り分けられる人がいなければ、
その設備は「止まったまま」になります。

自動化の前提は、設備ではありません。
それを扱える、自社の技術者です。
```

### 課題／解決の2枠（イラスト的表現）

| **よくある課題** | **RTSの答え** |
|---|---|
| 設備を導入したが、誰も触れない | **先に人を育ててから設備を選ぶ** |
| 生産ラインを止めて教育はできない | **教育専用設備を別に置く**ので現場に影響しない |
| 外部研修は単発で、身につかない | **月額で手元に置き続ける**から積み上がる |
| 教材用ロボットは実務と違いすぎる | **産業グレードの実機**で学ぶ |
| 故障が怖くて触らせられない | **"壊す→直す"を教材にする** |

> ※注記（小さいグレー文字）
> `※記載の学習内容は今後変更・細分化される場合があります。`

# P3｜RTSとは

### 二段見出し
```
（小）RTSが選ばれる理由
（大）3つの発想の転換
```

### 転換① 買う → 借りる
```
FA機器を「買う」のではなく、教育システムとして「借りる」。
月額制のため、初期投資を抑えて今日から始められます。
最短3ヶ月から。合わなければやめられます。
```

### 転換② 完成品 → コンプリートキット
```
RTSは完成した装置では届きません。
アルミフレームから部材一式が揃った「コンプリートキット」として届き、
お客様自身が組み立てるところから学習が始まります。

なぜなら——組み立てる工程そのものが、最も重要な教育だからです。

「コンプリート」とは、追加購入なしでその段階の学習が完結するという意味です。
```

### 転換③ 故障を避ける → 故障を教材にする
```
通常の教育は、故障しないように設計されています。
RTSは逆です。

わざと不具合を起こし、原因を切り分け、直すところまでを学習に組み込みます。
現場で本当に必要なのは、動いている設備を眺める力ではなく、
止まった設備を動かす力だからです。
```

### 円形数値バッジ（4つ・カタログ作成ルール §3.3）

| バッジ | 説明 |
|---|---|
| **STEP 20** | 体系カリキュラムの学習ステップ数 |
| **3ヶ月〜** | 最短契約期間 |
| **3営業日** | メールサポート返信目安 |
| **20年** | FA設備設計の実務年数 |
