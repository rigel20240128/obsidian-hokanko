# 社内ドキュメント用アイコン生成テンプレート

## 1. 共通スタイル定義（固定・毎回このまま使用）

| 項目 | 内容 |
|---|---|
| 形式 | SVGアイコン |
| キャンバス | viewBox="0 0 24 24"（正方形・24グリッド基準） |
| テイスト | フラット・ミニマル／線画中心 |
| 線の太さ | stroke-width: 1.5〜2 |
| 線端・角 | stroke-linecap="round" / stroke-linejoin="round"（角丸で統一） |
| カラー | 単色のみ使用（例：#2563EB など企業カラー1色）／背景は透明 |
| 余白 | 周囲に10%程度のセーフエリアを確保、モチーフは中央配置 |
| 構図 | モチーフは1〜2要素に絞る（情報を詰め込みすぎない） |
| 装飾 | 影・グラデーション・テクスチャ・多色は使わない |

→ この表をそのまま「固定プロンプト」として毎回貼り付ければ、テイストがぶれません。

## 2. 都度入力する項目（可変）

| 入力項目 | 説明 | 記入例 |
|---|---|---|
| ① 用途カテゴリ | どんな意味を持つアイコンか | 注意喚起／完了／ダウンロード／申請／承認待ち／お問い合わせ |
| ② モチーフ | 何を描くか（1〜2要素） | 書類とチェックマーク／虫眼鏡と書類／下向き矢印とトレイ |
| ③ アイコン名 | ファイル名・呼び名 | icon_approved |
| ④ 特記事項（任意） | サイズ違い・向き・強調したい部分など | 「もう少し太め」「矢印は右向きで」等 |

## 3. 依頼用の定型文（コピペして使う）

```
[共通スタイル定義]の条件で、以下のアイコンを作成してください。

用途カテゴリ：〇〇
モチーフ：〇〇
アイコン名：〇〇
特記事項：〇〇
```

## 4. 使用例

```
用途カテゴリ：承認完了
モチーフ：書類とチェックマーク
アイコン名：icon_approved
特記事項：チェックマークをやや大きめに
```

---

### 運用のコツ
- 最初の1〜2個を作った後、「このテイストを基準に」と伝えると以降のブレがさらに減ります。
- 企業カラーは最初に決めて固定しておくと、全アイコンで統一されます（複数色使う場合も「メイン1色＋アクセント1色」までに絞るのがおすすめ）。
- 用途カテゴリの一覧（例：全20種類）を先に洗い出しておくと、抜け漏れなく作成できます。
