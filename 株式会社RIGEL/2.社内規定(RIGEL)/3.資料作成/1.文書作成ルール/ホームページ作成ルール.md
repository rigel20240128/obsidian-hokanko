## 8. 文章ルール（ライティング・トーン＆マナー）

信頼、知性、誠実、そして未来への高揚感を両立させるための、厳格なテキスト記述規定。

*   **一人称（主体）の定義**：
    主語は原則「RIGEL」または「私たち（RIGEL WORKSのエンジニアチーム）」とする。ただし、代表挨拶部分のみ「私」とする。
*   **専門用語の扱いと信頼性の調和**：
    キーエンスやジャノメ、日本の最先端工場の生産技術者が日常的に使用する言葉（「タクトタイム」「干渉シミュレーション」「サーボプレス圧入・カシメ」「デジタルツイン」「レトロフィット（設備改善）」）[94, 98]を意図的に美しく配置し、「この会社は技術現場を心から理解している」という絶対的な安心感を与える。
*   **「 Hook the Future 」の語尾と文体**：
    文末は「です」「ます」を基本とするが、カードのキャッチコピーや見出し、コンセプト部分は「体言止め」や「～へ。」「～する。」という、AppleやTeslaのように知的で力強く、余韻を残す断定的な文体を使用する。
*   **数字の具体性**：
    「FA設備設計20年以上」という、代表の持つ揺るぎない実績の数字をすべてのコンテンツの根底に据え、裏付けのない誇大広告は徹底的に排除する。

## 9. 掲載しない内容（引き算のデザイン規律）

顧客である製造業の技術担当者にとって「信頼を損ねるノイズ、不要な情報」はすべて削ぎ落とす、引き算の美学を徹底します。

1.  **独立までの個人的な苦労話、情緒的な経緯**：
    「なぜ会社を立ち上げたのか」の個人的な紆余曲折はB2Bの設備投資担当者にとって意思決定の判断材料にならないため、一切掲載しない。
2.  **補助金獲得、資金調達状況、社内計画**：
    「補助金を活用した～」「第○期資金調達～」などの財務・資本情報は、大手企業担当者から見ると「資金繰りに懸念があるのでは」という不信感に繋がりかねないため、信頼を最優先とし排除する。
3.  **未確定、または仕様が固まっていないサービス**：
    「将来的に展開予定の～」などの未確定の事業構想は、技術的整合性と絶対の安心を求めるFA市場において不安要素になるため記載しない。
4.  **過度なAIアピールやトレンドの乱用**：
    「AIがすべてを解決する」といった抽象的なバズワードを乱用せず、キーエンスのIV4画像判定を最適に実装する[61, 75]などの「実用的な技術としてのAI組み込み」に留め、現場に即した堅実さを示す。

#### ① 技術スタック・デザイン規制
- **ベース**: HTML5, CSS3 (Tailwind CSS または CSS Variables), TypeScript
- **HTML制限**: `.html` および `.htm` の成果物保存は一切行わないこと。成果物は設計書マニュアルおよび各ビジュアル（JPG）としてStudioにマウントされている。開発時には、ブラウザのメモリアウトを避けるため、GPUに最適化されたCSS3 3D Transform（`translate3d`）をハードウェアアクセラレーションとして適用すること。
- **カラー変数定義**:
  - `--rigel-works-teal`: #005C8A (RGB: 0, 92, 138)
  - `--rigel-works-pure-white`: #FFFFFF
  - `--future-project-dark`: #4A4A4A
  - `--future-project-amber`: #D4AF37 (RGB: 212, 175, 55)
  - `--future-project-light-bg`: #FAF9F6

#### ② グローバル・ワールド切替（TDR式グローバルスイッチ）の実装
- HTML最上部に `data-brand-world="works"` をトグルするJSロジックを組むこと。
- [★ RIGEL WORKS] タップ時:
  - `body` にクラス `brand-works` を適用。
  - 背景に `rigel-brand-bg-pattern.jpg` を opacity: 0.15、z-index: -1 でフェードフェードインさせ、カラー変数を Works 用へ0.6sでイージング遷移（`cubic-bezier(0.16, 1, 0.3, 1)`）。
- [✿ FUTURE PROJECT] タップ時:
  - `body` にクラス `brand-future` を適用。
  - 背景に `rigel-future-bg-pattern.jpg` をフェードインさせ、フォントを `font-serif` （明朝体）に、テーマカラーをゴールド＆アッシュへと滑らかに遷移させること。

#### ③ ロゴ（ファーストビュー）のアニメーション
- トップの初期状態では、中央に大きくロゴを配置（高さ: 50vhの位置）。
- ロゴ下部の `.compass-star`（羅針盤）要素には、以下の無限回転CSSを適用：
  ```css
  @keyframes compassRotate {
    0% { transform: rotate(0deg); }
    100% { transform: rotate(360deg); }
  }
  .compass-star {
    animation: compassRotate 60s linear infinite;
  }
  ```
- ユーザーの最初のスクロール（またはフリック）をトリガーに、ロゴアセンブリを縮小（`scale(0.4)`）させながら、左上のナビゲーション位置（`.brand-logo-target`）へ0.8sでイージング吸着トランジションさせ、ヘッダーにガラスモーフィズム（`backdrop-filter: blur(12px) bg-white/70`）を付与して固定（`position: fixed`）すること。

#### ④ レスポンス・UIコンポーネントの実装
- **水平カルーセル（モバイル表示時）**:
  - 画面幅が 768px 未満（`md:`以下）の場合、FA設備設計のBento Gridを、`overflow-x: auto` および `scroll-snap-type: x mandatory` を適用した水平カルーセルカードスタックへとCSS Media Queryで動的にレイアウト可変させること。
  - 各カードには `scroll-snap-align: center` を付与し、右側が5%（幅24px分）次のカードが見切れていて、指でのフリックスワイプを直感的に促すレイアウトにすること。
- **モバイル固定ボトムトグルスイッチ**:
  - スマホ表示時のみ、最下部に `position: fixed; bottom: 16px; left: 50%; transform: translateX(-50%)` の位置に、 Works と Future を親指で左右にスライドして切り替えられる角丸のセグメンテッド・トグルボタンを実装すること。タッチ可能領域は `min-height: 48px` を確保。

#### ⑤ 迅速解決フォーム（キーエンス流）の動的切替
- フォーム入力エリアの `select#contact-purpose`（目的選択）のイベントリスナー（Change event）を監視すること。
- FA設計（値 `fa`）が選択された際：
  - ファイルアップロード用の `div#file-uploader` の親クラスに `.highlight-pulse` を付与し、スマホカメラ直結対応の `capture="environment"` 属性を持った `<input type="file">` を動的にアクティブ表示。
- 実機レンタル・教育（値 `rts`）が選択された際：
  - ロボットメーカーの複数選択チェックボックス群（ファナック、安川、三菱など）をフェードイン表示。
- NDA安心宣言マークおよび、お待たせしない24時間一次回答マニフェストをフォームの真上に明確な文字サイズ（`font-semibold text-lg`）で常に露出させること。
