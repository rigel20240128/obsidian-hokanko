# 3期目 売上2億円 到達シナリオ

> **本書の位置づけ**：「3年後（第3期＝2029年10月期）に売上2億円」を成立させるために、
> **何を・いつまでに・いくつ揃える必要があるか**だけを書く。
> 事実・確定値の正本は [[事業計画書_統合版マスター]]、RTSの仕様・料金の正本は [[基本概念]]。
> 本書はそれらを**書き換えない**。到達目標が変わったときのみ本書を直す。

---

## 0. 結論（先に3行）

1. **現在の事業モデルのままでは2億円に届かない。** 設計受託は「代表の時間」が原価であり、年間稼働2,000時間×単価12,000円＝**理論上限2,400万円**。RTSリースを保有11台すべて回しても年1,350万円。**両方を上限まで回しても4,000万円弱で頭打ちになる。**
2. 2億円に届く道は**1本しかない**。FA設備を「設計だけ請ける」のをやめ、**装置一式を自社名義で受注し製作を協力会社へ発注する「元請け」に立つ**こと。1件の売上が200〜300万円から**1,500〜3,000万円**に変わる。2億円のうち**1.2億円をここで作る。**
3. そのために必要なのは、資料でも営業トークでもなく、**①作業場 ②設計者3名 ③追加資金5,500万円 ④協力会社5社**の4点。**このうち1つでも欠けたら2億円は不成立**であり、着地は1.1〜1.5億円になる。

**要するに「5期目の目標を3期目へ2年前倒しする」という要求である。**

## 2. なぜ現行モデルでは届かないか（先に天井を確認する）

金融機関も自分自身も、まずここを直視しないと計画が絵になる。

| 収益源 | 単価の正本 | 物理的な上限 | 年商上限 |
|---|---|---|---:|
| 設計受託（自分の時間） | 8,000〜12,000円/時 | 年間稼働2,000時間が限界 | **約2,400万円** |
| RTSリース（保有11台） | 自社受取 ¥102,000/月（[[基本概念]] 3.2） | 保有11台・予備を除き実質9台 | **約1,100万円** |
| RTS初期費用 | ¥150,000/台（同 2.3） | 年間成約10台程度 | 約150万円 |
| FA設備「設計のみ」受託 | 200〜300万円/件 | 年6件（1件400〜600時間） | 上の設計受託枠と競合 |
| **合計（すべて上限稼働）** | | | **約3,700万円** |

**これが「1人・現行モデル」の天井である。** 2億円との差は約1.6億円。
したがって2億円は、**売上単価を上げる／台数を増やす**という延長線では到達しない。
**収益構造そのものを3つ入れ替える**必要がある。

| # | 入れ替え | Before | After |
|---|---|---|---|
| ① | **商流を通す** | 設計工数を売る（200〜300万円/件） | 装置一式を売る（**1,500〜3,000万円/件**） |
| ② | **他人の時間を売る** | 代表の稼働が売上上限 | 設計者3名＋社外フリーランス（**上限が人数に比例**） |
| ③ | **資産を積む** | 保有11台の範囲でリース | **38台体制**へ拡張しストック化 |

## 3. 3期目 2億円の内訳（積み上げ）

### 3-1. 売上構成

> ✅ **2026-08-26 改訂**：[[売上積み上げ_作業単位マスター]] で作業単位まで分解した結果、
> 内訳を組み替えた。**装置を「2,000万円×6件」から「19件への分散」へ変更**し、
> 消耗品・情報制作を独立区分として立てた。**合計2億円は変わらない。**

| 区分 | 3期目売上 | 構成比 | 性質 | 内訳の正本 |
|---|---:|---:|---|---|
| **B 装置・製作（元請け）** | **9,280万円** | 46.4% | スポット | [[売上積み上げ_作業単位マスター]] 6-1（**15件**） |
| **A 設計・エンジニアリング** | **3,720万円** | 18.6% | フロー | 同 6-2（**2,750時間＋件数制**） |
| **C RTS リース・研修** | **3,900万円** | 19.5% | **ストック** | 同 6-3（**平均稼働25台**） |
| **D オリジナル製品・無形商品** | **2,620万円** | 13.1% | **リピート＋ストック** | [[専売消耗品_独占設計]]（**RGシリーズ＋役務**） |
| **E 情報・制作・仲介** | **480万円** | 2.4% | スポット | [[売上積み上げ_作業単位マスター]] 6-5 |
| **合計** | **20,000万円** | 100% | | |

> **この構成の意味**：装置（スポット）が46%、それ以外の**毎月積み上がる収入が54%**。
> **「毎月893万円が自動で入り、9,280万円を装置で取りに行く」**構造であり、
> 装置が1件飛んでも計画全体は崩れない。旧案（元請け6件に1.2億円を集中）より耐性が高い。

> ✅ **【2026-08-26 ご裁可】市販品の再販は一切行わない。販売はオリジナル製品（治具中心）に限る。**
> これによりD区分から市販品824万円が消えたが、**RGシリーズ（ベース＋交換プレート方式）で上回った。**
> 同時に、よくある形の治具を都度設計（B-4）から標準品へ移したことで**装置が720万円分減り、
> 設計工数が240時間浮いた。**売上2億円は不変のまま、**リスクと工数が下がっている。**
> 詳細は [[専売消耗品_独占設計]] 第5章・10-3。

> 🔴 **工数の検算は [[売上積み上げ_作業単位マスター]] 第7章で行った。**
> 必要**6,870時間**に対し保有8,200時間（社員3名＋代表1,000h＋社外2名）で**余裕16%**。
> 治具の標準品化により11%→16%へ改善したが、それでも1件の大幅な手戻りで消える水準である。
> 売上だけ積んで工数を検算しないのが、事業計画で最もよくある破綻の仕方である。

## 4. 【最重要】FA設備の元請け化 — 2億円の60%を作る

### 4-1. 何を変えるのか

| | 現行（設計受託） | 元請け（一式請負） |
|---|---|---|
| 受注範囲 | 3D設計図面のみ | 構想・設計・部材調達・製作・組立・電気制御・据付・立会検査 |
| 1件の売上 | 200〜300万円 | **1,500〜3,000万円** |
| 粗利率 | 60%超 | **20〜25%** |
| 1件の粗利額 | 120〜180万円 | **300〜750万円** |
| 資金負担 | ほぼ無し | **1件あたり1,500万円を4〜6か月立替** |
| 責任 | 図面の瑕疵のみ | **納期・性能・安全・瑕疵の全部** |

**粗利率は落ちるが粗利額は2〜4倍になる。** そして何より、**代表の稼働時間に売上が縛られなくなる。**
ここが「時間を売る商売」から抜け出す唯一の出口である。

### 4-2. 揃えるもの①：協力会社網（最低5工程×各2社）

**1社依存＝納期リスクの全損**。各工程で必ず代替を1社持つ。

| 工程 | 必要社数 | 起点となる既存人脈（[[取引先情報]]） |
|---|---:|---|
| 製缶・板金・フレーム加工 | 2社 | 大田区・川口・三郷の町工場を新規開拓 |
| 機械加工（切削・研磨） | 2社 | **遠藤製作所**（流山）／**オジックとダイア**（三郷） |
| 電気制御盤製作・配線 | 2社 | **ニットクエンジニアリング**（千葉）／新規1社 |
| 装置組立・調整 | 2社 | **CONNECT**（日高）／**TAISHO**（川越） |
| 現地据付・搬入 | 1社＋自社 | 運送・重量物据付業者 |
| 設計外注 | 2名 | **波多野設計**（所沢）／新規1名 |

**期限：2027年6月までに各工程1社と「取引基本契約」を締結する。** 見積依頼の実績だけでは足りない。
単価表・標準納期・支払条件を紙で持っていることが、元請けとしての見積精度を決める。

### 4-3. 揃えるもの②：契約条件（これが無いと黒字倒産する）

**1件2,000万円の装置は、原価1,560万円を検収まで立替える。** 同時3件で4,680万円。
**手元資金では絶対に回らない。** したがって**入金条件を先に設計する**。

| 標準契約条件 | 比率 | タイミング |
|---|---:|---|
| 前受金（契約時） | **40%** | 注文書受領後10日以内 |
| 中間金（設計完了・部材発注時） | **30%** | 承認図承認後 |
| 検収金 | 30% | 立会検査合格後30日 |

- **前受40%が取れない案件は受けない。** これを社内ルールとして固定する
- 協力会社への支払は**月末締め翌月末払い（サイト60日）**で統一 → 入金と支払のギャップを最小化
- 前受40%＋中間30%が入れば、1件あたりの実質立替は**約760万円**まで下がる（1,560万−800万）

### 4-4. 揃えるもの③：見積の型

1件2,000万円の見積を**2日で出せる**ようにする。ここが受注率を決める。

```
装置見積 ＝ 機械部材費 ＋ 電気部材費 ＋ 外注製作費 ＋ 設計工数 ＋ 組立調整工数
           ＋ 据付・搬入費 ＋ 予備費(10%) ＋ 利益(22%)
```

- MISUMI・SMC・KEYENCE・JANOMEの単価表をテンプレート化（既に `10.空圧機器` にカタログ資産あり）
- **過去のSET設備原価表（2012-2026）が保管庫にある。** これが最強の積算根拠。
  実績原価から「この規模ならいくら」を即答できる状態にしておく
- **予備費10%を必ず入れる。** 元請けの利益は仕様変更で消える

### 4-5. 揃えるもの④：法務・保険

| 項目 | 内容 | 期限 |
|---|---|---|
| 🔴 **建設業許可（機械器具設置工事業）** | **1件500万円以上の据付工事を請け負う場合に必要**となる可能性が高い。要件は経営業務管理責任者（5年）・専任技術者・**自己資本500万円以上**。装置一式2,000万円のうち据付部分の切り分け方で要否が変わる | **2027年内に行政書士へ要確認** |
| 生産物賠償責任保険（PL） | 納入装置に起因する事故の賠償 | 1件目の受注前 |
| 請負業者賠償責任保険 | 据付作業中の事故 | 同上 |
| 注文請書・仕様確定書の書式 | 仕様変更時の追加請求根拠。**元請けで最も揉める箇所** | 1件目の受注前 |
| 古物商許可 | 中古ロボット取扱の前提（[[基本概念]] 6.2 で期限超過中） | **即** |

### 4-6. 6件をどう獲るか

| 獲得ルート | 3期目の想定件数 | 具体策 |
|---|---:|---|
| 既存人脈（サンエイテック時代の顧客・協力会社） | 2件 | 設計受託で入り込んだ先へ「一式でも受けられる」と告知 |
| RTS導入顧客からの横展開 | 2件 | **RTSは元請け案件のリード獲得装置**でもある。教育で入り、設備で稼ぐ |
| 商社経由 | 1件 | 緑屋テクノ・和泉産業・五光社・ライト・柳田機器 |
| FA設備営業代行（[[RIGEL事業概要]] ③）の自社受注転換 | 1件 | 他社へ紹介していた案件のうち、自社で対応可能なものを内製化 |

**受注率30%とすると、年20件の見積提出が必要＝月1.7件。** これが最重要KPI。

## 5. 設計受託のチーム化 — 4,100万円

### 5-1. 構造

**代表の時間を売るのをやめ、単価差を取る。**

| 項目 | 金額 |
|---|---:|
| 顧客への請求単価 | 10,000〜12,000円/時 |
| 社外フリーランスへの支払単価 | 7,000〜8,000円/時 |
| 社員（年収550万＋法定福利）の実質時間単価 | 約3,500円/時 |

- **社員3名**：うち2名相当をFA元請け案件の設計に充当（6件×500時間＝3,000時間）、残りを受託へ
- **社外フリーランス2名**：受託案件の変動分を吸収。固定費化しない緩衝材
- 代表は**検図・積算・営業・PMに専念**（設計実務からは3期目に離脱する）

### 5-2. 🔴 最大のボトルネックは検図

## 9. 🔴 融資審査との切り分け（実務上の最重要注意）

**現在提出予定の [[日本政策金融公庫_創業計画書_900万円案]] を2億円計画に書き換えてはならない。**

| 理由 | 説明 |
|---|---|
| 創業融資は「保守性」で評価される | 実績ゼロの法人が「3年で2億円」と書けば、担当者は**根拠を疑い、審査が長引くか減額される**。1期1,500万円のうち80%が契約済という現行案の強さが消える |
| 数字の整合が崩れる | 統合版マスターは既に矛盾①〜⑤を抱えている。ここに6本目の売上計画を足せば収拾がつかない |
| 2億円には追加融資6,300万円が必要 | それは**2期目の話**であり、1期目の900万円とは審査も時期も別物 |

### 運用ルール

| 用途 | 使う計画 |
|---|---|
| 公庫・京葉銀行への創業融資 | [[日本政策金融公庫_創業計画書_900万円案]]（1期1,500万円） |
| 認定支援機関・商工会議所 | [[事業計画書_統合版マスター]]（1期1,500→3期8,000万円） |
| **社内の到達目標・意思決定** | **本書（3期2億円）** |
| 2028年の追加融資申込 | 本書＋1期の実績決算書 |

**2億円は「対外的な宣言」ではなく「社内の設計図」として扱う。**
2028年に1期の黒字決算を持って追加融資に臨むとき、初めて本書を外部に出す。

## 11. 何をやめるか（集中しなければ届かない）

[[RIGEL事業概要]] には6事業が並んでいる。**1人〜5人の会社で6事業を同時に伸ばすことはできない。**
