# 設立前費用と個人資産の法人移転

> **本書は法的・税務的助言ではない。** 制度の一般的な理解を整理し、**顧問税理士に何を聞くべきかを確定させる**ためのメモである。
> 最終的な処理は顧問税理士の判断による。[[開業準備_2026年11月]] B-2（税理士・公庫担当との相談）の持参資料として使う想定。
> 前提：**法人設立目標 2026年11月**／退職 2026-09-29／資本金300万円（退職金・発起人は陛下お一人）。

---

## 0. 結論の要約

| # | 論点 | 現時点の整理 |
|---|---|---|
| 1 | 設立前の支出は3つに分かれる | **①創立費 ②開業費 ③資産の取得**。①②は繰延資産で**任意償却**（黒字の期に好きな額を落とせる）、③は費用ではなく法人が個人から**買い取る**もの |
| 2 | 個人資産の移転は「売買」で行う | 資本金は現金300万円と決定済みのため**現物出資ではない**。設立後に**売買契約＋実際の代金決済**で移す |
| 3 | 価額は「時価」でなければならない | 安すぎる＝法人に受贈益／高すぎる＝**役員賞与認定（損金不算入＋源泉徴収）**。中古相場の根拠資料を必ず残す |
| 4 | 一人会社でも社内手続きが要る | 代表者個人との売買は**利益相反取引**（会社法356条）。さらに合計額次第で**事後設立**（同467条1項5号）の株主総会特別決議に触れうる → **§3** |
| 5 | 按分するものは「根拠の記録」が命 | 自宅・古民家・プラド・携帯。**面積比・走行距離・使用時間**のいずれかで、実測の記録を先に始める |
| 6 | 失業保険と設立スケジュールは要事前確認 | 備品購入そのものより、**登記・開業届・営業活動の開始時期**が論点。ハローワーク松戸へ事前相談 → **§6** |
| 7 | 既存台帳と金額が食い違っている | ロボット・車両・PCで[[資産譲渡台帳]]と不一致。**どちらが正か確定が必要** → **§8** |

## 1. 前提の制度整理（3つの区分）

法人が成立する前に出ていったお金は、**すべてが「経費」になるわけではない**。次の3つに分けて考える。

| 区分 | 内容 | 税務上の扱い |
|---|---|---|
| **①創立費** | **会社を設立するために**要した費用。定款認証手数料、登録免許税、会社印鑑の作成費、謄本・印鑑証明の取得費、設立事務にかかった費用、金融機関の手数料、freee会社設立の利用料 など | 繰延資産。**任意償却**（5年均等でも、初年度に全額でも、赤字の期は0円でもよい） |
| **②開業費** | **設立後から営業開始までに、特別に支出**した費用。名刺・パンフレット・ホームページ制作、市場調査、開業前の広告宣伝、開業準備の打合せ費用 など | 繰延資産。**任意償却** |
| **③資産の取得** | ロボット（棚卸資産）、車両、PC、工具、携帯電話機 など**モノそのもの** | 費用ではない。**法人が個人から買い取る**か、賃借する。取得後は棚卸資産または減価償却資産 |

**注意点（税理士に確認する前提での理解）**

- **家賃・水道光熱費・給与のような経常的な費用は、開業費に含めないのが原則**とされる（「開業準備のために**特別に**支出する費用」であることが要件）。古民家の賃料・自宅の光熱費・息子への給与を「開業費でまとめて落とす」構想は、**そのままでは通らない可能性が高い**。
- **設立前に個人名義の領収書しかなくても、創立費・開業費として法人で処理できる**のが一般的な扱い（発起人による立替）。ただし**日付・目的・支払者が分かる形で残す**こと。**レシートを捨てないこと**が最優先の実務。
- **任意償却は初年度の資金繰りに効く。** 創業初期が赤字なら償却せず繰り越し、黒字化した期にまとめて落とせる。**償却を急がない**判断が有利になる場面がある。

## 3. 個人 → 法人へ資産を移すときの共通ルール

### 3-1. 「売買」で行う（現物出資ではない）

資本金300万円は**退職金からの現金**と既に決定済み（2026-07-22）。したがって資産は出資ではなく、**法人成立後に個人から買い取る**形をとる。

必要なもの：

- [ ] **売買契約書**（当事者・対象物・数量・価額・引渡日・代金支払方法）
- [ ] **資産の一覧表**（機種・製造番号・状態・写真）
- [ ] **時価の根拠資料**（中古相場のスクリーンショット、購入時の領収書、査定書）
- [ ] **代金の実際の決済**（法人口座から個人口座へ振込。**帳簿上の相殺・未払いのまま放置は避ける**。資金繰りの都合で分割にするなら金銭消費貸借の形を整える）

### 3-2. 価額は「時価」——高くても安くてもいけない

| ケース | 法人側 | 個人側 |
|---|---|---|
| **時価より著しく安い** | 時価との差額が**受贈益**として課税されうる | — |
| **時価より高い** | 差額が**役員賞与**と認定されうる（**損金不算入＋源泉徴収漏れ**） | 給与所得として課税 |
| **時価** | 取得価額として資産計上 | 下記の譲渡所得の判定へ |

**個人側の課税**（要税理士確認）

- **ロボット**：転売目的で仕入れた棚卸資産に該当するなら、譲渡所得ではなく**事業所得・雑所得**の対象になりうる。「個人の私物を売った」のか「仕入れて売った」のかで扱いが変わる。**2026年内の売却なら2026年分の確定申告に載る**点に注意。
- **車両・PC・工具**：生活に通常必要な動産の譲渡は原則非課税だが、**事業に使っていた資産は総合譲渡所得の対象**。総合譲渡所得には**50万円の特別控除**があり、いずれも購入額以下での譲渡であれば譲渡益は生じない見込み。
- **消費税**：陛下が個人として課税事業者でなければ売手側の納税は生じない。法人側は第1期が免税事業者となる見込みのため、**仕入税額控除も受けられない**（[[日記]] 2026年のインボイス論点と同じ整理）。

### 3-3. 🔴 会社法上の手続き（一人会社でも省略できない）

| 論点 | 根拠 | 必要な手続き |
|---|---|---|
| **利益相反取引** | 会社法356条1項2号 | 代表取締役個人が会社に資産を売る行為。取締役会非設置会社では**株主総会の承認**。株主も陛下お一人だが、**議事録を作って残す**こと |
| **事後設立** | 会社法467条1項5号 | **設立後2年以内**に、**設立前から存在する財産**を、**純資産額の5分の1を超える対価**で取得する場合、**株主総会の特別決議**が必要。純資産300万円 → **基準は60万円**。ロボット60万円＋車両25万円＋PC30万円＝**115万円で既に超える** |
| **役員報酬との区別** | 定期同額給与 | 資産の売買代金・車両使用料・家賃は**役員報酬とは別物**として契約と支払を分けること。混ざると定期同額給与の判定に影響する |

> **一人会社だから形式は不要、とはならない。** 税務調査で否認されたときに反論できるのは、**契約書・議事録・振込記録**の3点だけである。作成の手間は小さく、後から作れないものが多い。
> なお役員報酬そのものの決定期限（設立後3か月以内）は[[やること一覧]]に既出。

## 4. 項目別の整理（資産）

### 4-1. ロボット仕入れ 60万円

| 項目 | 内容 |
|---|---|
| 区分 | **棚卸資産**（リース用に自社保有するなら固定資産）。RTSがリース専業に一本化された以上、**販売用か貸与用かで科目が変わる** |
| 論点① | [[資産譲渡台帳]]では**卓上ロボット11台・計115万円**（JR3203×8＝80万円、JR3504×1＝20万円、JR2303×1＝10万円、JR2203×1＝5万円）。**ご入力の60万円との差の説明が必要** |
| 論点② | リース資産として保有する場合、**1台あたり10万円**の機体は少額減価償却資産（10万円未満）に該当せず、**一括償却資産（3年均等）または中小企業者等の少額減価償却資産の特例（30万円未満・年300万円まで）**の適用余地がある |
| 論点③ | 古物商許可の取得は**2027年初頭見込み**（[[開業準備_2026年11月]] A-1）。**個人から法人への譲渡は古物営業に当たらない**と考えられるが、**許可前に法人が中古機を仕入れる行為との線引き**を警察・税理士の双方に確認したい |
| 必要書類 | 機種・製造番号・台数・状態の一覧（[[開業準備_2026年11月]] E-1b「所有8台の詳細な在庫リスト」と同じもの）、購入時の領収書、売買契約書 |

### 4-2. 車両（フィットシャトル 25万円）

| 項目 | 内容 |
|---|---|
| 区分 | 車両運搬具。**法人名義に変更**して社有車とする |
| 減価償却 | 普通自動車の法定耐用年数6年。**中古資産は簡便法**で（法定耐用年数−経過年数）＋経過年数×20%。フィットシャトルは**初度登録から10年以上**経過している見込みで、**6年×20%＝1.2年 → 2年未満は2年**。定率法なら償却率1.000となり、**取得年度に（月割で）ほぼ全額を損金化できる** |
| 注意 | 経過年数は**個人が購入した日ではなく初度登録年月**で数える。車検証で確認すること |
| 手続き | 名義変更（移転登録）、**自賠責・任意保険の名義と使用目的の変更**（「業務使用」へ）、駐車場の使用者変更 |
| ガソリン代 | **社有車になれば法人カードで全額計上して問題ない。** 使用実態が100%業務であることが前提 |
| 論点 | [[資産譲渡台帳]]は**50万円**。ご入力は**25万円**。取得価額が違えば償却も譲渡代金も変わる → **§8** |

### 4-3. ノートパソコン 30万円（2026年8月購入）

| 項目 | 内容 |
|---|---|
| 区分 | 工具器具備品。法定耐用年数**4年**（電子計算機・パーソナルコンピュータ） |
| 🔴 30万円の壁 | 中小企業者等の少額減価償却資産の特例は「取得価額**30万円未満**」。**30万円ちょうどは対象外**であり、4年償却になる。**29万円台であれば全額を取得年度の損金にできる** |
| 判定単位 | 税抜／税込のどちらで判定するかは**経理方式による**。法人が第1期免税事業者であれば**税込金額での判定**となる見込み。ご入力の30万円が税込か税抜かで結論が変わる |
| 現実的な処理 | 法人が買うのは**数か月使用済みの中古PC**であり、**時価は新品価格を下回る**のが自然。中古相場に基づいて30万円未満の時価をつけられれば、特例の適用余地がある。**恣意的な値付けは不可**、根拠資料を残すこと |
| 論点 | [[資産譲渡台帳]]は**WU4-K3・28万円・2026-07-10取得**。ご入力は**30万円・2026年8月購入**。**同一機か別機か**を確定させる → **§8** |

### 4-4. 組立工具（10年前に個人購入）

ドライバ、ハンマー、テスター、半田こて、配線、コネクタ、ネジ類。

| 項目 | 内容 |
|---|---|
| 時価 | **10年経過した工具の時価はごく少額**。取得価額ベースではなく**現在の中古価値**で評価する |

### 4-5. 携帯電話（iPhone18・2026年9月購入予定）

| 項目 | 内容 |
|---|---|
| 🔴 タイミング | **購入予定は2026年9月、法人設立は11月。設立前のため法人名義では契約できない**（法人契約には登記事項証明書が必要。古物商許可と同じ構造の制約 — [[開業準備_2026年11月]] A-1） |

| 選択肢B | **端末・回線とも個人名義のまま、通信費を按分して法人が負担**。事業用専用機であることを説明できれば按分100%も主張しうるが、**専用機であることの立証（通話履歴・用途）**が要る |

| 通信費 | 事業用専用機なら全額。兼用なら**通話・データの使用実態で按分** |
| ⚠️ 失業保険 | **本項が最大の論点。§6を参照** |

> **推奨**：**選択肢C（設立後に法人名義で契約）が最も安全**。9月時点では、失業保険の受給認定との関係でも「事業用の設備投資」と見える行為を増やさない方がよい。**ただし現行機の故障など実需があるなら、個人名義で買って後から売却（選択肢A）で足りる。**

## 5. 按分が必要なもの

**按分に共通する原則：根拠は「後から作る」ことができない。** 面積・走行距離・使用時間のいずれを使うにせよ、**記録を今日から始めること**が唯一の備えになる。

### 5-1. 自宅（持ち家・ローンなし）を事務所に使う

| 方式 | 内容 | 留意点 |
|---|---|---|
| **A：賃貸借契約を結ぶ**（推奨） | 法人と陛下個人で**建物の一部の賃貸借契約**を締結し、法人が**地代家賃**を支払う | 法人：損金。個人：**不動産所得**として確定申告（収入−固定資産税・減価償却費・保険料・修繕費の按分）。給与以外の所得が20万円以下なら所得税の確定申告は不要でも、**住民税の申告は必要** |
| **B：実費のみ法人負担** | 賃料は取らず、**電気代・Wi-Fi等を按分して法人が負担** | 手続きは軽いが、**建物そのもののコストは1円も法人に移せない** |

**按分の根拠として使えるもの**

| 費目 | 按分基準 | 実務のポイント |
|---|---|---|
| 家賃相当（賃料設定） | **床面積比**（仕事デスクのある部屋の面積 ÷ 延床面積） | 図面に業務使用部分を明示し、**寸法と面積計算を残す**。写真も添える |
| 電気代 | 床面積比、または**業務で使う機器の消費電力×稼働時間** | ロボットの試験・PC・作業灯を使うなら、面積比より実態が大きくなる。**説明できる範囲で** |
| 水道・ガス | 原則按分しない（業務との関連が薄い） | 業務上の必要があるなら根拠を用意 |
| Wi-Fi・通信費 | 使用時間比、または**回線の用途比** | 家族も使う回線であることを前提に、**50%を超える按分は根拠を厚く** |
| 固定資産税・火災保険 | 床面積比 | **方式Aの場合、個人側の不動産所得の必要経費**になる |

> ✅ **ローンがないことは有利。** 住宅ローン控除との按分調整（事業割合が50%を超えると控除が制限される等）を考えなくてよい。
> ⚠️ **一方で、[[運営固定費・サブスク一覧]]では事務所としてKOIL柏の葉（月38,300円・法人登記オプション込み）を計上している。** 登記上の本店をKOILに置きながら自宅も事務所として按分計上する場合、**「自宅で何をしているのか」の説明**が要る（作業・保管・帳簿管理など）。二重計上に見えない整理を先に決めること。

### 5-2. 古民家（個人契約・スペース貸事業と兼用）

**既に[[建物転貸借覚書(古民家・源氏車)]]（草案 v1.0・2026-08-20・未締結）が存在する。** 本書はそれを置き換えるものではなく、**未確定の空欄を埋めるための論点整理**である。

| 現状 | 内容 |
|---|---|
| 建物 | 茨城県稲敷市上根本3265。母屋 約150㎡／離れ 約120㎡／納屋 約120㎡（**計 約390㎡**） |
| 覚書の建て付け | 甲＝陛下個人（原賃借人）→ 乙＝株式会社RIGEL へ**転貸**。転貸借料**月70,000円（税込）** |
| 使用目的（覚書3条） | 事業用資産（卓上ロボット等）の**保管**に限定 |
| 🔴 空欄 | **転借する建物部分**が未記入。契約期間・締結日も未定 |

**ご入力の「賃料はレンタル事業と按分が必要？」への回答**

**必要になる。** 用途が3つ混在しているためである。

| 用途 | 主体 | 位置づけ |
|---|---|---|
| ① スペース貸・撮影・イベント | **個人**（源氏車事業） | 個人の不動産所得または事業所得 |
| ② ロボット保管倉庫 | **法人** | 転貸借の対象 |
| ③ メンテナンス作業場 | **法人** | **覚書3条は「保管」しか許していない。作業場として使うなら使用目的の文言を追加すること** |

**按分の考え方**

- **面積按分が最も説明しやすい。** 例：納屋120㎡のみを法人が使うなら **120 ÷ 390 ≒ 30.8%**。原賃料に対してこの比率が、法人が負担してよい上限の目安になる。
- 覚書の注記にも既に「**原賃貸借の対象が古民家全体であり、乙が納屋のみを使用する場合、賃料の全額を乙が負担すると私用部分まで法人が負担することとなり、税務上否認される恐れがある**」と明記されている。**本書はこの指摘を再確認するものである。**
- 月70,000円という転貸借料が**原賃料の何%に当たるのかが本書からは確認できない**。原賃料の額と、それに対する70,000円の比率を明示できる状態にすること。
- **時間帯で共用する場合**（例：土日はイベント、平日は作業場）は面積按分だけでは説明しきれない。**使用日数・時間の記録**を併用する。

### 5-3. プラド（妻の個人資産・私用70%／業務30%）

**ご入力の「ローンなしだが按分で利用分を請求可能か？」への回答**

**可能。ただし「誰の事業に、どう使うか」を先に切り分ける必要がある。**

| 前提の確認 | 内容 |
|---|---|
| 🔴 まず切り分ける | 「30%は仕事」の**仕事が、株式会社RIGELの業務なのか、点心事業・LANTERN・古民家といった別事業なのか**。[[点心事業_事業計画壁打ちメモ]]では**牽引車（150系プラド）の維持費按分を月7,000円**として点心事業側に計上済みであり、**同じ30%を法人にも請求すると二重計上になる** |
| 所有者 | 妻。**法人へ名義変更しない**前提 |
| ローン | なし → **減価償却は所有者である妻側の話**。法人は「使わせてもらう対価」を払う立場 |

| 方式 | 内容 | 必要なもの |
|---|---|---|
| **A：車両賃貸借契約** | 法人が妻に**月額の車両使用料**を支払う | 賃貸借契約書、月額の算定根拠（車両の時価・減価償却相当額・維持費×業務割合）。妻側は**雑所得** |
| **B：実費精算**（推奨） | 業務利用の都度、**走行距離×単価**、またはガソリン・高速・駐車場の実費のうち業務分を精算 | **運行記録**（日付・行先・目的・走行距離）。最も否認されにくい |

**注意点**

- **妻への支払は同族関係者への支出**であり、税務調査で必ず見られる。**実態と適正額の立証責任は法人側にある。**
- **30%という数字は現時点で「仮定」。**[[点心事業_事業計画壁打ちメモ]]にも「**プラドの事業使用割合を走行距離ベースで実測し、按分計算（現在は30%と仮定）を精緻化する**」と未了項目として残っている。**実測を始めることが、そのまま本件の準備になる。**
- **ガソリン代を法人カードで満タン給油して全額落とすのは危険。** 私用分は**役員（または関係者）への給与認定**になりうる。**法人カードはフィットシャトル（社有車）に限定し、プラドは実費精算で分ける**運用が安全。
- 妻が法人の役員・使用人である場合、車両使用料は**役員報酬とは別建て**の契約として区別すること。
- 任意保険の**使用目的が「日常・レジャー」のままだと、業務中の事故で保険金が支払われない可能性**がある。業務利用するなら保険の見直しを。

## 6. 🔴 失業保険との関係（iPhone購入・設立時期）

**ご入力の「失業保険取得時に問題になる？」への回答**

| 論点 | 整理 |
|---|---|
| 制度の建て付け | 雇用保険の基本手当は「**失業の状態**（就職の意思と能力があるのに職業に就いていないこと）」にある者に支給される |
| **端末の購入そのもの** | **備品を1つ買った行為だけで直ちに受給資格を失うとは考えにくい。** 問題になるのは「事業を**開始**したか」であって「買い物をしたか」ではない |
| **本当の論点** | **法人の設立登記・開業届の提出・営業活動の開始**が「事業開始」と判断されうる点。既に[[法人設立準備チェックリスト]]で「**失業保険を1ヶ月受給後に法人設立の実手続き（登記等）を開始する**」方針が確認されており、**本書の論点はこの既定方針と整合している** |
| 認定申告書 | 失業認定申告書には**事実を正確に記載する義務**がある。**隠すという選択肢はない**（不正受給は返還＋最大2倍の納付命令＝実質3倍） |
| むしろ有利になりうる制度 | 受給資格者が事業を開始した場合、**再就職手当の対象となる場合がある**。「受給が止まる」だけでなく「一時金を受けられる」可能性も含めて確認する価値がある |

> ✅ **陛下は既に2026-07-27にハローワーク松戸で相談実績がある**（[[法人設立準備チェックリスト]]）。**次の来所時に、以下の3点を具体的に確認されたい。**
>
> 1. **設立準備行為（備品購入・見積取得・打合せ）はどこまで許容されるか。** 具体的に「事業用携帯を買う」「中古ロボットを保有している」ことを申告した場合の扱い
> 2. **法人の設立登記を行った時点で受給はどうなるか。** 登記のみで役員報酬がゼロの場合も含めて
> 3. **事業開始による再就職手当の対象になるか。** 対象になる場合の申請時期と必要書類
>
> **この3点の回答は、iPhone購入時期・登記日・役員報酬の開始月のすべてに影響する。** 費用の話ではなく**日程の話**として扱うこと。

## 7. 息子への給与（経済大学3年・freeeでの帳簿管理・月5万円前後）

| 論点 | 整理 |
|---|---|
| **時期** | **法人設立前に支払った分は、法人の経費にできない。** 経常的な人件費は開業費にも含めないのが原則（**§1**）。**11月の設立以降、法人からの給与として支給する**のが筋 |
| **損金算入の可否** | 息子が**役員でない**なら、**不相当に高額でない限り損金算入できる**（個人事業の青色事業専従者給与と異なり、**事前の届出は不要**）。ただし**実態が伴うこと**が絶対条件 |
| **必要な記録** | ①**業務内容の定義**（freeeへの仕訳入力・証憑整理など）②**勤務記録**（日付・作業時間・作業内容）③**雇用契約書または労働条件通知書**④**給与の銀行振込**（現金手渡しは避ける） |
| **金額の妥当性** | 月5万円＝**年60万円**。第三者に同じ作業を頼んだ場合の相場（記帳代行 月1〜3万円程度）と比べて、**作業時間で説明できる水準にする**。「時給×実働時間」で組み立てるのが最も安全 |
| **息子側の税負担** | 年収60万円であれば**所得税は生じない見込み**（給与所得控除＋基礎控除の範囲内。2025年分以降の改正で非課税ラインは大きく引き上げられている）。住民税は自治体により発生しうる |
| **扶養** | 大学3年生＝**19〜22歳の特定扶養親族**。改正後の制度でも**年収150万円程度まで63万円の控除が維持される**仕組みとなっており、**年60万円なら扶養から外れない見込み** |
| **社会保険** | 月5万円・週の労働時間が短ければ、**社会保険の加入義務は生じない見込み**（月額8.8万円・週20時間等の基準を下回る） |
| **雇用保険・労災** | ⚠️ **代表者と同居の親族は原則として労働者として扱われず、雇用保険に加入できない**のが原則。**別居なら扱いが変わる**ため、実態を税理士・社労士に確認 |
| **法人側の手続き** | **給与支払事務所等の開設届出書**（[[法人設立準備チェックリスト]]に既出）／**扶養控除等申告書の提出を受ける**（甲欄適用。月8.8万円未満なら源泉徴収税額0円）／**源泉所得税の納期の特例の承認申請**（年2回納付に軽減）／年末調整／**給与支払報告書**を1月末までに市区町村へ |

> ✅ **簿記知識を養うという目的そのものは、業務実態の説明として弱くない。** 「帳簿管理を実際に担当させている」＝**法人にとって必要な役務の提供**である。**作業記録を残しさえすれば、否認される性質のものではない。**
> ⚠️ ただし**設立前の月5万円は法人では落とせない。** 現時点の支払をどう位置づけるか（家事費として整理するか、個人事業の経費とするか）は、**現在の陛下の所得区分次第**であり税理士に確認を要する。
