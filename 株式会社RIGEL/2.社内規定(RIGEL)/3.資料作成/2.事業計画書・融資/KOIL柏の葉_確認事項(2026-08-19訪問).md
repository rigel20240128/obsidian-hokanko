## 🔴 必須確認（これが埋まらねば設立スケジュールが止まる）

### A. 法人登記

| # | 確認事項 | 聞き方の例 | 回答欄 |
|---|---|---|---|
| A-1 | **どのプランから法人登記が可能か** | 「11月に法人を設立予定です。本店登記が可能なプランはどれですか」 | |
| A-2 | 登記可能プランの**月額と初期費用の総額** | 「登記可能な最安プランの、初期費用込みの総額を教えてください」 | |
| A-3 | **登記オプションの追加料金**の有無 | 「登記利用に別途料金はかかりますか」 | |
| A-4 | 登記に必要な**書類（賃貸借契約書・使用承諾書）**を出してもらえるか | 「法務局に提出する使用承諾書は発行いただけますか」 | |
| A-5 | 登記できる**住所の表記**（号室まで書けるか） | 「登記簿に記載する住所は、どこまでの表記になりますか」 | |
| A-6 | **契約から登記までの日数** | 「申込みから登記可能になるまで何日かかりますか」 | |

> **A-4が最重要。** 法務局は本店所在地の使用権原を確認する。
> シェアオフィス側が使用承諾書を出さない場合、登記できない。

### B. 法人口座・信用面

| # | 確認事項 | 回答欄 |
|---|---|---|
| B-1 | **入居者が法人口座を開設できた実績はあるか。どの銀行か** | |
| B-2 | 日本政策金融公庫の融資を受けた入居者の実績はあるか | |
| B-3 | 郵便物の**受取・保管・転送**（法務局・公庫・税務署からの重要郵便） | |
| B-4 | **社名の表示**（表札・館内表示）は可能か | |

> **B-1は必ず聞く。** シェアオフィスを本店とすると法人口座の開設を断られる例がある。
> 口座が開けなければ、公庫の融資も入金先がなく実行できない。
> 「実績がある」と言われたら**銀行名まで**聞くこと。
