#古民家事業
## 古民家再生事業

# 事業概要

・茨城県稲敷市にある古民家を再生し、地域資源を活用した複合型事業を展開する  
・古民家の歴史的価値を残しながら、飲食・撮影・レンタルスペースとして活用する  
・単なる飲食店ではなく、「体験」「空間価値」「地域文化」を提供する事業とする

# 目的
・築き上げられた日本の古民家文化を次世代へ継承する  
・地域に人が集まる場所を創出する  
・RIGELブランドの技術事業とは異なる、地域密着型の価値創造事業として展開する

## 施設概要

# 建物情報

・所在地：茨城県稲敷市上根本3265  
・敷地：約200坪  
・母屋：延床約150㎡  
・離れ：延床約120㎡  
・納屋：延床約120㎡  
・駐車場：約4台分
　100m離れた場所に5-10台分の駐車スペースあり

# 活用エリア

・母屋  
　・飲食スペース  
　・予約制レストラン  
　・イベント利用

・離れ  
　・レンタルスペース  
　・撮影利用  
　・ワークショップ利用

・納屋  
　・展示スペース  
　・体験スペース  
　・農業・地域文化体験用途

## 事業内容

# 予約制点心レストラン

・ターゲット：20代女性を中心とした体験価値を求める顧客  
・古民家の雰囲気と本格的な点心を組み合わせた非日常空間を提供する  
・大量集客型ではなく、予約制による高付加価値型運営を目指す

# レンタルスペース事業

・古民家空間そのものを価値として提供する  
・利用用途  
　・写真撮影  
　・動画撮影  
　・企業プロモーション撮影  
　・個人イベント  
　・ワークショップ

# 撮影ロケーション事業

・古民家の外観、内装、庭、納屋を活用する  
・企業CM、SNS撮影、映像制作向けに提供する  
・撮影利用料の目安  
　・個人利用：約20,000円／日  
　・企業撮影：約50,000円／日

# 地域体験事業

・古民家、農地、地域文化を活用した体験サービスを検討する  
・例  
　・農業体験  
　・昔ながらの生活体験  
　・食文化体験  
　・季節イベント

## 収益モデル

# 収益源

・飲食売上  
・レンタルスペース利用料  
・撮影利用料  
・イベント開催  
・体験サービス

# 方針

・低価格大量販売ではなく、高付加価値型サービスを目指す  
・古民家という唯一性を活用し、価格競争を避ける

## 将来展開

# 事業拡大

・古民家を地域交流拠点へ発展させる  
・飲食、撮影、体験を組み合わせた複合サービス化を進める

# RIGELとの連携

・RIGELの技術事業とは別ブランドとして運営する  
・将来的には地域事業と技術事業の両面から価値提供する

## 重要方針

# ブランド価値

・古いものを壊すのではなく、価値を再発見して未来につなげる  
・歴史ある空間に新しい役割を与える

# 事業理念

・過去の文化を未来へつなぐ  
・人が集まり、記憶に残る場所を創造する  
・地域に新しい価値を生み出す
