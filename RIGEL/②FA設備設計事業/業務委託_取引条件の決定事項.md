# 業務委託　取引条件の決定事項

> 元請け（現職の会社）から設計業務を受託するにあたり、2026年8月4日までに確定した条件の記録。
> **次回以降、契約書・見積書・請求書を作成する際は本ノートと照合すること。**
> 条文そのものは [[業務委託基本契約書_受注用]] を参照。

---

## 1. 取引の構図（最重要・取り違え注意）

| | 内容 |
|---|---|
| 取引の向き | **RIGEL → 元請け（現職の会社）に請求する** |
| RIGELの立場 | **乙（受託者）** |
| 使用する契約書 | [[業務委託基本契約書_受注用]] |
| 背景 | 元請けが人材不足のため、退職後も従前の業務の継続対応を要望 |
| 専属性 | **専属ではない。** RIGELは他事業も並行して行う |

※ RIGELが**外注先へ発注する**場合は [[外注業務委託契約書]]（RIGEL＝甲）。**両者を取り違えないこと。**

---

## 2. 料金体系（確定）

### 業務委託料
- **プロジェクト（案件）単位の一括額**とする。
- **稼働時間・稼働日数による管理および精算は行わない**（人日単価・時間単価での請求はしない）。
- 金額は個別契約ごとに協議して決定。

### 実費・付随費用（業務委託料とは別に請求）

| 項目 | 単価 |
|---|---|
| 交通費（自動車） | **45円／km** |
| 交通費（公共交通機関） | **実費精算** |
| 高速・有料道路・駐車場 | **実費**（上記交通費とは別枠） |
| 移動時間費 | **6,000円／時**　算定は「片道 × 2（往復）」　**上限なし** |
| 宿泊費 | **15,000円／泊（定額）**　実費精算ではない |

- 移動時間費のみ時間単価だが、これは**付随費用**であり本体報酬ではない（プロジェクト単位の原則の例外として第5条2項但書に明記済み）。
- **単価設定時の注意**：移動時間が6,000円／時である以上、**設計業務の実質時間単価がこれを下回ると「移動している方が儲かる」不整合**が生じる。業務委託料はこれを上回る水準で設定すること。

---

## 3. 稼働・働き方

- **人日／稼働時間による上限は契約書に記載しない**（プロジェクト単位のため）。
  - 受注量の調整は**見積時の工数見積とスケジュール**で行う。
  - 安請け合いを防ぐ契約上の担保は**第2条5項（個別契約の締結を辞退できる）**に集約。
  - ②FA設備事業の自社顧客（継続案件の軸となる約10社）の開拓時間を確保するため、**元請け案件で埋める割合の上限は社内目安として持つ**（契約書には書かない）。
- **作業場所**：基本はPC作業中心のため**自社事業所**。ただし**据付・立上げ・調整・打合せ・立会いのため、現地または請負会社（再委託先）の事業所で作業することがある**（第15条5項）。
- **再委託**：可能。元請けは体制の小ささを理由に再委託を制限できない（第12条3項）。組立の外注候補は3社。

## 4. 保険・法令

### 労災保険
- 法人の代表取締役は労働者ではないため、**労災保険の対象外**。
- フリーランス新法により**特定受託事業者として特別加入が可能**（業種不問）。
- **加入予定：2026年11月**（法人設立の直後）。
- それ以前に現地作業が発生する場合は**前倒しを検討**すること。移動中の事故も対象になり得る。

### RIGELを保護する法律（いずれも「守られる側」）
- **下請法（現・中小受託取引適正化法）**：RIGELは資本金300万円 → 下請事業者（保護対象）。
- **フリーランス新法**：RIGELは代表者1名・従業員なし → 特定受託事業者（保護対象）。**元請けの資本金を問わず適用される**点が重要。
- ⚠ **将来RIGELが従業員を雇用すると、フリーランス新法の保護対象から外れる。**

### その他
- **社会保険**：1人法人でも健康保険・厚生年金は強制適用。単価に約30%の負担を織り込む。
- **賠償責任保険**：現地作業の対物・対人事故に備え、請負業者賠償責任保険を検討。労災特別加入（自分の身体）とは別枠で、**両方必要**。
