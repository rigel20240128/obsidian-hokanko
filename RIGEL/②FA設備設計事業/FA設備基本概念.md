## 1. 事業コンセプト（一言で）

**「関東圏の特定顧客（前職の繋がり含め約10社）との継続関係を軸に、JANOME卓上/直交/SCARAロボット＋アルミフレーム架台による、10kg以下・0.1mm精度の組立/検査設備を、商社経由・売価500〜1,000万円台で供給する」**

- 高速ライン、24時間の不具合対応、垂直多関節ロボット、プレス関連の圧力管理、認証規格対応（ISO9001/IATF16949等）は対象外と明確に線引きする
- 商社・代理店経由の受注を軸とし（前職の繋がりあり）、資金負担の大きい直接営業一本足打法は避ける
- 5年後をめどにスタッフ5名体制を見込む

## 2. 対象市場

- **業界**：自動車部品（内装／電装品／樹脂部品）、電子部品組立、食品（生産設備・検査設備の両方）
- **エリア**：国内。まず関東圏を攻略し、数年後に全国規模へ拡大
- **商流**：前職で取引していた設備メーカー経由の紹介、および商社・代理店経由を軸とする。装置メーカーの下請けの場合はRIGELの役割を「設計のみ」に限定
- **顧客関係**：継続案件の軸は約10社。新規は展示会・商工会議所経由の紹介を重視
- **バッチ規模**：1バッチ10〜30個単位

## 3. 対応工程（やる／やらない）

| 工程 | 方針 | 詳細 |
|---|---|---|
| 組立 | ◎ 主軸 | 圧入組立／ネジ組立／はめ込み／接着組立、いずれも対応 |
| 検査（画像・寸法） | ◎ 範囲内 | 外観キズ／寸法／色味／部品有無を対象 |
| 締結 | ◎ 範囲内 | 電動ドライバーによる締結が基本。**プレスによる圧入・圧力管理は対応外** |
| 搬送・ハンドリング | ○ 簡易搬送のみ | ベルトコンベアで数十cm程度の搬送が基本。長距離・複雑な搬送系は対象外 |
| 塗布・接着 | △ 積極的には開拓しない | 前職との関係上の配慮 |

## 4. 標準機構・機材

- **ロボット**：JANOME卓上／直交／SCARAロボットを最優先で提案（客先要求があればIAI等も検討）。位置補正（カメラ・画像処理）はJANOMEロボット標準機能で対応し、別途カメラ選定は基本不要
- **駆動軸**：単軸アクチュエータ（JANOME、IAIベース）、最大ストローク1,000mm程度まで
- **架台**：アルミフレーム（MISUMI中心、標準部品比率は現状約70%。残り30%はロボット本体・シリンダ／電磁弁等のブランド品・特注部品）
- **空圧機器**：シリンダ・電磁弁（SMC）による位置決め・クランプ制御。**プレス相当の高荷重・トルク管理は対象外**
- **熱プロセス**：40〜100℃の範囲で温調・乾燥工程に対応
- **精密位置決め**：メカ的なジグを基本とし、段取り替え（機種切替）は30〜300秒程度を想定

## 5. 設備仕様の標準レンジ

| 項目 | 標準レンジ |
|---|---|
| ワークサイズ | 150×150×50mm程度まで |
| ワーク重量 | 10kgまで |
| ワーク材質 | 問わず。ただし樹脂は静電気帯電に注意 |
| 個体差許容 | 画像処理で±50μm程度まで吸収 |
| 位置決め精度 | 0.1mm（ロボット動作精度・ジグ位置決め精度の両方に適用） |
| タクトタイム | 1個あたり10秒程度が下限目安。高速ライン（数秒未満）は対応不可 |
| 生産数量 | 月産数千個から。上限規模は設備台数を増やすことでカバー（1ラインの高速化ではなく並列化で対応） |
| 多品種少量 | 最大10機種程度を想定 |
| 稼働時間 | 客先での24時間運用は可（設備側は対応）。ただし**RIGEL側の24時間不具合対応は不可**（保守は定期点検＋部品交換ベース） |
| 拡張余地 | 予備スペース・予備I/Oは標準設計に必ず織り込む |
| 検査方式 | 全数検査（画像処理搭載）／抜き取り検査（サンプリング率は客先次第） |
| トレーサビリティ | 外部サーバーへ接続。バーコード／2次元コード連携を含む |
| 不良品排出 | アーム排出方式 |
| 認証・規格対応 | ISO9001／IATF16949等の認証取得支援は**対応外** |
| 案件予算 | 売価500〜1,000万円台（周辺機器・据付込みの最終価格） |

## 6. 標準化とオーダーメイドのバランス

- 型化が理想だが「**顧客ごとの仕様差異が大きい**」ことが都度設計になりがちな根本要因と判明
- → 対応方針：完全な標準機の型化は狙わず、[[FA設備仕様]]の標準構成（アルミフレーム＋JANOMEロボット＋単軸＋シリンダ＋電磁弁）を「共通言語・共通部品セット」として持ちつつ、都度設計を前提に見積・工期を組む
- 設計データ蓄積は具体的に **①CADデータ　②仕様書テンプレート　③過去の不具合事例・対策集** の3種を蓄積対象とする。関羽（vault管理）と趙雲が連携してこの3種の蓄積構造を整備する

## 7. 拡張オプション

- 小規模改造・追加工事（既存設備への検査ユニット追加等、数十万円〜）は積極的に受注
- リース・レンタルモデル（RTS類似）は**売価500万円以下の小規模設備**に限り応用可能
- 保守契約は「定期点検＋部品交換」を基本とし、契約期間は3〜24ヶ月のレンジ

## 8. 体制・AIエージェントの役割範囲

- 設計主体は陛下ご自身。ただし**繁忙期は外部設計者へ一部委託する可能性あり**（完全内製ではない）
- 組立の外注先はすでに**3社**候補あり
- 現地立上げは陛下ご自身＋外注業者が対応
- スタッフ雇用は**創業5年後をめどに5名体制**を見込む（職種の内訳は未定）
- **趙雲（FA設計AI）への委任範囲は、仕様書作成・概算構想から詳細設計までの全工程**。趙雲が作成したものを陛下が最終承認するフローとする

## 9. 未確定・今後詰める論点

- **認証・規格対応を「対応外」とした場合のリスク**：自動車部品業界の顧客の中には、取引条件としてISO9001等の認証を暗黙に求めるケースがある。「対応外」の方針を営業段階で顧客にどう伝えるか（設計は対応するが認証取得支援はしない、等）は事前にすり合わせておくと良い
- **別事業（Lantern等）でのオリジナル製品計画との関係**：FA設備事業では「自社オリジナル機構は持たない」方針だが、別事業ではオリジナル製品を予定しているとのご回答あり。両事業のノウハウ・リソースが将来的に交差する可能性がある点は、頭の片隅に置いておきたい
