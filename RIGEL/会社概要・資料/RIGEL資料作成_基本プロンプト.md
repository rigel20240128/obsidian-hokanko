# RIGEL 資料作成 基本プロンプト（v1.0）

> RIGELの文書（契約書・提案書・仕様書・報告書などの印刷/PDF成果物）を作るときの
> **共通の作り方**。以後、資料作成を頼まれたら本プロンプトに従って作る。
> 姉妹ファイル [[プレゼンフォーマット]]（pptx向け）と一体でRIGELのブランド基準を成す。

---

## 0. 使い方（AIへの指示）
「RIGELフォーマットで◯◯を作って」と言われたら、以下すべてを満たす成果物を作る。
可能なら成果物はHTMLで組み、Edgeヘッドレスで**A4 PDF**化して納品する。

---

## 1. 会社ロゴ（最重要・変更不可）
- 使用ロゴ: `RIGEL(Jubilee Blue).png`（会社概要・資料/logo/）のみ。他バリエーションは使わない。
- 配置: **ページ右上**に固定。
- **ロゴの色味は絶対に変更不可（再配色・変形・分離・トーン変更いずれも禁止）。**
- ロゴ正式カラー「ジュビリーブルー」:
  | 表色系 | 値 |
  |---|---|
  | HTML/HEX | **#026881** |
  | RGB | **R:2 / G:104 / B:129** |
  | CMYK | **C:89 / M:56 / Y:44 / K:1** |
  - ※印刷（CMYK）・画面（RGB/HEX）で上記値を厳守。近似色で代用しない。

## 2. カラー運用（ブランドの濃淡設計）
同じ青の**濃淡（モノクロマティック）**で統一し、一体感と高級感を両立する。
- ロゴ・塗り面（表ヘッダー等）・区切り線 → 明るい **#026881**（ブランドの華）
- 文中の見出し（各章・条の見出し） → 濃い **#014B5D**（ジュビリーブルー・ダーク／引き締め）
- 本文 → 近似ブラック **#17181A**（青くしない＝可読性優先）
- 補足・キャプション → **#6B6E73**／罫線 → **#E3E1DB**／明背景 → **#F7F6F3**
- 別色相の多用は禁止。強調はオレンジ #E8622C を「重要数値・注意」のごく一部のみ。

## 3. タイポグラフィ
- フォント: **Noto Sans JP**（無ければ Yu Gothic / Hiragino 等にフォールバック）。
- 装飾フォント・手書き風は使わない。装飾は最小、階層とタイポで見せる。

## 4. 書式・ページ規定（印刷/PDF）
- **用紙は必ずA4**（`@page{ size:A4 }`）。余白は用途に応じ最小限（実印刷するなら端7〜8mm確保、PDF閲覧/入稿なら5mm可）。
- **章（条・セクション）の途中でページを割らない**。区切りは必ず章の境目。
  - CSS: 章ブロックに `break-inside:avoid; page-break-inside:avoid;`、
    見出しに `break-after:avoid;`、表・署名欄等の塊にも `break-inside:avoid;`。
- ページ末に隙間が出ても、章は途中で切らない（余白は許容）。
  隙間を減らしたいときは**文言を変えず**、行間・余白（レイアウト）で圧縮する。
  ※契約書等の法的文書は「文は正、レイアウトを合わせる」。句読点・文言を体裁目的で変えない。

## 5. レイアウトの型（文書系）
- ヘッダー: 右上にロゴのみ（重複する文字ラベルは置かない）＋直下に区切り線（#026881）。
- タイトル: 中央・太字（近似ブラック）。必要なら下にサブ（当事者名など・#6B6E73）。
- 本文: 章（第N条／セクション）を積む。各章は見出し（#014B5D・左に#026881のアクセントバー）＋本文。
- 表: ヘッダー行は #026881 塗り・白文字。
- 署名欄（契約書）: 末尾に甲/乙を2カラム、住所・法人名・代表者・押印欄。
- フッター: 文書名／日付を小さく（#6B6E73）。

## 6. 情報ソース
- 会社の事実（社名・代表者・住所・事業）は `RIGEL事業概要.md` 等、保管庫内のRIGEL資料から引く。
  （会社名: 株式会社RIGEL／代表: 佐藤 貴久／設立目標: 2026年10月29日 ほか）
- 案件固有の資料（例: 契約条件のxlsx）があれば必ず参照し、その内容を正としてデータを反映する。

## 7. 納品フロー
1. HTMLで組む（ロゴはbase64で埋め込み＝単一ファイルで完結）。
2. Edgeヘッドレスで **A4 PDF** 生成（`--headless=new --print-to-pdf --no-pdf-header-footer`）。
3. **PDFは自動でDownloadsフォルダへ保存**（都度確認しない）。元フォルダにも残す。
4. 契約等の法的文書は、末尾または連絡で「締結前の専門家確認」を必ず添える（本作成物は法的助言ではない）。
