# RIGEL プレゼンフォーマット（v0.2）

> **ステータス: 主要デザイン方針を確定（2026-07-23）**。今後の提案資料・説明資料すべての土台となる基本フォーマット。
> 図表配色順・章扉背景・表紙ロゴ位置・アクセント色の4点は陛下ご決定済み（6章参照）。NotebookLM生成のたたき台と統合し、さらに磨き込む余地は残す。

---

## 0. 位置づけ

- 対象: パワーポイント（pptx）で作成するスライド資料全般（営業提案、社内報告、説明会資料など）
- 目的: 案件ごとに配色・レイアウトがバラつかないよう、共通の「型」を持つ
- 関連ファイル:
  - [[RIGEL(Jubilee Blue).png]] — 使用する会社ロゴ（唯一の正式版）
  - [[skills/営業提案プレゼン作成]] — 本フォーマットをベースにした「営業・提案」特化スキル
  - `.claude/document_rules/01_presentation_design_rules.md` — 社内文書ルール全般（プレゼン以外にPRチラシ・仕様書も含む上位ルール）

---

## 1. ロゴ規定（固定）

- 使用ロゴ: [[RIGEL(Jubilee Blue).png]] のみ。他バリエーション（基本／立体／正式登録＝旧ネイビー版）は使用しない
- 色・形状は完全固定。再配色・変形・要素の分離は禁止
- 配置: **全ページ右上に固定（表紙も本編も右上で統一）**
- 濃色スライド（章の扉など）では、ロゴ輪郭に沿った**白フチ（約5px相当）**を付けてコントラストを確保する（矩形の白プレートは使わず、透明背景のまま輪郭だけ白縁取り）
- クリアスペース: ロゴ高さの0.5倍以上を四方に確保

## 2. カラーパレット

| 用途 | 値 | 備考 |
|---|---|---|
| 背景（明） | オフホワイト `#F7F6F3` | 本文スライドの基本背景 |
| インク（文字） | 近似ブラック `#17181A` | 本文・見出しの基本色（純黒は使わない） |
| サブ文字 | `#6B6E73` | 補足・キャプション・出典 |
| メイン／アクセント | RIGELジュビリーブルー `#026881` | ロゴと同系。強調文字、線、図表のキー系列 |
| メイン・ライト | ジュビリーブルー・ライト `#74ACBA` | 図表の第2系列、控えめな強調 |
| 罫線 | `#E3E1DB` | 区切り線、表の罫線 |
| 差し込み（章扉）背景 | ジュビリーブルー・ダーク `#014B5D` | 章扉・表紙などの反転（濃色）ページ |
| 章扉アクセント | ジュビリーブルー・ライト `#74ACBA` | 濃色背景上の強調要素 |

- 背景色は資料全体で最大1〜2色（オフホワイト＋反転の濃色）に絞る
- アクセントカラーの多用は避け、1スライドにつき強調は1〜2箇所

---

## 3. タイポグラフィ

- フォント: Noto Sans JP（ウェイト 300 / 400 / 500 / 700 / 900 を使い分け）
- タイプスケール（1920×1080px基準）

| 要素 | サイズ | ウェイト |
|---|---|---|
| タイトル | 68〜88px | 700〜900 |
| サブタイトル | 40px | 500 |
| 本文 | 32px（最小24px） | 400 |
| 補足（small） | 24px | 400 |
| kicker（章名ラベル） | 22px | 500 |
| 章番号・KPI数値 | 110〜200px | 900（特大） |

- 本文は最小24px（会議室スクリーン視認性の下限）を死守
- 装飾フォント・手書き風フォントは使用しない

---

## 4. レイアウト共通ルール

- サイズ: 16:9（1920×1080px）
- 全スライド左上に kicker（章名・セクション名）を配置
- 会社ロゴは全ページ右上に固定配置（1章参照）
- 各スライド右下にページ番号（`n / 総数` 表記可）
- タイトルは左寄せ・上部、下部に余白を残す構成
- 章の扉（差し込みページ）は反転デザイン（濃色背景＋白文字）で統一
- 装飾用の余計な図形・アイコン・数値は足さない（「装飾は最小、情報の階層とタイポグラフィで魅せる」）

---

## 5. スライド型（レイアウト部品）

枚数に依存しない。以下の型を必要な数だけ組み合わせる。

### 骨格（必須の3型）
- **表紙** — タイトル / サブ / 会社名 / 日付 / ロゴ
- **目次（アジェンダ）** — 章立てを番号付きで一覧
- **まとめ・締め** — 要点の再確認＋次のアクション（お問い合わせ・ロゴ）

### 中身（必要なだけ繰り返す本文型）
- **章の扉（差し込み）** — 章番号＋章タイトル。反転・ジュビリーブルーダーク。章の数だけ挿入
- **本文（箇条書き）** — 2〜4カラムの並列項目、または縦積みの論点
- **図表・グラフ** — 棒／折れ線／円 ＋ 左右2分割の説明文
- **比較・対比** — Before / After や A / B の2カラム
- **KPI 数値強調** — 特大数字を主役に、1〜4指標
- **プロセス／ステップ** — 横並びのSTEP、区切り罫線つき
- **スケジュール／工程** — ガント風のグリッド

### 汎用ルール
- 章の扉は章の数だけ挿入し、番号（01, 02, 03…）を自動連番にする
- 目次の項目数と章の扉の数は常に一致させる
- 型を増減しても、カラー・タイポ・レイアウト規則は変えない

---

## 6. 確定デザイン方針（2026-07-23 陛下ご決定）

- [x] **図表・グラフの配色順序**：`#026881`（メイン）→ `#74ACBA`（ライト）→ `#C7CBD3`（ミッドグレー）の順で固定。強調したい1系列のみ例外的にオレンジ`#E8622C`を使用。多色使いは避ける
- [x] **表紙のロゴ位置**：表紙も本編も**全ページ右上で統一**（中央大きく配置はしない）。テンプレートをシンプルに保つ
- [x] **章の扉（区切りページ）の背景**：**単色（ジュビリーブルー・ダーク `#014B5D`）で統一**。写真・図版は敷かない。章番号＋章タイトルのみの反転デザインで高級感・統一感を優先
- [x] **アクセントカラー**：基本は**ジュビリーブルー単色で統一**。オレンジ`#E8622C`は「重要数値・注意喚起」のごく一部に極小面積で使うのみ（セカンダリカラーとしての多用はしない）
